Feature Protection Roadmap

Stage 1 is implemented. --preserve-feature-curves now uses --feature-protection-mode primitive-curves by default: circle, near-circle, and ellipse loops stay hard-protected, while generic polygonal and dihedral creases are soft cost/guard inputs instead of automatic hard locks.

The strict legacy behavior remains available as --feature-protection-mode all-feature-edges or --protect-all-feature-edges. The SDK also exposes FeatureProtectionMode / LqFeatureProtectionMode with none, circular-only, primitive-curves, and all-feature-edges.

  • Mars wheel: all-feature-edges stopped at 10974 faces with 468702 feature rejections; primitive-curves reached 9066 faces with 31 feature rejections and 0 generic rejections.
  • Differential gear: all-feature-edges stopped at 2662 faces with 68993 feature rejections; primitive-curves reached 1236 faces with 0 feature rejections.
  • Fandisk: both modes reached target, but generic feature rejections dropped from 513 to 0.

Source design note: docs/design/feature_protection_roadmap.md.
