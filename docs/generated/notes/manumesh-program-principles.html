1程序目标与数据流

论文出处

标准 QEM 部分来自 Michael Garland 和 Paul S. Heckbert 的 Surface Simplification Using Quadric Error Metrics（SIGGRAPH 1997）。Line Quadrics 部分来自 Hsueh-Ti Derek Liu、Mehdi Rahimzadeh、Victor Zordan 的 Controlling Quadric Error Simplification with Line Quadrics（SGP 2025）。本仓库对应 PDF 位于 docs/papers/qem/garland_heckbert_1997_surface_simplification_qem.pdf 和 docs/papers/line_quadrics/liu_rahimzadeh_zordan_2025_line_quadrics.pdf。

当前程序把输入三角网格简化到指定面数或比例。核心库入口是 manumesh::simplification::simplifyMesh，输入为 manumesh::Mesh 与 manumesh::simplification::SimplifyOptions，输出为新的 manumesh::Mesh，同时可填充 manumesh::simplification::SimplifyReport。核心网格类型位于根 manumesh 命名空间，功能模块不再回灌根命名空间别名。

输入 STL/OBJ 或生成器 Mesh │ ▼ SimplifyOptions ├─ method: standard / line ├─ targetRatio / targetFaces ├─ lineWeight / weightMode / featureBoost ├─ boundaryWeight └─ preserveFeatureCurves / featureCurveWeight │ ▼ 可选：detectFeatureCurves() │ ▼ computeInitialQuadrics() │ ▼ 优先队列：每条活动边的坍缩代价 │ ▼ 反复弹出最低代价边 → 求新点 → 约束检查 → 更新网格 │ ▼ compactResult() 输出简化网格
这不是黑箱优化器

当前实现是典型的局部贪心边坍缩。每一步只看当前所有活动边中代价最小的一条，然后执行局部更新。数学目标来自 QEM 与 Line Quadrics 的二次误差，工程稳定性来自优先队列重建、退化三角形检查、重复面删除和特征约束拒绝。

2网格、面、边与坍缩问题

公共数据结构很轻量：

struct Mesh {
  std::vector<Vec3> vertices;
  std::vector<Face> faces;
};

struct Face {
  std::array<int, 3> v;
};

给定一条边 $(i,j)$，边坍缩会把两个顶点合并成一个新顶点 $x$。若保留 $i$、删除 $j$，所有引用 $j$ 的面都会改成引用 $i$。包含重复顶点的退化面会被删除。

所以每次坍缩要回答三个问题：

  1. 新顶点 $x$ 放在哪里？
  2. 坍缩代价是多少？
  3. 这个坍缩是否合法，是否破坏特征或生成退化几何？

QEM 负责前两个问题；当前程序的拓扑和特征逻辑负责第三个问题。

3标准 QEM：从点到平面的距离到 4×4 二次型

3.1 单个三角面的平面误差

设三角面 $f=(i,j,k)$ 的单位法向为 $n_f$，面上一点为 $p_f$。该面的平面方程写成：

$$n_f^\top x + d_f = 0,\qquad d_f=-n_f^\top p_f$$ (1)

任意点 $x\in\mathbb{R}^3$ 到该平面的有符号距离是：

$$r_f(x)=n_f^\top x+d_f=n_f^\top(x-p_f)$$ (2)

QEM 使用平方距离作为误差：

$$E_f(x)=r_f(x)^2=(n_f^\top x+d_f)^2$$ (3)

3.2 齐次坐标与 4×4 矩阵

令齐次点 $\bar{x}=[x^\top,1]^\top$，平面向量 $\pi_f=[n_f^\top,d_f]^\top$。则：

$$E_f(x)=\bar{x}^\top(\pi_f\pi_f^\top)\bar{x}$$ (4)

于是单个面的 quadric 为：

$$Q_f=\pi_f\pi_f^\top= \begin{bmatrix} n_fn_f^\top & d_fn_f\\ d_fn_f^\top & d_f^2 \end{bmatrix}$$ (5)

这正对应代码里的 planeQuadric(normal, point)：

plane << normal.x(), normal.y(), normal.z(), -normal.dot(point);
return plane * plane.transpose();

3.3 顶点二次型：面积加权 one-ring 求和

一个顶点 $i$ 通常连接多个三角面。当前程序把每个相邻面的面积平均分给三个顶点，所以顶点 $i$ 的面积权重为 $A_f/3$。顶点 quadric 为：

$$Q_i^{plane}=\sum_{f\in N(i)} \frac{A_f}{3}Q_f$$ (6)

因此顶点 $i$ 被移动到 $x$ 时的标准 QEM 误差为：

$$E_i^{plane}(x)=\bar{x}^\top Q_i^{plane}\bar{x} =\sum_{f\in N(i)} \frac{A_f}{3}(n_f^\top x+d_f)^2$$ (7)
代码映射

这部分在 src/simplification/QEMSimplifier.cpp 的 computeInitialQuadrics 中完成：每个有效三角面计算法线、面积、平面 quadric，再按 area / 3.0 加到三个顶点。

4边坍缩代价与最优位置求解

4.1 两端点 quadric 相加

若坍缩边 $(i,j)$，新点 $x$ 同时代表原来的两个顶点，因此误差直接相加：

$$Q_{ij}=Q_i+Q_j,\qquad E_{ij}(x)=\bar{x}^\top Q_{ij}\bar{x}$$ (8)

把 $Q_{ij}$ 分块：

$$Q_{ij}= \begin{bmatrix} A & b\\ b^\top & c \end{bmatrix}, \qquad A\in\mathbb{R}^{3\times3},\ b\in\mathbb{R}^3,\ c\in\mathbb{R}$$ (9)

则：

$$E_{ij}(x)=x^\top A x+2b^\top x+c$$ (10)

4.2 对二次函数求极值

如果 $A$ 可逆且条件良好，最优点满足梯度为零：

$$\nabla_xE_{ij}(x)=2Ax+2b=0$$ (11)
$$Ax^*=-b,\qquad x^*=-A^{-1}b$$ (12)

当前程序不是盲目求逆，而是先对 $A$ 做自伴随特征分解，检查特征值比例：

$$\frac{\min|\lambda_k(A)|}{\max|\lambda_k(A)|}>10^{-12}$$ (13)

只有满足条件才用 A.ldlt().solve(rhs) 计算候选最优点。否则进入 fallback。

4.3 fallback 候选集

无论线性系统是否可解，程序都会至少评估三个候选点：

$$\mathcal{C}=\{v_i,\ v_j,\ (v_i+v_j)/2\}$$ (14)

如果线性系统可解，则再加入 $x^*$：

$$\mathcal{C}=\{v_i,\ v_j,\ (v_i+v_j)/2,\ x^*\}$$ (15)

最终选择使 $\bar{x}^\top Q_{ij}\bar{x}$ 最小的候选点。这样做牺牲了一点理论上的连续最优性，但换来了数值鲁棒性。

直接解线性系统
  • 平坦区域中 $A$ 经常奇异。
  • 近平坦区域中解可能被浮点误差主导。
  • 错误解会污染优先队列排序。
当前程序的候选点策略
  • 先判断矩阵条件。
  • 不可解时仍能用端点/中点继续。
  • 所有候选都用同一个 quadric 代价比较。

5为什么平坦区域会退化

考虑一个完全平坦的局部区域，所有三角面的法线相同，例如 $n=[0,0,1]^\top$，且平面为 $z=0$。那么单个面的 $A_f=n n^\top$：

$$A_f= \begin{bmatrix} 0&0&0\\ 0&0&0\\ 0&0&1 \end{bmatrix}$$ (16)

任意面积加权求和后仍然只有法线方向有约束：

$$A^{plane}=\alpha n n^\top= \begin{bmatrix} 0&0&0\\ 0&0&0\\ 0&0&\alpha \end{bmatrix}$$ (17)

误差函数变成：

$$E^{plane}(x,y,z)=\alpha z^2$$ (18)

这意味着在切平面方向 $(x,y)$ 上，任意移动都不增加标准 QEM 误差。对于单步几何保真，这是合理的；但对于迭代边坍缩，它会造成一个工程问题：平坦区域里许多边代价同为零或接近零，优先队列很难区分“会形成好三角形的坍缩”和“会造成极差采样分布的坍缩”。

当前程序为什么要加 Line Quadrics

Line Quadrics 并不是为了让结果更贴近原始曲面法线方向，而是为了在标准 QEM 缺少切向约束时，给切向移动一个温和的正则项。它让平坦和近平坦区域的代价排序更有信息量，从而改善顶点分布和三角形质量。

6Line Quadrics：当前程序的核心增强

6.1 一般直线距离二次型

给定一条经过点 $p$、单位方向为 $t$ 的直线：

$$\ell=\{p+\alpha t\mid \alpha\in\mathbb{R}\},\qquad \|t\|=1$$ (19)

点 $x$ 到这条直线的平方距离等于 $x-p$ 在垂直于 $t$ 的平面上的投影长度平方。投影矩阵为：

$$P_t=I-tt^\top$$ (20)

因此线二次误差为：

$$E_\ell(x)=\|P_t(x-p)\|^2=(x-p)^\top P_t(x-p)$$ (21)

展开：

$$E_\ell(x)=x^\top P_t x-2(P_t p)^\top x+p^\top P_t p$$ (22)

写成齐次二次型：

$$Q_\ell(p,t)= \begin{bmatrix} P_t & -P_t p\\ -p^\top P_t & p^\top P_t p \end{bmatrix}$$ (23)

6.2 程序里的法线方向直线

当前程序中普通 Line Quadrics 使用的是“经过顶点、方向为该顶点面积加权法线”的直线。也就是说，对于顶点 $i$：

$$t_i=\frac{\sum_{f\in N(i)}A_f n_f}{\left\|\sum_{f\in N(i)}A_f n_f\right\|},\qquad \ell_i=\{v_i+\alpha t_i\}$$ (24)

代码里的 lineQuadric(point, normal) 不是直接构造公式 (23)，而是先找两条与 $t_i$ 正交的单位向量 $u_i,w_i$，然后把两张经过直线的平面 quadric 相加：

$$u_i^\top t_i=0,\quad w_i^\top t_i=0,\quad u_i^\top w_i=0$$ (25)
$$Q_\ell=Q_{plane}(u_i,v_i)+Q_{plane}(w_i,v_i)$$ (26)

因为 $u_iu_i^\top+w_iw_i^\top=I-t_it_i^\top=P_{t_i}$，所以 (26) 与 (23) 等价。

实现等价性

这也是 src/simplification/QEMSimplifier.cpp 中 lineQuadric 的核心：用 Gram-Schmidt 生成垂直于方向向量的两个基，再返回两张平面 quadric 的和。

6.3 平面 QEM 与线二次型合并后的矩阵性质

顶点 $i$ 的最终初始 quadric 是：

$$Q_i=Q_i^{plane}+w_i a_i Q_\ell(v_i,t_i)+Q_i^{boundary}+Q_i^{curve}$$ (27)

先忽略边界和曲线特征，只看平坦区域。若法线为 $n=[0,0,1]^\top$，则：

$$A^{plane}=\alpha nn^\top= \begin{bmatrix} 0&0&0\\ 0&0&0\\ 0&0&\alpha \end{bmatrix}$$ (28)

法线方向直线的投影矩阵为：

$$P_n=I-nn^\top= \begin{bmatrix} 1&0&0\\ 0&1&0\\ 0&0&0 \end{bmatrix}$$ (29)

加入 Line Quadric 后：

$$A=A^{plane}+w a_i P_n= \begin{bmatrix} wa_i&0&0\\ 0&wa_i&0\\ 0&0&\alpha \end{bmatrix}$$ (30)

只要 $w>0$、$a_i>0$、$\alpha>0$，矩阵就从秩 1 变为满秩。误差函数也从 $\alpha z^2$ 变成：

$$E(x,y,z)=wa_i\big((x-x_i)^2+(y-y_i)^2\big)+\alpha z^2+\text{linear/constant terms}$$ (31)

这就是当前程序中 Line Quadrics 的实际作用：标准 QEM 负责保持点接近原始局部平面；Line Quadrics 负责给切向漂移一个小惩罚，使平坦区域不再完全自由。

7权重、边界项与特征曲线项

7.1 普通 Line Quadric 权重

当前程序对顶点 $i$ 使用的普通线二次型权重为：

$$w_i= \begin{cases} w_0, & \text{uniform}\\ w_0+\beta s_i, & \text{dihedral / height / xband} \end{cases}$$ (32)

其中 $w_0$ 对应 lineWeight，$\beta$ 对应 featureBoost，$s_i\in[0,1]$ 是特征分数。

模式特征分数 $s_i$程序含义
uniform$0$所有顶点使用同一个 lineWeight。
height$\operatorname{clamp}\frac{z_i-z_{min}}{z_{max}-z_{min}}$高处更强，适合观察空间位置加权。
xband$\exp(-80(\hat{x}_i-0.5)^2)$x 中央带状区域更强。
dihedral由边二面角超过阈值的程度给出硬边、边界附近增加线二次型影响。

7.2 adaptiveScale 分支

默认分支直接加：

$$Q_i\leftarrow Q_i+w_i a_iQ_\ell$$ (33)

如果开启 adaptiveScale，程序先加一个基础线二次型，再整体缩放当前 quadric：

$$Q_i\leftarrow \left(Q_i+w_{base}a_iQ_\ell\right)(1+\max(0,\beta)s_i)$$ (34)

这个分支更像实验性“重要区域整体放大”，不是默认推荐路径。

7.3 边界 plane quadric

当 boundaryWeight>0 时，程序会对边界边加入额外平面约束。对边界边 $(a,b)$，令边方向为 $e=b-a$，相邻面的法线为 $n_f$。程序构造一个同时垂直于边和面的方向：

$$m=\frac{e\times n_f}{\|e\times n_f\|}$$ (35)

然后把经过边界边、法向为 $m$ 的平面 quadric 加到两个端点：

$$Q_a\leftarrow Q_a+\gamma\|e\|Q_{plane}(m,a),\qquad Q_b\leftarrow Q_b+\gamma\|e\|Q_{plane}(m,a)$$ (36)

这里 $\gamma$ 是 boundaryWeight。它惩罚顶点穿过边界支撑平面的运动，用来减少边界塌陷或边界漂移。

7.4 特征曲线 tangent-line quadric

当开启 preserveFeatureCurves 且 featureCurveWeight>0 时，程序会检测特征曲线，并对特征顶点加入沿曲线切线方向的 line quadric：

$$Q_i\leftarrow Q_i+\eta a_iQ_\ell(v_i,\tau_i)$$ (37)

这里 $\eta$ 是 featureCurveWeight，$\tau_i$ 是检测出的特征曲线切线。注意普通 Line Quadric 使用的是法线方向 $t_i$，而特征曲线项使用的是曲线切线 $\tau_i$。二者约束的自由方向不同：

普通 line quadric：方向为局部法线

点被鼓励留在穿过原顶点的法线直线附近，因此切向漂移会被惩罚，平坦区域更稳定。

特征曲线 line quadric：方向为曲线切线

点被鼓励留在特征曲线的切向直线附近，因此特征边/圆环不容易横向漂移。

8特征检测与圆形特征保持

8.1 特征边来源

detectFeatureCurves 会遍历无向边，根据相邻面数量和二面角判定特征边：

  • 只有 1 个相邻面：边界边。
  • 有 2 个相邻面且二面角超过 featureAngleDeg：折痕边。
  • 超过 2 个相邻面：非流形边。

二面角判定使用：

$$\theta=\arccos(|n_1^\top n_2|),\qquad \theta\ge\theta_0$$ (38)

8.2 normal tensor 弱特征来源

只靠二面角会漏掉浅折痕和 fillet transition。当前实现因此把 normal tensor 作为第二条证据通道：对顶点邻域面法向累加 $T=\sum w_f n_f n_f^\top$，再用特征值结构判断局部更像平面、折痕还是角点。这里的目的不是替代二面角，而是给 FeatureEvidence.cpp 一批“可能是弱特征”的候选边。

步骤当前实现为什么重要论文依据
局部尺度用局部平均边长解释 smoothing 和 gap 阈值。避免非均匀采样下同一个参数在稠密区过小、稀疏区过大。M009、M012/M013。
多尺度评分保留 featureScore、persistentFeatureScore、persistentScales。弱特征如果只在一个尺度高分，更可能是噪声；多个尺度都高分才更可信。M009、M015。
边接受要求端点 persistent score、最小 persistent scales 和 edge/tangent alignment 同时满足。防止孤立高分点被误连成 feature line。M012/M013 normal voting，M015 feature-line direction。
后续过滤tensor edge 还要进入 graph cleanup 和 component confidence。弱证据必须先 consolidated，再决定软保护还是硬保护。M026 CWF。

8.3 featureAngleDeg 与 loopTraceAngleDeg 的分工

featureAngleDeg 控制“这条边是否算二面角 evidence”；loopTraceAngleDeg 控制“这条边是否可以进入 trace graph 形成 loop ownership”。当 loopTraceAngleDeg<0 时，程序复用 featureAngleDeg。把这两个阈值拆开，是为了避免诊断里已经承认 25-39 度浅特征，但 trace 阶段又用更高阈值把它们排除，导致 QEM 完全消费不到这些边。

现象先看什么可能原因调整方式
dihedral feature edges 有数量，但 loop 很少untraced_feature_edges、loop 数、component 数。trace 阈值过高、图断裂、junction 太多。降低 loopTraceAngleDeg 或调小 cleanup gap；优先保持 evidence/trace 口径一致。
normal tensor edge 很多但 component confidence 低weakFeatureComponents、meanFeatureComponentConfidence。弱特征可能是噪声，或 alignment/persistence 不够严格。提高 normalTensorMinPersistentScales 或 alignment。
featureRejectedCollapses 极高featureRejectedCollapses 与目标面数差距。检测太宽或保护模式太硬。先降保护模式/权重，再考虑提高检测阈值。

8.4 从特征边到特征环

程序将特征边构造成顶点邻接图，再寻找连通的特征 loop。每个 loop 会记录顶点、边数、是否闭合、是否大部分来自边界等信息。每个特征顶点还会保存：

  • isFeature：是否位于特征图上。
  • loopId：所属特征 loop。
  • tangent：局部曲线切线。
  • circular 及圆心、法线、半径：是否识别为圆形特征。

8.5 graph cleanup 与 component confidence

真实 STL 的 feature graph 通常不是干净闭环：边界会有短 gap，normal tensor 会带来短 spur，junction 附近会出现重复或错位端点。FeatureGraphCleanup.cpp 在 loop 拟合前做三件事：短 gap 桥接、弱 spur 删除、近 junction 合并。桥接边带 cleanupBridge 标记，因此报告仍能区分原始证据和后处理补边。

component 统计含义QEM 侧用途
strongEvidenceRatioboundary / dihedral / non-manifold 等强证据比例。强 CAD loop 可以获得更高保护 confidence。
normalTensorEdges弱特征边数量。弱 ridge 通常先给软成本，不宜一开始全部硬锁。
closureRate端点、cycle rank 和闭合程度。闭合 loop 更适合 primitive fitting 和 hard budget。
junctionVertices度数不为 2 的图节点数量。junction 多时，普通 loop confidence 应降低。
primitive residual圆/椭圆/平面拟合误差。残差低的 primitive 才适合曲线偏移预算。

这一层把 M016 的 CAD feature graph 连续性、M024/M025 的 segmentation 边界闭合要求、M026 的弱特征 consolidation 放到同一个实现里：先把候选边整理成可信 component，再让 QEM 按 confidence 软消费或硬保护。

8.6 圆拟合推导

对一个候选特征 loop，先计算顶点均值 $\mu$ 和协方差：

$$\mu=\frac1N\sum_i v_i,\qquad C=\sum_i(v_i-\mu)(v_i-\mu)^\top$$ (39)

协方差最小特征值对应的特征向量作为拟合平面法线 $n_c$。在该平面上取正交基 $u,v$，把三维点投影成二维坐标：

$$x_i=(v_i-\mu)^\top u,\qquad y_i=(v_i-\mu)^\top v$$ (40)

二维圆方程写为：

$$(x-c_x)^2+(y-c_y)^2=r^2$$ (41)

展开并整理：

$$2c_xx+2c_yy+\rho=x^2+y^2,\qquad \rho=r^2-c_x^2-c_y^2$$ (42)

于是对每个样本点有线性方程：

$$ \begin{bmatrix} 2x_i&2y_i&1 \end{bmatrix} \begin{bmatrix} c_x\\c_y\\\rho \end{bmatrix} =x_i^2+y_i^2 $$ (43)

程序累计正规方程 $A^\top A$ 与 $A^\top b$，用 LDLT 求解。解出后：

$$r=\sqrt{\rho+c_x^2+c_y^2},\qquad center=\mu+c_xu+c_yv$$ (44)

最后计算径向误差和平面误差，并用相对阈值判定是否为圆形特征：

$$\frac{rms_{radial}+rms_{plane}}{r}\le \epsilon,\qquad \frac{\max(max_{radial},max_{plane})}{r}\le \max(3\epsilon,0.08)$$ (45)

8.7 坍缩保护与圆投影

开启特征保持后，程序不只是加权，还会硬性拒绝部分坍缩：

  • 若需要保护的特征顶点和非特征顶点相互坍缩，拒绝。
  • 若两个特征顶点不属于同一 loop，拒绝。
  • 若任一端点是 junction，拒绝。
  • 若该 loop 的活动顶点数已经不超过 minFeatureLoopVertices，拒绝。

若同一圆形特征 loop 内的边被允许坍缩，求得的新位置会被投影回拟合圆：

$$x_{proj}=center+r\frac{P_{n_c}(x-center)}{\|P_{n_c}(x-center)\|}$$ (46)

这对应 projectToCircle 与 projectFeaturePlacement。

9完整坍缩循环与合法性检查

核心循环在 simplifyMesh 中。其逻辑可以写成：

while activeFaceCount > targetFaces:
  if queue empty: rebuildQueue()
  candidate = queue.pop_min()
  if candidate stale or endpoints inactive: continue

  Q = vertex[a].q + vertex[b].q
  x = solveOptimal(Q, vertex[a].p, vertex[b].p)

  if featureCollapseAllowed(...) == false: reject
  if circular feature: project x back to fitted circle
  if collapseRejectReason(...) != None: reject

  keep a, remove b
  vertex[a].p = x
  vertex[a].q = Q
  rewrite faces b → a
  delete degenerate and duplicate faces
  push updated neighbor edges

9.1 stale candidate

优先队列里的候选边保存了两个端点的版本号。每次顶点被修改时版本号增加。弹出候选时如果版本号不匹配，说明该候选基于旧几何，直接丢弃。

9.2 几何合法性

当前代码把 collapse 合法性集中在 collapseRejectReason(...)。它先用 link condition 拦截会破坏局部拓扑的塌缩，再检查退化三角形、重复面、法向翻转、三角形质量、局部误差预算；开启 --prevent-local-intersections 或 --industrial-safe 后，还会做局部自交检查。也就是说，QEM/line quadrics 负责给候选排序，最终是否执行由这些拓扑和几何 guard 决定。

9.3 停止条件

目标面数为：

$$F_{target}= \begin{cases} \texttt{targetFaces}, & \texttt{targetFaces}>0\\ \max(4,\operatorname{round}(F_0\cdot\texttt{targetRatio})), & \text{otherwise} \end{cases}$$ (47)

如果约束太强导致长时间无法接受任何坍缩，程序会停止，而不是无限循环。

11总结：当前程序真正优化的目标

如果不启用特征曲线保护，当前程序每次坍缩近似最小化的是：

$$ E_{ij}(x)= \bar{x}^\top \left[ \sum_{q\in\{i,j\}} \left( \sum_{f\in N(q)}\frac{A_f}{3}Q_f +w_q a_q Q_\ell(v_q,t_q) +Q_q^{boundary} \right) \right] \bar{x} $$ (48)

启用特征曲线保护后，还会加入：

$$ \sum_{q\in\{i,j\}\cap feature}\eta a_q Q_\ell(v_q,\tau_q) $$ (49)

并且不是所有低代价边都允许坍缩；特征 loop 规则、圆投影、退化面检查会共同决定最终是否执行。

一句话版本

标准 QEM 让简化后的点尽量贴近原始局部切平面；Line Quadrics 给平坦区域的切向漂移加上温和惩罚；特征曲线项和硬约束让 CAD/STL 中的边界、折痕和圆环更不容易被坍缩破坏。当前程序就是把这三层机制合在一个优先队列边坍缩框架里。
