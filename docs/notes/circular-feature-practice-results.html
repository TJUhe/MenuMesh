1. 实验怎么跑的

这些结果来自当前仓库已经生成的验证输出，目录为 examples/output/feature_curve_validation/。核心对照是：

linequadrics validate-features --ratio 0.20 --n 96 --samples 1000

每个案例现在整理为三套简化结果：

  • standard：传统 QEM，不启用 line quadrics，也没有曲线特征保护。
  • line：普通 line quadrics + 二面角权重增强。
  • curve：在 line quadrics 基础上启用 --preserve-feature-curves，给圆形/曲线 feature loop 加 tangent-line quadric、collapse 合法性约束和圆投影 placement。
读表方式

matched / missing 表示输入中检测到的圆形环在简化后是否还能重新匹配。radial_rms 和 radius_error 越小，说明圆孔或圆环的半径漂移越小。

这不是完胜，而是工程取舍

凸台法兰的结果说明当前曲线约束对“可识别的圆环”非常有效，但检测器还会被 jagged hole boundary 和多环连通分量干扰。保住更多圆孔的同时，三角形质量和 edge length CV 会变差。这正好指向下一步：更强的 multi-loop tracing 和更温和的质量/特征联合权重。

5. 对 CWF 页面的补充意义

这些实践结果可以作为 CWF 理论页旁边的“当前程序证据页”。它们说明：

  • 当前程序已经能对圆孔、凸台、轴肩、槽轮这类 CAD 式圆形特征做可量化验证。
  • 传统 QEM 的整体距离误差可能很好看，但圆孔/凸台这种语义特征仍可能被破坏。
  • 普通 line quadrics 改善采样和部分几何误差，但仍不保证圆孔环不被 collapse 破坏。
  • 曲线特征约束通过 tangent-line quadric、collapse legality 和 projected placement，把“圆孔保持”变成可测指标。
  • 这与 CWF 的精神相通：不是只看整体误差，而是把特征对齐作为单独目标放进简化过程。
