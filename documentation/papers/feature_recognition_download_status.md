## Immediate Algorithm Takeaways

1. Add a scale-aware confidence layer: combine dihedral, normal-tensor anisotropy, curvature/ridge evidence, and persistence across neighborhoods instead of relying on one threshold.
2. Promote feature edges to a graph/loop object earlier: D-FRAME, PC2WF, and Polygon Crawling all treat connectivity and junctions as first-class, which matches the commercial-kernel need for stable CAD patch boundaries.
3. Separate hard CAD creases from smooth ridge/valley/fillet transitions: use dihedral and facet distribution for hard boundaries; use curvature/crest/ridge methods for soft features.
4. Add a segmentation validation loop: after detection, validate loop closure, patch leakage, primitive residual, and boundary consistency before simplification consumes the result.
5. Treat learned methods as benchmarks or offline tools first: DEF, PIE-NET, EC-Net, NerVE, and NEF are useful for labels, stress cases, and architecture ideas, but deterministic geometry filters should remain the commercial-core default.
