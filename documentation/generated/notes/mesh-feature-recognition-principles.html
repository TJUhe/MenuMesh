三角表面网格中的特征识别

从二面角的直接判断，到法向张量对弱折痕的补充

目录

如果把特征理解为“后续处理不应轻易抹去的几何结构”，最自然的出发点不是复杂曲率，而是一条网格边。边两侧三角面的朝向发生变化，这个变化由二面角直接给出。对于机械零件和 CAD 离散网格，大量重要轮廓正是这样显现出来的。

但二面角也很快暴露出边界：它擅长发现尖锐折线，却不擅长描述被圆角过渡削弱的折痕；它依赖面法向，而面法向又受绕序、退化面和噪声影响。法向张量（normal tensor）的引入，正是沿着这个问题继续向前一步。

1

从一条边开始：二面角为什么有效

设三角面 f = (i, j, k)。先由两个边向量的叉积形成未归一化法向；若三角面退化，则单位法向定义为零：

af= ( pj−pi )×( pk−pi ) nf={ af∥af∥ ∥af∥>0 0 ∥af∥=0 (1)

对一条恰好连接两个面的内部边 e，若两侧法向分别为 n0, n1，先把浮点点积限制在合法区间，再取反余弦：

C(x) = min (1, max (−1,x)) θe (0) = acos (C( n0 · n1 )) (2)

这里的 C(x) 只是数值保护，不改变几何含义。当协调后的二面角超过识别阈值 θ识 时，这条边成为硬特征候选；识别阈值取 40°。它不需要先估计高阶微分量，只要折角真实存在，即使三角形大小不均匀，法向跳变仍然清晰。

拓扑先于角度

并非所有边都适合计算二面角。首先按相邻面数量区分边的角色：

|F(e)|=1⇒边界边 |F(e)|=2⇒内部边 |F(e)|>2⇒非流形边 (3)

边界和非流形本身就是强拓扑信号；只有内部边进入角度判定。这样把“拓扑异常”与“几何折角”分开，也避免给没有唯一两侧面的边强行定义夹角。

处理选择：强特征先由边关联关系和二面角建立，而不是先计算曲率再反推折线。这使干净 CAD/STL 网格的主路径短、阈值含义直接，也让边界、非流形和折角分别保留自己的证据类型。
2

角度还不够：绕序、折向与退化

式 (2) 隐含了一个条件：相邻面的法向必须采用一致朝向。如果某个三角面被反向存储，它的法向会整体翻转，原本很小的夹角可能被读成接近 180°。因此，真正计算二面角之前，必须先处理面绕序。

先协调绕序，再计算角度

沿双面邻接关系做确定性的广度优先传播，为每个面求翻转符号 εf ∈ {−1, +1}，但不改写原网格。协调法向记为 n¯f：

n¯f = εf nf ce = C( n¯0 · n¯1 ) θe = acos (ce) (4)

这一步不是简单地对点积取绝对值。绕序协调尽量恢复局部可定向表面，使大角度和小角度仍保留原本的区别；局部反向存储的面也不会因此被误判为硬折角。

同一个角度，还要区分折向

二面角给出折叠强度，却没有说明折叠朝向。设 c0, c1 为两侧三角面的面心，面心矢量 ge 从第一侧指向第二侧。它与法向变化量的点积可用于判断局部折向：

ge= c1−c0 qe={ ge· ( n¯1− n¯0 ) ∥ge∥ ∥ge∥>0 0 ∥ge∥=0 (5)

对于非退化且绕序一致的相邻三角面，这个面心写法与有向二面角的传统三重积给出相同的折向符号；这里关注的是符号等价，而不是两个表达式的数值相等。

δ=10−12 se={ +1qe>δ −1qe<−δ 0|qe|≤δ (6)

符号随后参与曲线延续和分支相容性判断：两个已有明确符号但折向相反的局部片段，不应被轻易接成同一条特征线。这里的正负是相对于协调绕序的局部折向；只有外法向已经确定时，才可稳定解释为凸或凹。若整个闭合分量整体反向，正负类别也会交换。

绕序无法协调时如何降级

对于不可定向区域或局部拓扑冲突，不再伪造折向，而是退回无向角度：

θe* = acos (|ce|) se =0 (7)

这是一种可继续运行的降级，而不是完整修复。由于 acos(|ce|) 只落在 0° 到 90° 之间，真实的大折角可能被折回为补角。

需要保留的边界：如果一个真实的 150° 折角进入无向降级，它会表现为 30°，可能低于识别阈值。诊断中的绕序冲突计数因此不是普通统计项，而是解释漏检的重要依据。

退化面不是普通噪声

零面积三角面的法向为零。若直接与正常面做点积，它会产生近似 90° 的伪折角。这类输入仍可继续分析，但会在证据汇集后撤销与退化面相邻内部边的二面角标记；边界和非流形证据不依赖法向，仍然保留。

受证据处理次序影响，硬特征顶点掩码在退化证据撤销前已经形成，撤销后不会重新计算张量候选。因此，退化输入虽然不会留下伪二面角，却仍可能压制邻近的弱折痕候选；退化面计数必须和最终结果一起阅读。

分层处理的特点：“角度强度”“折向符号”和“输入可信度”被拆成三个层次。正常情况下保留有向信息；绕序冲突时只保留无向强度；法向本身失效时再撤销角度证据。与直接对点积绝对值取反余弦相比，这种分层处理保留了更多可解释信息。

识别阈值与追踪阈值分开

一条边先由 θ识 决定是否成为二面角证据，再由 θ追 决定是否进入曲线追踪。后者若未单独设置，就复用前者：

θ追={ θ识未单独设置 θ设已单独设置 θe ≥ max (θ识,θ追) 二面角进入追踪 (8)

这使“局部识别”和“曲线组织”可以采用不同严格度，但它不是高低双阈值生长。较低的追踪阈值不能召回未被识别的边；对二面角通道而言，最终有效条件仍是两道门槛中较严格的一道。

3

当折痕不再尖锐：法向张量

二面角观察的是一条边两侧的法向跳变。若表面经过圆角过渡，变化会分散到一片邻域中，单条边的夹角可能都不够大。此时需要换一个问题：不再问“这两张面差多少”，而是问“这个顶点周围的法向总体分布成什么形状”。

为什么使用法向外积

对顶点 v 的每个相邻面 f，取单位法向 nf 和面积 Af。先求有效邻接面的总面积 Av，再构造面积加权张量：

Av= ∑f∋v Af Tv={ Av−1 ∑f∋v Af nf nfT Av>0 0 Av=0 (9)

外积 nnT 有两个重要性质。第一，它把方向变成对称半正定矩阵，可以通过特征值分解读取主要方向。第二，(−n)(−n)T = nnT，所以张量天然不受法向正负翻转影响。这与二面角形成互补：二面角需要协调绕序，张量的局部分布本身不依赖法向符号。代价也由此产生：它能判断“像不像折痕”，却不能单独区分凸脊与凹谷。

面积权重抑制了细碎三角形的数量偏置。若不加权，一个大三角面与十个极小三角面会被当作 1 : 10；加入面积后，法向统计更接近实际表面覆盖。若邻域中的有效面积为零，则直接给出零张量，而不是让分母失效。

特征值谱在描述什么

令张量的特征值按降序排列：

λ0≥ λ1≥ λ2≥0 (10)

这里采用三个短谱量：

S面=max(0,λ0−λ1) S折=max(0,λ1−λ2) S角=λ2 (11)
近似平面
法向集中在一个方向，λ0 占主导，λ1, λ2 很小，因此 S面 较大。
折痕邻域
法向主要分布在两个方向张成的平面中，λ0, λ1 有支撑而 λ2 较小，因此 S折 较大。
多向交汇
法向在三个方向上都有明显分量，最小特征值也不再接近零，因此 S角 上升。

顶点在单个尺度上的候选分数取：

Sv= max (S折,S角) (12)

支持尺度的计数依据这个候选分数，而不只依据折痕分数。不过，真正生成弱特征边时还要求两端都满足 S折 ≥ S角。也就是说，角点响应可以进入诊断和持久性统计，但不会直接被当作普通折痕边延伸。

折痕切向来自最小特征值方向

在折痕邻域中，法向变化主要发生在垂直于折痕的截面内；沿折痕方向，法向变化最小。令 u2 为最小特征值对应的单位特征向量，则：

Tv u2 = λ2 u2 ∥u2∥=1 tv=u2 (13)
需要特别澄清的一点：折痕切向取最小特征值方向，而不是中间特征值方向。特征向量本身允许整体变号，但后续方向门控取点积绝对值，所以这个符号不确定性不会改变边的接受结果。
4

一个邻域还不够：尺度与持久性

单个一环邻域很容易把局部三角剖分误当成几何结构。因此，对张量场进行空间平滑，并在逐步增大的尺度上重复分析。先定义邻点权重，再写一次平滑：

wij= exp [− ( ∥pj−pi∥ ri ) 2 ] Ti′= Ti+ ∑j∈N(i) wij Tj 1+ ∑j∈N(i) wij (14)

其中 ri 由局部平均边长乘以尺度倍率得到。权重随距离平方指数衰减，避免远处结构以同样强度进入局部判断。这里平滑的是已经形成的张量场，不是面法向本身；更大的尺度也不是每次回到原始张量独立重算，而是在上一尺度结果上继续扩散。各尺度因此构成一条确定的累计过程。

不只看最大值：还要看尺度支持

设总尺度数为 K，第 k 个尺度的分数为 Sk，阈值为 τ张。用 m 记录达到阈值的尺度数：

m=|{ k∈{1,…,K} :Sk≥τ张 }| S¯= 1K ∑k=1K Sk S峰= max1≤k≤K Sk (15)

最终持久分数不是单纯的峰值，而是峰值、全尺度均值和支持比例的组合：

P张= ( 0.65S峰 + 0.35S¯ ) mK (16)

峰值保留局部显著性，全尺度均值惩罚只在某一尺度突出的偶然响应，m / K 则按支持比例衰减只在少数尺度出现的响应。在单尺度设定 K = 1 下，此项退化为单尺度分数；当 K > 1 时，式 (16) 开始发挥跨尺度加权。只有把最少支持尺度数也设为大于 1，才形成硬性的跨尺度门槛。

从顶点分数落到网格边

法向张量在顶点上产生方向与分数，最终结果却要落在已有网格边上。对边 e = (a, b)，依次检查：

  1. 该边不是边界、二面角或非流形强特征；
  2. 两个端点都没有接触离散强特征；
  3. min(ma, mb) 达到最少支持尺度数；
  4. min(P张,a, P张,b) ≥ τ张；
  5. 两端均满足 S折 ≥ S角；
  6. 网格边方向与至少一端的折痕切向充分一致。

最后一项先检查边长；零长度边直接拒绝，其余边再单位化并取两端对齐度中的较大值：

ℓe= ∥pb−pa∥ ℓe=0⇒拒绝 e^= pb−pa ℓe ℓe>0 max( |e^·ta|, |e^·tb| )≥η向 (17)

这里采用两端对齐度的最大值，而分数门控采用两端较弱值。前者意味着只要一端给出可靠方向，边就有机会被接受；后者要求两端都具有足够强度。两个门控一宽一严，分别处理方向估计的不稳定与特征证据的连续性。方向阈值取 η向 = 0.45。

证据组合策略：法向张量不在硬特征附近重复竞争。只要一条边已经属于强证据，或任一端点已经接触边界、非流形边或达到阈值的二面角边，张量通道就退出。这样牺牲了一部分硬边邻域中的弱响应，却换来更清楚的证据归属：二面角解释尖锐折线，法向张量补充远离硬边的弱折痕。
另一个有意保留的差异：可选面法向滤波会影响二面角，但法向张量仍直接从原始三角形几何重新计算法向。两条通道不是对同一组平滑法向做重复判断。它增强了证据独立性，同时也使张量通道对原始噪声更敏感，需要依靠空间尺度和持久性加以约束。
5

两条路径最终如何协同

从识别逻辑看，二面角和法向张量不是平行投票后简单相加，而是有明确优先级的两层判断：

  1. 先确认拓扑强信号。边界与非流形不依赖法向连续性，直接形成强证据。
  2. 再判断硬折角。内部边经过绕序协调、有向二面角与退化过滤后，形成可解释的强几何证据。
  3. 最后补充弱折痕。只有远离离散强特征的普通内部边，才进入法向张量的持久性、谱型和方向门控。

这种次序使两条方法各自承担最擅长的部分。二面角的优势是直接、稳定、阈值易解释；法向张量的优势是把一片邻域中的法向变化压缩成谱结构，并借助尺度持久性识别单边角度不明显的折痕。它们的共同限制也很清楚：最终特征仍需落在现有网格边上，因此三角剖分方向与真实曲线方向偏离过大时，候选边可能断续。

阅读结果时最重要的区分：二面角回答“这条边两侧是否发生明显折叠”；法向张量回答“这个邻域是否呈现折痕型法向分布”。前者是边局部的强判断，后者是顶点邻域的弱判断。把两者看成同一种分数，会丢失这种分层判断的可解释性。
