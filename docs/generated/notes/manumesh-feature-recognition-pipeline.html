1. 一句话路线

当前特征识别不是“单阈值二面角提边”。 它是一条 CAD/STL 优先的图恢复路线：boundary / non-manifold / dihedral 提供强离散证据，normal tensor 与 opt-in 的 smooth curvature（确定性多尺度 quadric 曲率）提供弱特征补充，之后构建 FeatureGraph 和 TraceGraph，通过 cleanup 修补/清理局部碎片，再恢复 open chain、closed loop、circle、near-circle、ellipse、polygonal loop，最后计算 component confidence，并把结果交给 CLI 报告和 QEM 简化保护使用。

这条路线与文献图谱的判断一致：对于干净 CAD/STL，二面角、边界、facet 邻接和 loop construction 往往比直接估 curvature derivative 更稳；对于弱 crease 或噪声场景，则需要 normal/tensor voting 或多尺度证据来避免单阈值漏检。文献技能的 distilled corpus 明确把 CAD/STL hard boundary 抽取、normal/tensor voting、loop tracing 和 feature-preserving simplification 分成互补家族 P00。

输入假设

输入是三角网格 Mesh，通常来自 STL/OBJ 或生成器。没有 B-Rep 语义，因此“孔、倒角、圆环、patch 边界”都只能从三角面邻接、法向和采样点几何中推断。

识别目标

不是完整 CAD 反求，而是为后续简化和验证提供足够稳定的特征图：edge evidence、loop、primitive、junction、component confidence。

核心取舍

强证据优先、弱证据保守；先成图再恢复 loop；把可保护的 primitive curves 和普通 crease 区分开，避免所有 feature edge 都被硬锁导致简化质量恶化。

3. 数据结构和输出语义

FeatureAnalysis 是识别模块的交付物，调用方不要只看 featureEdges。真正有语义的是 vertices、loops、components 和 graph 的组合 C02。

结构源码位置含义下游用途

为什么要保留这么多诊断？ 文献路线里，feature extraction 的风险不只是“漏边”，还包括边碎裂、loop 不闭合、junction 错误、弱特征噪声和简化后漂移。当前结构把这些风险拆成可观测字段，而不是只输出一个黑盒 edge set。

证据当前实现文献对应主要风险
Boundary edge incident faces 数为 1 即边界。 STL/CAD 三角网格边界抽取和工程对象边界 segmentation 是经典硬特征起点 P01 P09。 开放边界不一定是设计特征，也可能是破洞。
Non-manifold edge incident faces 数大于 2。 作为拓扑异常/分支处处理，比直接归为普通 crease 更安全。 可能来自坏网格，需要结合 repair。
Dihedral 有向二面角（orientedDihedralAngle）：先按共享边在两面中的遍历方向判断绕向一致性；一致时用带符号法向点积求转角，能识别 >90° 的反折刀边（旧 |dot| 会把 120° 法向夹角读成 60°、把薄片折边读成平面而漏检）；绕向不一致的边回退无符号角并计入 inconsistentWindingEdges。夹角超过阈值即候选，同时尝试 signed convex/concave 分类。 CAD/STL hard edge extraction 和 polygon crawling 家族的主要信号 P02 P03。 浅 fillet transition 容易漏；噪声面片会制造假硬边。
Normal tensor 只在非 boundary/dihedral/non-manifold 边上尝试；要求 persistent score、crease saliency、edge/tangent alignment 达标。 normal voting / normal tensor 文献用于弱 crease、噪声 crease 和 junction 分类 P04 P05。 尺度和局部采样密度决定成败，弱证据需要 cleanup 和 confidence。
Smooth curvature（opt-in） 只在非 boundary/dihedral/non-manifold、且两端都不是离散特征顶点的边上尝试；要求两端 persistent score、persistent scales、符号一致、切向一致性与边对齐同时达标。 确定性 ridge/valley 检测家族：局部 quadric 拟合 + 主曲率方向极值 + 多尺度 persistence P07 P08 P15。 光滑证据天然弱于离散证据，默认关闭；启用后仍由 graph 约束和 confidence 决定最终归属。详见第 8 节。

为什么强证据优先

NormalTensorEvidenceStrategy 和 SmoothCurvatureEvidenceStrategy 如果发现边已经是 boundary、dihedral 或 non-manifold，就直接返回；两个 candidate 函数还都会检查 discreteFeatureVertex，只要任一端点属于 boundary/non-manifold/强 dihedral，就拒绝弱边。这相当于在强 CAD 证据周围留出一个顶点宽的排除区，避免弱证据跨过硬边搭桥 C05 C30。两条弱路径独立执行，smooth strategy 不检查 edge.normalTensor，所以同一条非强证据边可以同时携带 normal-tensor 与 smooth-curvature 标记；后续 per-source 计数是证据通道计数，不一定等于唯一边数。

7. Normal tensor 弱特征分支

当前 normal tensor 实现是一个轻量局部版本：先用面法向 outer product 按面积累加到顶点，再按一环邻接进行可选平滑和多尺度平滑，最后通过张量特征值分解得到 surface/crease/corner saliency、feature score 和 persistent score C06。

每一尺度的张量都由面积归一化后的 face-normal outer product 构成；局部平均边长只用于平滑核半径，并不是再对 eigenvalue score 做长度除法。当前汇总公式是 averageFeatureScore = Σ scaleScore / scaleCount，robustScore = 0.65·maxFeatureScore + 0.35·averageFeatureScore，persistentFeatureScore = robustScore·persistentScales/scaleCount。只要某尺度的 featureScore 达到调用方给定 persistence threshold，该尺度就计票。

8. Smooth curvature 弱特征分支（opt-in）

本轮新增的第二条弱证据路径是确定性光滑曲率特征检测：用多尺度局部 quadric（Monge patch）拟合在光滑表面上找 ridge/valley 极值线。它没有任何 AI/学习成分，权威设计文档是 docs/design/smooth_curvature_feature_detection_2026_07_11.md，实现在 src/feature_detection/SmoothCurvature.cpp C29。

双路径理念：硬证据与弱光滑证据分开走，只在 FeatureGraph 汇合。 boundary、non-manifold、dihedral 是离散网格上的不连续；光滑 ridge/valley 是局部光滑表面上的微分事件。如果把两类原始分数直接混在一起，阈值会变得难以解释，噪声也会直接和强拓扑证据竞争。所以 ManuMesh 让硬证据（boundary / non-manifold / dihedral）和弱光滑证据（normal tensor / smooth curvature）各自打分、各自过滤，只在显式 FeatureGraph 上汇合——那里才有来源归属、连续性、junction、cleanup、component 和 confidence 可用。component 置信度把 normal-tensor 与 smooth-curvature 视为相互独立的弱支持（取两者中较强者作为 weak support），硬证据始终占主导 C12。

算法：逐顶点、逐拓扑尺度的九个步骤

  1. 构建 k-ring 邻域与面积加权局部法线；
  2. 用局部平均边长 × ring 数做坐标归一化；
  3. 带距离权与确定性 Huber 重加权拟合三次 Monge patch（9 系数：u², uv, v², u, v, u³, u²v, uv², v³），正规方程增量累加求解，替代每轮鲁棒迭代一次的稠密 QR；
  4. 由第一/第二基本形式解广义自伴特征问题，二次块给出两条带符号主曲率与方向；三次块解析给出 extremality e_i = ∇κ_i·t_i；
  5. 边零交叉极值判据（Ohtake）：主方向 line field 先做切向/extremality 符号同步；两端都通过曲率支配性测试（ridge 要求 κ_max > |κ_min|，valley 对偶）；extremality 沿近似跟随主方向的边变号并通过两端一阶极大测试；零交叉按 |e| 反比插值归属较小 |e| 的端点，使检测带保持一个顶点宽；
  6. cyclideness 门控（Yoshizawa M021 Eq.5-6）：零交叉处的插值 cyclideness 0.5(|e_center|+|e_neighbor|) 必须 ≥ 0.15·κ²（kMinCrossingCyclidenessRatio，e 与 κ² 同为 1/L² 量纲，比值无量纲、均匀缩放不变）。Dupin cyclide（球/柱/锥/环面）上 extremality 恒为零，符号变化只是离散化噪声——该门控让环面内侧曾经的伪 valley 带（24-48 段 max persistent 0.097→0.0）精确沉默；真 crest 的比值 p10 ≥ 0.38、环面伪交叉最大 0.06，阈值 0.15 对两侧各留约 2.5 倍裕量，高斯脊响应逐位不变；
  7. 打分融合尺度归一化曲率幅值、各向异性、极值对比度、拟合残差质量；
  8. 选最高分尺度为参照；全部请求尺度分别投票：候选有效、分数达到 max(绝对阈值, 0.30·bestScore)、signed kind 相同、与最佳切向的绝对 dot 达到一致性阈值即可。支持尺度不要求相邻，最粗尺度没有特殊否决权；
  9. 两端点在符号、切向、尺度支持、边对齐上都一致时，才把顶点证据转成 mesh-edge 证据。

14. 论文路线对照

按 mesh-feature-literature 技能的分类，当前 ManuMesh 选择的是“干净 CAD/STL hard boundary + normal/tensor weak feature + graph/loop recovery + feature-preserving simplification consumption”的组合路线，并在其上叠加了一条 opt-in 的确定性 smooth-curvature（多尺度 quadric ridge/valley）弱证据分支；仍然不是深度 wireframe 或扫描 mesh denoising pipeline P00。

程序阶段当前实现论文锚点为什么对应
CAD/STL 离散特征 boundary、non-manifold、dihedral evidence。 P01 P02 P03 这些文献关注 CAD/STL 三角面上的 C1/C2 discontinuity、feature edge extraction、polygon crawling 和 robust feature line extraction。
弱特征补充 normal tensor feature score、persistent score、edge/tangent alignment；opt-in smooth curvature 走并列的第二条弱路径。 P04 P05 P06 normal tensor / normal voting / multiscale crease 文献都在处理“局部法向变化如何从噪声与采样中分离出来”。
确定性曲率 ridge/valley 分支（opt-in） 多尺度 Monge patch 拟合 + 广义特征问题 + 方向极值 + persistence，顶点证据在两端一致时转为边证据（第 8 节）。 P07 P08 P15 curvature/ridge 方法对光滑表面 interrogation 有价值；ManuMesh 把它作为默认关闭的弱证据分支引入，而不是替代 CAD/STL 上更稳的二面角与 graph 规则。
Graph / loop / segmentation 友好输出 trace graph cleanup、loop recovery、component closure/confidence。 P02 P09 P14 工程对象 segmentation 和 wireframe extraction 都要求 feature 不只是边分数，而是连通、闭合、junction 正确的图。
简化保护消费 feature curve quadrics、hard protection、projection、curve budget。 P10 P11 P12 P13 feature-preserving simplification 文献共同强调：QEM 排序不够，必须结合特征权重、弱特征处理、边折叠约束和误差/质量 guard。

2017–2025 确定性文献锚点（smooth curvature 分支）

smooth-curvature 分支在本地 M014/M042–M044 曲率与 quadric 参考之外，还对照了近年不含学习成分的工作（综述见 docs/papers/recent_deterministic_feature_detection_2026-07-11.md P15）。当前实现明确不使用、也不推荐任何神经/学习方法。

开源库实现经验对照（smooth curvature 分支）

  • libigl：局部切平面 + k-ring/半径邻域 + quadric 拟合 + 显式主方向；ManuMesh 在此之上增加鲁棒重加权、尺度归一化、方向极值和 persistence。
  • pmp-library：曲率作为 mesh property，配显式边界与平滑策略；ManuMesh 保持“打分”与“graph 归属”分离。
  • CGAL PMP：在 patch/remeshing 操作前先物化显式约束边图；FeatureGraphEdge 就是 ManuMesh 的对应物。
  • OpenMesh：拓扑/状态/属性存储与特征策略分离；检测器只依赖核心 mesh 查询，不拥有编辑操作。

当前实现与文献路线的差距

  • 与 normal voting/tensor voting 全模型相比，当前 tensor 分支是局部轻量版，没有全局投票场和特征保持去噪 P05。
  • 与 ridge/valley/crest line 文献相比，opt-in 的 smooth-curvature 分支已经覆盖了曲率极值线检测的主干，但每个顶点只保存一条主导光滑切向（极紧的光滑多分支 junction 仍困难），也尚未实现全局 Hough/winding-number 曲线恢复和 split/collapse 后的增量邻域更新 P07 P08 P15。
  • 与 D-FRAME、PC2WF、NerVE 等 wireframe/神经方法相比，当前不学习方向场或隐式边场，不解决复杂 CAD wireframe 的全局图推断 P14。
  • 与 CWF 弱特征 consolidation 相比，当前已有 weak component 和 cleanup，但还没有完整的弱特征 consolidation/重定位/优化闭环 P10。

当前边界

  • 输入 STL/OBJ 没有 B-Rep 语义；圆孔、倒角、patch 边界均为从三角网格推断。
  • 默认更适合干净 CAD/STL；强噪声扫描 mesh 需要先补 robust normal/denoising/scale selection。opt-in 的 smooth-curvature 分支为光滑 ridge/valley 提供了确定性起点，但在带标注的扫描基准补齐之前不会默认开启。
  • normal tensor 与 smooth curvature 都是辅助弱证据，不应单独等价于真实 CAD feature。
  • feature graph cleanup 有保守上限：端点/junction 过多时跳过，以避免组合爆炸。
  • endpoint bridge 使用距离和双端切向，close-junction bridge 当前只使用局部尺度距离；后者在密集独立曲线网络中可能误连。
  • normal-tensor edge alignment 当前取两端较大值，只需一个端点方向达标；这是召回优先的宽松策略，噪声/非均匀采样 benchmark 仍应比较 min/mean 规则。
  • primitive fitting 的圆/椭圆判断依赖顶点采样质量、loop 闭合性和阈值。
  • featureComponentMinConfidence 不过滤低置信 component；若产品策略需要“低于阈值不保护”，必须在消费层显式实现，不能依赖当前计数选项。
