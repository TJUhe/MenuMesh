QEM 二次型展开速查：当前到底加了哪些项

ManuMesh 当前把所有软几何成本统一累积到齐次二次型。设 x 是候选新顶点位置，x_h=[x,1]^T，每个顶点保存 Q=[[A,b],[b^T,c]]，则候选代价为 E(x)=x_h^T Q x_h=x^T A x+2 b^T x+c。折叠边 (i,j) 时先做 Q_edge=Q_i+Q_j，再解 A x=-b；若矩阵病态则回退到端点/中点候选。

二次型项展开到 A,b,c参数与默认值作用与引用
面平面 QEMpi=[n,-n.p]，Q += area/3 * pi*pi^T。等价于 E=a(n.x-n.p)^2，所以 A+=a nn^T、b+=-a(n.p)n、c+=a(n.p)^2。无独立开关；退化面用很小的 1e-6 pointQuadric 稳定。主几何误差，来自 M002 Garland-Heckbert 1997。
普通 Line QuadriclineQuadric(p,n) 取两个与局部法线 n 垂直的单位方向 u,v，加入 Q_l=pi_u*pi_u^T+pi_v*pi_v^T。展开为 E_l=||(I-nn^T)(x-p)||^2，即惩罚切向漂移。useLineQuadrics=true，lineWeight=1e-3。默认分支：Q_i += w_i area_i Q_l。补平坦区 QEM 切向不满秩问题，来自 M004 Liu-Rahimzadeh-Zordan 2025。
特征加权 Line Quadric非 uniform 模式下 w_i=lineWeight+featureBoost*s_i；s_i 来自 dihedral、normal-tensor persistence、height 或 xband。normal-tensor 模式只给满足 normalTensorMinPersistentScales 的顶点写入 persistent score。weightMode=uniform，featureBoost=0.05；常用调试值 dihedral/normal-tensor + 0.08。featureAngleDeg=40，normalTensorFeatureThreshold=0.16，normalTensorScaleCount=1。让硬边、弱 ridge 或指定区域获得更高排序成本；feature evidence 参考 M007/M012/M013/M015/M016，弱特征参考 M026。
Adaptive Scale 分支若 adaptiveScale=true，当前实现先加 adaptiveBaseLineWeight*area_i*Q_l，再整体缩放 Q_i *= 1+max(0,featureBoost)*s_i。adaptiveScale=false，adaptiveBaseLineWeight=1e-2。这是实验性尺度归一化路径，不是默认推荐。用于跨尺度模型的 line weight 可比性；需要结合 benchmark 校准。
边界 Plane Quadric边界边 (a,b) 只有一个邻接面时，取 m=normalize(n_face x e_hat)，加入 Q_b=boundaryWeight*|e|*pi_m*pi_m^T 到两个端点。它的 A=boundaryWeight*|e|*mm^T，秩 1。boundaryWeight=0.0 默认关闭；常用 1-10。硬边界保护另看 preserveBoundary。减少开放边界沿面内法向漂移；扩展 QEM 思路参考 M003，工程 guards 参考 M030-M033。
特征曲线 Tangent-Line Quadric当检测到 loop/primitive 后，对特征顶点用切线 t 调用 lineQuadric(p,t)，即 E_curve=eta*rho*area*||(I-tt^T)(x-p)||^2。这里 rho=0.35+0.65*confidence。preserveFeatureCurves=false 默认关闭；featureCurveWeight=0.05，常用 0.08；featureComponentMinConfidence=0.35 影响诊断/策略判断。允许沿特征线滑动，惩罚离开曲线；组合 M004 line quadrics、M016 CAD feature line、M026 weak-feature consolidation、M028/M029 feature-preserving simplification。
Primitive 投影与硬过滤圆/椭圆/多边形不是当前 Quadrics.cpp 里的单独径向二次型；当前代码用 tangent-line quadric 排序，再由 projectToCircle/projectToEllipse/projectToPolygonal、maxFeatureCurveDeviationRatio 和 featureProtectionMode 控制最终位置与是否拒绝折叠。maxFeatureCurveDeviationRatio=0 表示关闭曲线漂移预算；featureProtectionMode=PrimitiveCurves。圆/椭圆阈值默认均为 0.05。把“软成本排序”和“硬合法性保护”分开，符合 M030-M033 edge-collapse 工程建议。
带合理参数的数值展开例子

为了看清量级，假设坐标单位是 mm，某顶点 p=(10,5,0)，barycentric 顶点面积 a_i=2.0，候选新位置写作 x=(x,y,z)。实际折叠候选会把两端点 Q_i+Q_j 相加；下面先看单个顶点的一项怎样进入 A,b,c。

例子代入参数展开后的二次型读法
面平面 QEM平面 z=0，n=(0,0,1)，a=2.0E_plane=2*z^2，A=diag(0,0,2)，b=(0,0,0)，c=0离开面法向 0.2 mm 的代价是 2*0.2^2=0.08。
普通 Line QuadriclineWeight=1e-3，n=(0,0,1)，a_i=2.0，所以 alpha=0.002E_line=0.002*((x-10)^2+(y-5)^2)，A=diag(0.002,0.002,0)，b=(-0.02,-0.01,0)，c=0.25切向漂移 1 mm 只加 0.002，它是稳定排序的小正则项，不应压过平面 QEM。
特征加权 Line QuadricweightMode=normal-tensor，persistent score s_i=0.6，lineWeight=0.001，featureBoost=0.08，得 w_i=0.001+0.08*0.6=0.049，alpha=0.098E_feature_line=0.098*((x-10)^2+(y-5)^2)，A=diag(0.098,0.098,0)，b=(-0.98,-0.49,0)，c=12.25同样 1 mm 切向漂移，代价从 0.002 升到 0.098，约 49 倍；这就是弱特征被 QEM 排序“看见”的方式。

为什么识别到边界、dihedral 或 normal-tensor 特征后要提高 Line Quadric 权重

先把一个容易误解的点说清楚：提高 lineWeight 或 featureBoost，确实会改变 A x=-b 的最小误差位置。它会让位置从“纯 plane QEM 的最优点”偏向“更靠近原顶点法线支撑线、切向漂移更小”的点。因此这不是免费的精度提升，而是一个有意加入的软正则项。M004 line quadrics 的核心价值，正是给标准 QEM 在平坦或近似平坦区域缺失的切向方向补一个小惩罚；M030-M033 的 edge-collapse 工程路线也强调，QEM/line quadrics 负责候选排序，真正危险的 collapse 仍要交给拓扑、边界、特征和质量过滤器。

当前代码里，weightMode=dihedral 会把开边界边记为 score=1，把超过 featureAngleDeg 的二面角边按强度写入端点分数；weightMode=normal-tensor 则使用满足 normalTensorMinPersistentScales 的 persistent feature score。随后普通 line quadric 的权重变成 w_i=lineWeight+featureBoost*s_i。这意味着边界、硬折痕、弱 ridge 附近的候选点，如果试图沿局部切平面大幅滑走，会在优先队列里付出更高代价。

疑问准确回答对应代码/参数
为什么识别到特征还要加 line 权重？因为 plane QEM 主要惩罚离开局部平面，很多特征破坏发生在切向：点沿表面滑过折痕、孔边被拖圆、边界轮廓缩进。Line quadric 惩罚 ||(I-nn^T)(x-p)||^2，正好给这种切向漂移加成本。Quadrics.cpp::lineQuadric，lineWeight，featureBoost
这会不会让最小误差位置更偏？会。它会偏离纯 plane QEM 的最优点，但这个偏移的方向是“少做切向漂移”。如果纯 plane QEM 本来在切向不满秩或近似不满秩，那么这个偏移反而让候选 placement 更稳定。solvePlacementCandidates() 用合并后的 Q_i+Q_j 求解
为什么特征附近要比普通平面更强？普通平面内的小滑动通常视觉影响不大；特征线附近同样大小的滑动可能跨过 CAD patch boundary、浅 ridge 或孔边。提高 w_i 让这些 collapse 排序靠后，给非特征区域优先被简化的机会。w_i=lineWeight+featureBoost*s_i
边界线也靠 line 权重保护吗？不是只靠它。开边界在 dihedral weight mode 下会得到高 feature score，从而减少切向漂移；但真正的边界形状和拓扑还要看 boundaryWeight 的边界 plane quadric、preserveBoundary 的硬策略和 topology guards。addBoundaryQuadrics()，preserveBoundary
normal tensor 弱特征会不会误检后过度保护？会有这个风险。所以 normal-tensor 路径现在用 persistent score、最小 persistent scales、edge alignment 和 component confidence 来减少单尺度噪声；弱特征更适合先作为软成本进入 QEM，而不是一上来全量 hard lock。normalTensorFeatureThreshold，normalTensorMinPersistentScales，featureComponentMinConfidence

可以用一个二维化的例子看直觉。假设局部平面是 z=0，纯 plane QEM 是 E_plane=2*z^2。候选点从 (10,5,0) 滑到 (11,5,0) 时，纯 plane QEM 代价仍是 0，因为它没有离开平面。加入普通 line quadric 后，代价多出 0.002；如果 normal-tensor persistent score 是 0.6 且 featureBoost=0.08，同样 1 mm 切向滑动代价变成 0.098。这并不是说几何误差突然大了 49 倍，而是系统在告诉优先队列：“这里像特征支撑，不要把切向漂移很大的 collapse 排得太靠前。”

因此正确的调参原则不是“特征越强，line 权重越大越好”。更稳的顺序是：保持基础 lineWeight 小，让它只修补平坦区病态；让 featureBoost 只放大高置信的 dihedral/normal-tensor 证据；把圆、椭圆、polygonal loop 交给 featureCurveWeight、primitive projection 和 hard feature policy；最后用 feature_rejected、generic_feature_rejected、max_orig_to_simp 和 feature drift 去判断是否过度保护。这个取舍也对应 M026 弱特征整合和 M030-M033 collapse guards 的思路：先让特征证据形成可靠 support，再决定软成本、硬保护或后处理投影。

因此当前总能量可读成：E = E_plane + E_line(weightMode) + E_boundary + E_feature_curve；拓扑、边界、特征保护、法向翻转、三角形质量、局部误差和自交检查不是二次型项，而是候选折叠通过 QEM 排序之后的硬过滤。

1当前程序解决的核心问题

当前程序的直接目标是：给定一个三角网格，在尽量保持形状、特征和拓扑合法性的前提下减少面数。它不是单纯追求误差最小，也不是单纯追求速度，而是在三个目标之间做工程折中：误差代价来自 QEM [GH97] 和 line quadrics [LRZ25]，特征曲线判断参考 normal tensor/feature-line 思路 [TH14]，拓扑合法性和工程组织参考 CGAL/OpenMesh 的 decimation 框架 [CGAL][OpenMesh]。

目标具体含义当前实现位置
几何误差小简化后的点不要远离原始局部平面和法向结构computeInitialQuadrics()、solveOptimal()
特征尽量保留硬边、圆孔、工业件上的连续特征线不要过早消失detectFeatureCurves()、featureCollapseAllowed()
几何合法闭合二流形不要被简化成开洞或非流形collapseWouldPreserveLinkCondition()
大模型可跑1w 到 10w 面模型不能因为每步扫全网格而变慢DynamicTopology
一句话概括

这个程序现在不是“只会做 QEM”的研究脚本，而是一个正在向工业 mesh kernel 收敛的简化内核：QEM 和 line quadrics 决定哪里值得塌缩，特征约束决定哪些塌缩要谨慎，link condition 决定哪些塌缩绝对不能做，增量邻接决定这些判断能不能在大模型上跑得动。这四层分别对应 cost、feature policy、legality、topology cache，后文每一层都会给出公式、例子和代码位置。

文献给出的关键提醒

本地文献综述也指向同一个结论：feature-preserving simplification 本质是约束优化，而不是单一阈值分类 [MLIT-SIM]。只增加特征权重或硬锁定特征边，可能保住局部线条，却牺牲三角形质量甚至拓扑。当前程序因此把合法性检查放在代价函数之后、真正执行塌缩之前，作为不可绕过的闸门。

2.1 本文符号约定

为与 docs/generated/notes/normal-tensor-qem-notes.html 保持一致，本文按下表使用符号。几何顶点写作 $V_i$ 或 $V_n$，优化变量写作 $x$；当强调顶点位置时，$x_i$ 表示 $V_i$ 的三维坐标。

符号含义使用位置
$V_i,V_j,V_n$网格顶点；$x_i$ 表示顶点 $V_i$ 的位置向量拓扑、特征、塌缩边
$x,\tilde{x}$塌缩后候选位置；$\tilde{x}=(x^\top,1)^\top$ 为齐次坐标QEM 能量最小化

3标准 QEM 的数学形式

3.1 点到平面的距离平方

QEM 的基本构造是把顶点到局部邻接平面的距离平方累加起来 [GH97]。设三角面 $(V_i,V_j,V_k)$ 的单位法向量为 $\hat{n}_{ijk}$，其所在平面为

平面方程 $$\hat{n}_{ijk}^{\top}x+d_{ijk}=0,\qquad \|\hat{n}_{ijk}\|=1.$$

点 $x$ 到该平面的有符号距离为 $\hat{n}_{ijk}^{\top}x+d_{ijk}$，距离平方为

$$E_{\pi_{ijk}}(x)=(\hat{n}_{ijk}^{\top}x+d_{ijk})^2.$$

写成齐次坐标 $\tilde{x}=(x^\top,1)^\top$，令平面向量 $\pi_{ijk}=(\hat{n}_{ijk}^{\top},d_{ijk})^\top$，则

QEM 基本二次型 $$E_{\pi_{ijk}}(x)=\tilde{x}^\top(\pi_{ijk}\pi_{ijk}^{\top})\tilde{x}.$$

一个顶点 $V_i$ 相邻多个面时，把这些面的 $\pi_{ijk}\pi_{ijk}^{\top}$ 按面积或局部权重累加，得到顶点 quadric $Q_i$。其左上角 $3\times3$ 块与 normal tensor 的结构一致：

QEM 法向二阶矩 $$A_i^{\text{QEM}}=\sum_{ijk\in N_i}a^i_{jk}\,\hat{n}_{ijk}\hat{n}_{ijk}^{\top}.$$

这正对应 normal tensor 页中的 $A_n=\sum_{n'\in\mathcal{F}(n)}w_{nn'}N_{n'}^fN_{n'}^{f\top}$。也就是说，QEM 的秩、条件数和病态求解可以用同一组特征值 $\sigma_1,\sigma_2,\sigma_3$ 解释。塌缩边 $(V_i,V_j)$ 时，合并点的代价为

$$E_{ij}(x)=\tilde{x}^\top(Q_i+Q_j)\tilde{x}.$$

3.2 最优点求解

把边塌缩 quadric $Q_{ij}=Q_i+Q_j$ 分块写成

$$Q_{ij}=\begin{bmatrix}A_{ij}&b_{ij}\\b_{ij}^\top&c_{ij}\end{bmatrix},\qquad E(x)=x^\top A_{ij}x+2b_{ij}^\top x+c_{ij}.$$

对 $x$ 求梯度：

$$\nabla E(x)=2A_{ij}x+2b_{ij}.$$

如果 $A_{ij}$ 可逆，则唯一驻点满足

最优位置 $$A_{ij}x=-b_{ij}.$$

当前程序在 solveOptimal() 中先尝试这个线性系统。如果矩阵病态或不可解，则回退到端点和中点候选，选代价最低者。

标准 QEM 的短板

如果局部区域几乎完全平坦，所有平面法向 $\hat{n}_{ijk}$ 都近似相同，则 $A_i^{\text{QEM}}$ 主要只约束法向方向，切平面内两个方向缺少惩罚。用特征值说，就是 $\sigma_1$ 大而 $\sigma_2,\sigma_3\approx0$。此时点沿切平面漂移几乎不增加 $E$，矩阵可能病态，优先队列中的代价也会失去区分度。

3.3 例子：为什么平坦区会秩亏

假设顶点 $V_i$ 周围有 4 个小三角面，它们都在平面 $z=0$ 上，单位法向量都是 $\hat{n}=(0,0,1)^\top$，每个面的权重取 $1/3$。那么

$$A_i^{\text{QEM}} =4\cdot\frac{1}{3} \begin{pmatrix}0\\0\\1\end{pmatrix} \begin{pmatrix}0&0&1\end{pmatrix} =\frac{4}{3} \begin{pmatrix} 0&0&0\\ 0&0&0\\ 0&0&1 \end{pmatrix}.$$

若候选塌缩位置相对原点为 $x=(a,b,c)^\top$，忽略一次项后有

$$x^\top A_i^{\text{QEM}}x=\frac{4}{3}c^2.$$

这说明 $a,b$ 两个切向坐标完全不进入代价。比如 $x=(1,0,0)^\top$ 沿平面滑动 1 个单位，代价仍为 $0$；而 $x=(0,0,0.1)^\top$ 只离开平面 0.1 个单位，代价是 $\frac{4}{3}\cdot0.01\approx0.0133$。所以普通 QEM 在平坦区不是“算错”，而是它的数学目标本来只看到了法向误差。这个例子与 normal tensor 页里 $A_n$ 的秩 1 平坦场景完全一致 [NQEM]。

4Line Quadrics 为什么能补 QEM 的短板

4.1 点到直线的距离平方

2025 line quadrics 论文的核心思想是：除了让点贴近原始切平面，还要让点不要在切平面内任意漂移 [LRZ25]。程序采用的是“点到法向线”的距离项。给定原始顶点 $V_i$ 的位置 $x_i$ 和单位法向 $\hat{n}_i$，法向线为

$$L_i(t)=x_i+t\hat{n}_i.$$

点 $x$ 到该直线的平方距离是

$$\operatorname{dist}^2(x,L_i)=\|(I-\hat{n}_i\hat{n}_i^\top)(x-x_i)\|^2.$$

这是因为 $\hat{n}_i\hat{n}_i^\top$ 是投影到直线方向的矩阵，$I-\hat{n}_i\hat{n}_i^\top$ 是投影到垂直于直线的平面。也就是说，line quadric 惩罚的是 $x-x_i$ 中垂直于法向线的分量。

4.2 为什么它给平坦区域补了秩

平面 QEM 的局部二次项可近似看成

$$A_i^{\text{QEM}}\approx \alpha\,\hat{n}\hat{n}^\top.$$

它只在法向 $\hat{n}$ 上有明显特征值，在切向两个方向上特征值接近 0，即 $\sigma_1\gg\sigma_2\approx\sigma_3\approx0$。line quadric 的二次项为

$$A_i^{\text{line}}=\beta(I-\hat{n}\hat{n}^\top).$$

两者相加后：

秩补全 $$A_i^{\text{total}}=A_i^{\text{QEM}}+A_i^{\text{line}} \approx \alpha\,\hat{n}\hat{n}^\top+\beta(I-\hat{n}\hat{n}^\top).$$

对任意向量 $v$，分解为 $v=v_\parallel+v_\perp$，其中 $v_\parallel$ 平行 $\hat{n}$，$v_\perp$ 垂直 $\hat{n}$，则

$$v^\top A_i^{\text{total}}v=\alpha\|v_\parallel\|^2+\beta\|v_\perp\|^2.$$

只要 $\alpha>0$ 且 $\beta>0$，该式对任意非零 $v$ 都大于 0。因此 $A_i^{\text{total}}$ 在局部变成正定或更接近正定，求解更稳定，切向漂移也有代价。用 normal tensor 的语言说，line quadrics 把原来接近 0 的 $\sigma_2,\sigma_3$ 提升到可控正值，使平坦区不再是任意滑动的零代价空间。

这就是当前程序采用 line quadrics 的数学依据

普通 QEM 主要控制法向误差，line quadric 补充切向正则化。它不是简单调大权重，而是给原来缺约束的方向加入明确的二次惩罚。

4.3 例子：同一个平坦区，加 line quadric 后发生什么

继续使用 3.3 的平坦区例子。普通 QEM 给出

$$A_i^{\text{QEM}}=\operatorname{diag}(0,0,4/3).$$

如果采用当前命令中常用的 --line-weight 1e-3 量级，把 $\beta=10^{-3}$ 看作局部线约束强度，则

$$A_i^{\text{line}}=10^{-3}\operatorname{diag}(1,1,0),\qquad A_i^{\text{total}}=\operatorname{diag}(10^{-3},10^{-3},4/3).$$

此时三个特征值为

$$\sigma_1=\frac{4}{3},\qquad \sigma_2=\sigma_3=10^{-3},\qquad \kappa(A_i^{\text{total}})=\frac{\sigma_1}{\sigma_3}\approx1333.$$

普通 QEM 的条件数相当于无穷大，因为切向特征值为 0；加入 line quadric 后，条件数虽然仍然不小，但已经是有限值。再看代价：沿切平面移动 $x=(1,0,0)^\top$ 时，普通 QEM 代价为 $0$，line 后代价为 $10^{-3}$。这个数不大，意味着程序仍允许平坦区简化；但它不再把任意远的切向漂移当成完全免费。也正因为 $\beta$ 较小，line quadrics 是“软约束”，不是把所有点钉死在原位。

5特征曲线保护为什么不能只靠硬锁定

2014 normal tensor 论文强调，工业模型里许多重要结构不是孤立边，而是连续 surface-feature lines，例如 Fandisk 上的硬边、Casting 上的孔边和 fillet 相关线 [TH14]。当前程序的 detectFeatureCurves() 会把 boundary、dihedral、non-manifold 候选边追踪成 loop 或 curve，并尝试识别圆形 loop。

在 normal tensor 记号下，顶点 $V_n$ 的局部法向分布由 $A_n$ 描述，特征值分解给出 $\sigma_1\ge\sigma_2\ge\sigma_3$ 与 $E_1,E_2,E_3$。参考页采用的显著性定义为

$$S_{Su}=\sigma_1-\sigma_2,\qquad S_{Cr}=\sigma_2-\sigma_3,\qquad S_{Co}=\sigma_3.$$

当 $S_{Cr}$ 占优时，顶点被解释为 crease，特征切向为 $T_n=E_3$。当前代码已经加入一版轻量 normal tensor 增强：computeNormalTensorFeatures() 从 one-ring 面法向外积累加 $A_n$，可选做邻接张量平滑，再输出 surfaceSaliency、creaseSaliency、cornerSaliency 和 featureScore。在 detectFeatureCurves() 中，normal tensor 只补充没有 boundary/dihedral/non-manifold 离散证据的软特征边，避免把干净圆孔硬环用额外 tensor 边搭桥成大组件；在 QEM 中，--weight-mode normal-tensor 会用同一 featureScore 抬高 line quadric 权重。

5.1 例子：60° 折痕为什么会被判成 crease

设 $V_n$ 在一条理想折痕上，两侧面法向关于 $z$ 轴对称，折痕方向为 $y$ 轴。若折痕角 $\varphi=60^\circ$，取

$$N_1=\left(\sin30^\circ,0,\cos30^\circ\right),\qquad N_2=\left(-\sin30^\circ,0,\cos30^\circ\right).$$

令两侧权重都为 1，则

$$A_n=N_1N_1^\top+N_2N_2^\top =\begin{pmatrix} 0.5&0&0\\ 0&0&0\\ 0&0&1.5 \end{pmatrix}.$$

因此 $\sigma_1=1.5,\sigma_2=0.5,\sigma_3=0$，显著性为

$$S_{Su}=1.0,\qquad S_{Cr}=0.5,\qquad S_{Co}=0.$$

如果采用 normal tensor 页中常见的 $\varepsilon=5$，分类时比较 $S_{Su}$ 与 $\varepsilon S_{Cr}$：$\varepsilon S_{Cr}=2.5>S_{Su}=1.0$，所以该点被判为 crease。对应的零特征值方向是 $E_3=(0,1,0)^\top$，这正是折痕方向，因此 $T_n=E_3$。这说明 normal tensor 的特征向量不是抽象数学装饰，它直接给出了“特征线应该沿哪里走”。

同一个公式如何解释阈值

若 $\varphi=20^\circ$，则 $\sin^2(10^\circ)\approx0.030$，$S_{Cr}$ 会很小。用 $\varepsilon=5$ 时不容易判成 crease；用 $\varepsilon=100$ 时才会把这种细微折痕放大出来。这就是 $\varepsilon$ 的工程含义：它不是神秘参数，而是在控制多小的折痕角也要被当成特征。

对应到简化，程序做了三件事：

  1. 给特征点增加 tangent-line quadric，鼓励新点留在特征曲线附近。
  2. 对圆形 loop，塌缩后可把新点投影回拟合圆。
  3. 在 hard feature 模式下，禁止跨 loop、跨 feature/non-feature、过度减少圆形 loop。
为什么后来又加拓扑合法性

我们在 Casting 模型上看到，单纯 hard-lock 特征边会导致大量拒绝和局部退化压力。特征保留本身不是错，但它不能高于拓扑合法性。最低代价且特征友好的 collapse，仍然可能让两个本不该相邻的邻域粘在一起，形成非流形边。

这正是当前实现的策略：特征约束可以拒绝一部分 collapse，但最终是否执行，还必须经过 link-condition 和面积退化检查。

6Link condition：为什么它能避免坏拓扑

6.1 定义

对顶点 $V_i$，定义它的 link 为所有与 $V_i$ 同在某个三角形中的邻接顶点集合：

$$\operatorname{Lk}(V_i)=\{V_k\mid (V_i,V_k)\text{ 是某个活动三角形中的边}\}.$$

对边 $(V_i,V_j)$，定义该边的 link 为共享这条边的三角形中的对顶点集合：

$$\operatorname{Lk}(V_i,V_j)=\{V_k\mid (V_i,V_j,V_k)\text{ 是活动三角形}\}.$$

当前程序采用的合法性条件是，这也是 edge-collapse 简化中常见的拓扑合法性门槛 [CGAL]：

Link condition $$\operatorname{Lk}(V_i)\cap\operatorname{Lk}(V_j)=\operatorname{Lk}(V_i,V_j).$$

6.2 证明思路

塌缩边 $(V_i,V_j)$ 等价于把 $V_j$ 的一圈邻域接到 $V_i$ 上。若存在某个顶点 $V_k$ 同时属于 $\operatorname{Lk}(V_i)$ 和 $\operatorname{Lk}(V_j)$，但 $V_k$ 不是边 $(V_i,V_j)$ 两侧三角形的对顶点，则塌缩前有两条不同路径：

$$V_i\leftrightarrow V_k,\qquad V_j\leftrightarrow V_k.$$

塌缩后 $V_i$ 和 $V_j$ 变成同一个点，这两条不同路径会合并到同一条边或同一片局部扇区上。结果是某条边被超过两个三角形共享，或者一个顶点的一环邻域不再同胚于圆盘/半圆盘。这就是非流形的来源。

反过来，如果公共邻居恰好只来自边 $(V_i,V_j)$ 两侧三角形的对顶点，那么塌缩删除的正是这两个三角形，其他邻域不会被额外粘合。局部拓扑从两个相邻三角扇合并为一个三角扇，二流形性质保持。

6.3 例子：一个合法塌缩和一个非法塌缩

场景link 集合能否塌缩直观解释
合法 interior edge$\operatorname{Lk}(V_i)\cap\operatorname{Lk}(V_j)=\{V_a,V_b\}$，且 $\operatorname{Lk}(V_i,V_j)=\{V_a,V_b\}$可以公共邻居只来自边两侧的两个三角形。塌缩删除这两个面后，没有额外邻域被粘合。
非法额外公共邻居$\operatorname{Lk}(V_i)\cap\operatorname{Lk}(V_j)=\{V_a,V_b,V_k\}$，但 $\operatorname{Lk}(V_i,V_j)=\{V_a,V_b\}$拒绝$V_k$ 同时邻接 $V_i,V_j$，却不是塌缩边两侧的对顶点。塌缩后两片原本分开的扇区会在 $V_k$ 附近被额外粘起来。

这张表可以这样读：link condition 不是为了让代价更小，而是为了确保局部网格仍然像一个盘。当前程序宁可少塌缩一条低代价边，也不允许把闭合二流形简化成非流形。

没有 link condition

代价最低的边可能把两个远处但共享邻居的扇区粘在一起。输出看起来面数正确，但会出现 non-manifold edge 或意外 boundary。

加入 link condition

这种塌缩在执行前被拒绝。代价函数仍负责排序，但拓扑合法性拥有最终否决权。

6.4 程序中的实现

代码位置是 collapseWouldPreserveLinkCondition()。它先找边 $(keep,remove)$ 的 incident faces，得到 $\operatorname{Lk}(keep,remove)$；再用增量邻接表分别取 keep 和 remove 的 link，计算交集并比较。

if (Lk(keep) ∩ Lk(remove) != Lk(keep, remove)) {
    reject collapse;
}

这个检查放在 collapseRejectReason(...) 的第一步。也就是说，无论是 standard QEM、line quadrics，还是 feature-preserving 模式，都不能绕过它；后续还会继续检查退化面、重复面、法向偏转、三角形质量、局部误差和可选局部自交。

7增量邻接拓扑：为什么能提速百倍

7.1 原来的瓶颈

加入 link condition 后，如果每次检查都扫描全体 faces，那么复杂度会非常差。假设有 $F$ 个面，需要执行 $K$ 次塌缩，原始做法近似是

$$O(KF).$$

100k 面模型塌缩到 50% 时，$K$ 约为 25k。每次都扫 100k faces，实际运行会被合法性检查和 neighbor refresh 拖垮。

7.2 例子：100k 面为什么会被全局扫描拖慢

以 Armadillo 100k 面、50% ratio 为例，粗略估算要执行 $K\approx25\,000$ 次塌缩。如果 link condition、邻接刷新、重复面检测每次都扫描 $F\approx100\,000$ 个面，那么仅一次“每步扫全局 faces”的检查量就是

$$K\cdot F\approx25\,000\times100\,000=2.5\times10^9.$$

这还没有计算优先队列更新和其他合法性判断。增量邻接的思路是：一个顶点的一环 incident faces 通常只有个位数到十几项，因此每次塌缩只需要改动 remove 和 keep 周围的小邻域。若平均局部面数按 $d\approx12$ 估算，局部访问量约为

$$K\cdot d\approx25\,000\times12=3\times10^5.$$

这不是严格复杂度证明，但足够解释为什么实测能从分钟级降到秒级。当前工程记录和大模型验证见 [ARCH][LV]。

7.3 当前的 DynamicTopology

当前程序在 simplifier 内部维护一个动态拓扑缓存：

vertexFaces[v] = 当前还包含顶点 v 的活动 face id 集合
facesByKey[sorted(a,b,c)] = 具有同一顶点集合的活动 face id 集合

它让以下操作从全局扫描变成局部查询：

操作旧做法新做法
判断两个顶点是否相邻扫描所有 face求两个 incident face 集合是否有交集
计算 link扫描所有 face 找包含该顶点的面直接遍历 vertexFaces[v]
塌缩后更新面扫描所有 face 替换 remove只遍历 vertexFaces[remove]
删除重复面全局重建 face key set局部查 facesByKey
刷新候选边扫描全体面找邻居只遍历 vertexFaces[keep]

如果平均顶点度数为常数，局部邻域大小近似常数，那么每次塌缩的拓扑维护从 $O(F)$ 降到近似 $O(1)$ 或 $O(d)$，其中 $d$ 是局部 incident face 数。

9用 Casting 模型把原理说透

2014 normal tensor 论文中的 Casting 模型来自 AIM@SHAPE/LIRIS 风格测试集 [TH14][LIRIS]。我们下载了公开镜像并转换为 casting_aimshape_2014.stl，它约 10k 面，包含大量圆孔、硬边和 fillet-like 结构，非常适合测试“特征保护”和“拓扑合法性”的冲突。

9.1 只看几何代价会发生什么

普通 QEM 可以把面数降到目标，但圆形特征 loop 会大量减少。它追求的是点到局部平面的误差小，不知道某些边是工业特征线。

line quadrics 后，平坦区域和规则采样更稳定。Casting 25% 简化时，普通 QEM 的 mean triangle quality 约为 0.549，而 line quadrics 约为 0.665 [LV]。也就是说，它不是只保外形，还改善了采样均匀性和三角形质量。

hard feature 会强行保护很多 loop。Casting 上 feature loop 很多，硬保护会导致大量候选 collapse 被拒绝，最终可能达不到目标面数。这说明“特征保留”本身还需要更细的 policy，不能简单理解为所有特征边都永远不能动。

在加入 link condition 前，部分 line/feature 模式可能在 Casting、Fandisk 这类模型上产生少量 boundary 或 non-manifold edge。加入 link condition 后，同样的模型输出不再新增坏拓扑。

这一节怎么读

前面的章节已经解释了 QEM、Line Quadrics、特征保护和 link condition 的独立原理。本节把它们按程序真实执行顺序重新串起来。你可以把 ManuMesh 想象成一条流水线：先把三角网格变成可查询的拓扑和特征证据，再把每个顶点变成一组二次误差矩阵，然后不断从优先队列里取出“看起来最值得塌缩”的边，最后用一串硬规则判断它到底能不能塌缩。

A.1 最小心智模型：算法到底在反复做什么

网格简化的一个 edge-collapse 步骤可以用一句话说清楚：选择一条边 $(u,v)$，把它的两个端点合并成一个新点 $x$，删除退化三角形，并更新周围的三角形连接。所有复杂性都来自两个问题：

  • 选哪条边：如果随便选，形状会很快坏掉；ManuMesh 用 QEM/line quadrics 给每条候选边打分。
  • 能不能塌缩：最低分的边也可能破坏拓扑、边界、特征线或三角形质量；ManuMesh 用 legality gates 拦住危险塌缩。
while face_count > target:
    edge = priority_queue.pop_lowest_cost()
    if edge is stale:
        continue
    placement = solve_best_position(edge.u, edge.v)
    if violates_feature_policy(edge, placement): reject_feature++ ; continue
    if violates_boundary_policy(edge, placement): reject_boundary++ ; continue
    if violates_link_condition(edge): reject_topology++ ; continue
    if flips_normals_or_bad_quality(edge, placement): reject_quality++ ; continue
    if exceeds_local_error_or_intersects(edge, placement): reject_error++ ; continue
    collapse(edge, placement)
    update_local_topology_and_queue()

A.3 QEM 的每个矩阵项到底从哪里来

标准 QEM 的核心思想是：一个顶点如果靠近它原来周围的所有面，就认为几何误差小。每个三角面给出一个平面 $\pi=(a,b,c,d)^\top$，其中 $(a,b,c)$ 是单位法向，$d=-n^\top p$。点 $x$ 到这个平面的有符号距离是 $a x+b y+c z+d$，平方后就是：

$$E_{plane}(x)=(a x+b y+c z+d)^2=\tilde{x}^\top(\pi\pi^\top)\tilde{x},\quad \tilde{x}=(x,y,z,1)^\top$$

一个顶点周围有很多面，所以顶点 quadric 是这些面 quadric 的和。边 $(u,v)$ 塌缩时，新点 $x$ 同时替代 $u$ 和 $v$，所以候选边的 quadric 是 $Q_u+Q_v$。这就是为什么 QEM 可以局部累加：每个面贡献一个二次型，顶点贡献是面贡献之和，边贡献是两个顶点贡献之和。

代码中的量数学意义容易误解的点
planeQuadric(n, a)$\pi\pi^\top$不是一个普通标量误差，而是一个可以之后代入任意点的矩阵
vertexArea[id]面积权重大三角面对误差贡献更大，避免小碎面过度支配
quadrics[a] += baryArea * q把面误差分摊到顶点不是复制面，而是在顶点上存局部形状约束
evaluateQuadric(q, p)$\tilde{p}^\top Q \tilde{p}$给候选位置打分，越小越贴近原始局部面

A.4 为什么要有 Line Quadrics，而不是只用 Plane QEM

Plane QEM 有一个经典问题：如果一个区域很平，所有点只要还在同一个平面上，点到平面的距离都接近 0。这样优先队列会看到大量“同样便宜”的边。算法仍能简化，但边长分布、采样均匀性和局部三角形质量可能变差。Line Quadrics 的做法是加一个很小的点到直线距离项，让平面内的移动也有轻微代价。

$$E_{line}(x)=\|(I-tt^\top)(x-p)\|^2$$

当前实现里 lineQuadric(point, normal) 的参数名是 normal，它构造的是与该方向相关的一条支撑线距离。直观上，标准 QEM 管“别离开原来的切平面太远”，line quadric 额外管“别在平面里乱滑得太厉害”。权重 lineWeight 通常要很小，因为它是正则项，不应该压过 plane QEM 的几何保真主项。

只用 Plane QEM
  • 平坦区域内很多候选边代价接近 0
  • 排序容易退化成实现细节决定
  • 局部三角形可能变瘦或采样不均
Plane QEM + Line Quadrics
  • 平坦区域也有轻微切向约束
  • 候选队列有更稳定的排序信号
  • 通常能改善 edge length CV 和局部质量

A.5 特征检测为什么放在简化之前

如果先简化再检测特征，弱特征可能已经被删掉了。ManuMesh 因此在需要特征保护时先跑 detectFeatureCurves()，把 STL/OBJ 的三角网格证据转成 FeatureAnalysis。这个结果不是“完美 CAD 语义”，而是一个可诊断的特征支持层。

Mesh
  -> build edge info
  -> collect boundary / dihedral / non-manifold evidence
  -> compute normal tensor weak evidence
  -> build trace graph
  -> cleanup short gaps and weak spurs
  -> recover loops and primitives
  -> summarize FeatureComponent confidence
  -> expose VertexFeature to simplifier
证据类型识别依据适合什么主要风险

B特征识别细读版：从 edge evidence 到 FeatureAnalysis

特征识别不是“把二面角大于某个阈值的边标红”这么简单。ManuMesh 现在把特征识别拆成四层：第一层收集局部证据，第二层把证据连成图，第三层把图修成可用曲线，第四层把曲线、primitive 和 confidence 写回 FeatureAnalysis，让 QEM 和 legality gates 能消费。这样做的原因来自文献里的共同结论：CAD/STL 硬边可以靠离散邻接和二面角起步，弱特征需要 normal tensor / voting 的尺度稳定性，后续 segmentation 和 simplification 则需要闭合、连续、可诊断的 curve graph。

B.2 第一层：从 MeshEdgeInfoMap 收集离散证据

检测器先用 src/common/detail/MeshQueries.h 建无向边到相邻面的映射。每条 mesh edge 只看局部邻接，就能得到三类强证据：只有一个相邻面的边是 boundary，超过两个相邻面的边是 non-manifold，恰好两个相邻面的边可以计算二面角。这个路线对应 CAD/STL 文献中的硬不连续性识别和 polygon crawling：先用网格邻接找到候选边，再追踪成连续边界，而不是从一开始就猜曲面语义。

判定当前实现含义参数论文来源
Boundary相邻面数为 1。它可能是真实开口/孔边，也可能是破洞；所以报告为强 evidence，但下游仍要看 loop closure。边界保护和 boundary quadric 参数。M016、M018/M019 的 CAD mesh edge tracing 思路。
Dihedral两个相邻面法向夹角达到 featureAngleDeg。这是硬折痕的最快 baseline。featureAngleDeg 控制“是否算 evidence”。M007 的 C1/C2 discontinuity 背景，M016 的 CAD triangular mesh feature line extraction。

这一层最重要的工程原则是：edge evidence 和 loop ownership 分开报告。如果某条边满足二面角阈值却没有进入任何 loop/component，就应该在 untraced_feature_edges 一类诊断里暴露出来。这样调参时可以区分“没检测到”和“检测到了但没有形成可用曲线”。

B.3 第二层：normal tensor 只补弱证据，不替代 CAD 证据

二面角对干净硬边很快，但对浅折痕、fillet transition、非均匀采样和噪声不够稳。normal tensor / normal voting 文献的核心想法是：不要只看一条边两侧两个面的夹角，而要看一个局部邻域里的法向分布。ManuMesh 的 NormalTensor.cpp 会把每个顶点的一环/多尺度邻域法向外积累加成 $T=\sum w_f n_f n_f^\top$，再由特征值结构得到 surface / crease / corner saliency。

实现细节为什么需要相关论文
局部边长归一化同一个 smoothing 半径在稠密区和稀疏区不能有完全不同的几何意义；所以半径和 gap 阈值要和局部平均边长/采样密度绑定。M009 multi-scale crease detection，M012/M013 normal voting。
多尺度 persistence单尺度最高分容易把噪声当特征；persistentScales 和 persistentFeatureScore 表示同一个顶点在多个尺度下是否稳定高分。M009 的多尺度思想，M015 normal tensor surface-feature lines。
端点最小分数一条 feature edge 两端都应该有支持；只用平均值会让一个高分噪声点拖着低分点误连。normal voting 里的局部一致性要求，M012/M013。
切线对齐张量给出的 crease tangent 应与 mesh edge 方向一致，否则只是点状响应，不应连成曲线。M015 的 feature-line direction，M016 的 graph continuity。
按 component 消费一个弱 ridge 不应该全局关闭圆孔 fallback；只有同一连通分量内部的证据和风险才应该互相影响。M024/M025 segmentation loop closure，M026 weak-feature support consolidation。

可以把 normal tensor 看成“弱证据候选器”：它告诉检测器哪里可能有连续浅特征，但这些边还要经过 graph cleanup、component confidence 和 benchmark 验证。默认路线仍是强 CAD/STL evidence 优先，tensor evidence 用来补漏，而不是把所有高分点直接硬锁。

B.4 第三层：trace graph 和 cleanup 把候选边变成曲线

一堆边还不能保护特征。QEM 需要知道“哪些顶点属于同一条曲线”“这条曲线闭合吗”“junction 是真实分叉还是噪声造成的断裂”。因此 FeatureGraph.cpp 先把候选 edge 加入 trace graph，FeatureGraphCleanup.cpp 再做三类整理。

  1. 短 gap 桥接：如果两个 endpoint 在局部尺度下足够近、方向也合理，就用 cleanupBridge=true 的边补上断裂。bridge 会被报告出来，不会伪装成原始 dihedral/boundary。
  2. 弱 spur 删除：如果一个短枝只由 tensor-only 弱证据支持，且没有强 CAD 证据，就删除。这样保留弱特征 recall 的同时控制假阳性。
  3. 近 junction 合并：很多 STL 在角点附近会出现多个几乎重合的端点；合并可减少“本来闭合的 loop 被切成几段”的情况。

这里对应 M016 的 CAD feature graph 连续性，也对应 M024/M025 的 segmentation 前提：没有闭合、连续、可追踪的边界，后续 patch segmentation 或 primitive fitting 就会泄漏。M026 CWF 则提醒我们，弱特征要先 consolidated 成稳定 support，再决定是软保护、硬保护还是后处理 relocation。

B.5 第四层：loop recovery 和 primitive fitting 决定哪些特征值得保护

cleanup 后，检测器会从 trace graph 里恢复 loop 或 chain。圆孔、椭圆孔和近圆 loop 会走 primitive fitting：先用局部点集拟合平面，再投影到 2D，拟合 circle / ellipse，最后计算 radial residual、plane residual、闭合率和顶点数门槛。

步骤检查什么失败时的含义
排序 loop vertices顶点是否能沿图走成稳定序列，是否有过多 junction。edge evidence 还不是可用曲线，可能需要 cleanup 或更严格阈值。
拟合平面loop 是否近似共面，法向是否稳定。可能是空间折线、破碎边界或噪声枝。
拟合 circle / ellipse半径、长短轴、中心、残差是否合理。不能当作圆孔硬保护，只能作为 generic polygonal feature。
写回 VertexFeature每个顶点获得 loop id、component id、confidence、tangent、primitive 数据。如果 id 或 ownership 不连续，QEM 侧会漏建约束；这类问题必须用测试保护。

这一步解释了为什么“检出 edge 数量”不是充分指标。真正有用的是：feature edges 是否形成 component，component 是否闭合，loop 是否能稳定拟合 primitive，primitive 的 residual 是否低到可以给 QEM 使用。

B.6 QEM 怎么消费这些识别结果

特征识别的结果进入简化器后有三种作用。第一，Quadrics.cpp 会把 feature score、component confidence 和 tangent 数据转成 feature-curve soft quadric，让候选点更倾向于贴近曲线。第二，FeatureConstraints.cpp 会在 primitive curve deviation 超预算时拒绝塌缩。第三，SimplifyReport 会暴露 feature rejection、weak/high-confidence components、graph cleanup 计数，方便判断是检测问题还是保护策略问题。

消费方式软/硬适合对象风险
feature-curve quadric软成本可信但不需要完全锁死的曲线、弱 ridge、generic polygonal feature。权重过小会漂移，过大可能压过 plane QEM。
primitive deviation budget硬 guard圆孔、椭圆孔、制造语义明确的闭合 loop。目标 ratio 太低时可能导致大量 featureRejectedCollapses。
feature protection mode策略层primitive-curves、circular-only、all-feature-edges 等不同保守程度。全部硬锁通常能保特征，但可能牺牲面数、质量和局部 valence。
benchmark / diagnostics验证层precision/recall、loop closure、junction F1、feature drift/Hausdorff envelope。只看 feature 数量会掩盖误连、断裂和漂移。

B.7 调试特征识别时按这个顺序看

  1. 先看 edge evidence：boundary_feature_edges、dihedral_feature_edges、normal_tensor_feature_edges 是否符合预期。若二面角浅特征没出现，先调 featureAngleDeg；若 tensor 弱特征泛滥，先提高 normalTensorThreshold 或 normalTensorMinPersistentScales。
  2. 再看 trace / cleanup：graphCleanupBridgedGaps、graphCleanupRemovedSpurs、graphCleanupMergedJunctions 是否过高。过高说明原始证据破碎或阈值太宽。
  3. 再看 component：weakFeatureComponents、highConfidenceFeatureComponents、meanFeatureComponentConfidence 能告诉你弱证据是否真的形成稳定结构。
  4. 再看 primitive：circle/ellipse loop 数、radial residual、plane residual 和 loop closure rate 决定特征是否可被 hard budget 保护。
  5. 必要时看 HTML 线框：若 report 已经指出是哪类边异常，但 STL 里难以定位，可临时启用 MANUMESH_ENABLE_DEBUG_UTIL，用 MANUMESH_DEBUG_UTIL_FEATURES 或 MANUMESH_DEBUG_UTIL_EDGES 生成可旋转的 HTML 辅助页。
  6. 最后看 simplify rejection：如果检测正确但 featureRejectedCollapses 极高，问题在保护策略或目标 ratio；如果检测阶段就没有 loop，问题在 evidence/cleanup/primitive。
debugUtil 不是验收工具

src/debugUtil 只在 Debug + MANUMESH_ENABLE_DEBUG_UTIL=ON + 非 NDEBUG 时输出 HTML。它适合定位 edge evidence、loop tracing 或 collapse candidate 的空间位置；正式结论仍应回到 feature-report、metrics CSV、CTest 和输出 STL/OBJ。

B.10 下一轮算法改进应该怎样落到代码和测试

如果继续增强特征识别，优先级应按“可度量、可回归、可解释”排序。第一批不建议直接替换成 neural detector，而是让当前几何管线的弱点可观测。

  1. 补 ground-truth benchmark：给典型 CAD 零件、浅 ridge、破碎圆孔、非均匀采样模型加 edge labels，输出 precision/recall、loop closure rate、junction correctness、primitive residual、feature drift/Hausdorff envelope。
  2. 把弱特征 confidence 做成 component policy：同一个 component 内根据 strong evidence ratio、tensor persistence、closure 和 residual 决定 soft cost、hard guard 或 diagnostic-only；不要用一个全局开关影响所有圆孔 fallback。
  3. gap closure 使用局部尺度和方向双约束：gap 阈值按局部平均边长归一化，桥接前检查端点 tangent、曲率变化和 bridge 后的 closure 改善量。
  4. primitive fitting 引入失败解释：圆/椭圆失败时记录是 non-planar、vertex count 不足、radial residual 大，还是 junction 破坏排序，这样 feature-report 能告诉用户下一步该调哪个参数。
  5. QEM 侧做二轮 feature relocation 实验：第一轮 collapse 保守保护，第二轮只在 high-confidence primitive/component 附近做小范围投影修正，对照 M001/M026/M033 的二阶段和弱特征思想。

A.6 Normal Tensor 的直观解释

Normal tensor 把一个顶点附近的面法向看成一堆投票。每个面法向 $n_f$ 贡献 $n_fn_f^\top$。如果邻域是一块平面，所有法向几乎相同，张量只有一个主方向强；如果邻域跨过折痕，法向分成两簇，第二个特征值会变强；如果是角点，三个方向都可能有能量。

局部形状特征值表现ManuMesh 解释
平滑面片$\lambda_0$ 强，$\lambda_1,\lambda_2$ 弱surfaceSaliency 高，不应作为 crease
折痕附近$\lambda_0$、$\lambda_1$ 有区分度creaseSaliency 高，可作为 normal-tensor feature edge
角点/ junction$\lambda_2$ 也明显cornerSaliency 高，但当前 edge 接受会避免把 corner 当作普通 crease 乱连

当前实现比单尺度张量多做了三件事：

  • 局部尺度归一化：平滑半径使用 computeVertexAverageEdgeLength()，避免不同采样密度下同一个参数含义完全不同。
  • 多尺度 persistence：同一个顶点如果在多个 smoothing scale 下都高分，说明它更像稳定特征而不是局部噪声。
  • edge alignment：即使两个端点分数高，边方向还要和 crease tangent 对齐，避免把离散点状响应误连成线。

A.7 Feature graph cleanup：为什么要修图再拟合 primitive

特征检测第一步得到的是一堆边，不一定是干净曲线。真实 STL 中常见三类问题：短断裂、噪声 spur、junction 附近重复/错位。直接拿这样的图去拟合圆或椭圆，可能漏掉本来很清楚的孔边界，也可能把噪声边当作特征保护。FeatureGraphCleanup.cpp 的角色就是把 edge evidence 转成更像“可用特征曲线”的图。

cleanup 动作做什么为什么安全性可控诊断字段
短 gap 桥接把两个相近 endpoint 用 cleanup bridge 连起来距离阈值按局部平均边长缩放，不用全局绝对长度graphCleanupBridgedGaps
弱 spur 删除删除很短的 tensor-only 小枝只删没有 boundary/dihedral/non-manifold 支持的弱边graphCleanupRemovedSpurs

A.8 Component confidence：弱特征怎么变成 QEM 能消费的数

ManuMesh 不再把每条特征边同等硬锁。当前会先按连通分量统计支持强度，再把 confidence 写回 loop 和 vertex。这个 confidence 被 QEM feature-curve soft quadric 消费，强 CAD loop 权重更接近用户设置，弱 tensor support 权重更柔和。

$$confidence \approx 0.45\cdot evidence + 0.25\cdot closure + 0.20\cdot residual + 0.10\cdot tensor - junctionPenalty$$

A.9 Primitive loop fitting：为什么圆孔能被保护

圆孔、椭圆孔和近圆孔在工业 STL 中非常常见。若只用 generic feature edge，简化器可能仍然沿孔边界做一些形状可接受但制造语义不好的塌缩。Primitive fitting 的目的不是恢复完整 CAD 草图，而是让简化器知道“这圈点应该继续贴近一个圆或椭圆”。

trace graph component
  -> ordered loop vertices
  -> fit plane
  -> project vertices into local 2D coordinates
  -> fit circle / ellipse
  -> compute radial and plane residuals
  -> assign tangent and primitive data to VertexFeature

塌缩时如果新点属于 primitive feature，程序可以检查它离拟合曲线是否超过 maxFeatureCurveDeviationRatio。这样 QEM 的 soft cost 和 legality 的 hard budget 是两层保护：soft cost 让队列倾向于别破坏曲线，hard budget 则防止已经选中的塌缩真的把曲线拉坏。

A.10 候选位置怎么求：为什么不是永远用矩阵逆

理论上，边 $(u,v)$ 的最优点由 $Q_u+Q_v$ 的二次函数最小值给出。把齐次 quadric 写成：

$$Q=\begin{bmatrix}A & b\\ b^\top & c\end{bmatrix},\quad E(x)=x^\top A x+2b^\top x+c$$

对 $x$ 求导得到 $Ax=-b$。如果 $A$ 条件良好，可以直接解；如果 $A$ 病态或奇异，强行求逆会把点扔到很远的位置。当前程序因此会准备多个 placement candidates：端点 $u$、端点 $v$、中点 $(u+v)/2$，以及可解时的最优点，然后选代价最低且合法的候选。

候选好处坏处
端点 $u$ 或 $v$最保守，常能保持已有顶点位置可能产生不均匀采样
中点稳定、简单不一定最贴合原始几何
最优解 $-A^{-1}b$数学上最小化 quadric cost在秩亏或病态时可能漂移

A.11 Legality gates：为什么最低代价边也会被拒绝

QEM 只回答“几何误差小不小”，不回答“拓扑是不是坏了”“边界是不是合并了”“三角形是不是翻了”。ManuMesh 现在把这些检查作为执行塌缩前的硬闸门。

A.12 DynamicTopology：为什么不能每步重建邻接

最朴素的做法是每塌缩一条边就重新扫描所有面，重建所有边表。这在几千面模型上还能忍，在 10w 面模型上会很慢。DynamicTopology 的思路是：塌缩只影响局部，所以只更新受影响顶点和面。

collapse(u, v -> kept):
    affected_faces = incident_faces[u] union incident_faces[v]
    mark faces containing both u and v as inactive
    replace removed vertex id by kept vertex id in affected faces
    remove degenerate duplicate faces
    update incident face lists for local vertices
    recompute candidates only around the changed one-ring

这也是为什么 SimplifyReport 里会有大量 reject counters：算法不是一次性全局优化，而是局部队列不断尝试。一个候选被拒绝并不等于程序失败，它只是说明某条边在当前拓扑和参数下不能安全塌缩。

  1. 是否达到目标：termination_reason、输出 faces 是否接近 target。
  2. 是不是拓扑/质量拦住了：topology_rejected、quality_rejected、normal_flip_rejected。
  3. 是不是特征保护过强：feature_rejected、primitive_feature_rejected、generic_feature_rejected。
  4. 特征识别本身是否可信：feature_components、weak_feature_components、mean_feature_component_confidence、graph_cleanup_*。

A.15 当前算法和文献路线的关系

本地文献库建议的顺序是：先做确定性几何 baseline，再做弱特征 consolidation 和 benchmark，最后再考虑 neural/wireframe。当前代码正处在第二阶段：已经不只是 standard QEM，也还没有把 neural edge fields 当作默认核心。

文献路线当前状态为什么不是一步到位
Garland-Heckbert QEM已实现，是 cost backbone经典、快速、可解释
Line Quadrics已实现，用小权重做正则直接补 QEM 平坦区弱约束
CAD feature-line extraction已实现几何工程版：dihedral/boundary/trace/primitive适合 STL/OBJ 输入，没有依赖 B-Rep
Normal tensor / voting已实现多尺度弱特征证据作为补充通道，不替代硬 CAD evidence
CWF 弱特征 consolidation部分实现：component confidence 和 cleanup完整 CWF 需要更多 benchmark 和 relocation
Neural edge / wireframe未作为默认核心需要训练分布、标签、OOD 验证；更适合后续离线对照

A.18 最重要的理解：QEM 不是裁判，QEM 只是候选排序器

这是读完整个程序最关键的一点。QEM/line quadrics 会告诉我们哪个塌缩候选“代价低”，但它不会知道 CAD 孔是否有语义，也不会知道三角形是否翻面，更不会证明全局 Hausdorff envelope。ManuMesh 的工程路线是把 QEM 放在候选排序层，把 feature graph 和 legality guards 放在决策层，把 metrics/benchmark 放在验证层。

ranking layer:     plane QEM + line quadrics + feature curve quadrics
semantic layer:    FeatureAnalysis + FeatureComponent confidence
legality layer:    feature/boundary/topology/normal/quality/error/intersection gates
validation layer:  metrics CSV + feature-report + feature-benchmark + ctest

12当前收益、边界和下一步

12.1 当前收益

  • 标准 QEM 仍然保留，便于对比。
  • Line quadrics 解决了平坦区域切向漂移和病态求解的一部分问题。
  • Feature curve 机制让圆孔、硬边、连续线结构可以被显式识别和报告。
  • Link condition 把拓扑合法性变成硬约束，避免闭合二流形简化出坏几何。
  • DynamicTopology 把大模型运行时间从分钟级拉回秒级。
  • 局部几何误差、三角形质量、normal flip、局部自交和 per-loop 曲线预算让坍缩拒绝原因可审计。
  • FeatureGraph 明确表达复杂 loop、junction、共享顶点和多特征归属，不再只依赖单个连通分量。
  • 多尺度 normal tensor 作为 dihedral 之外的弱特征候选，有助于暴露非均匀采样和噪声敏感性。

12.2 当前边界

  • normal tensor 已经接入多尺度评分，但阈值仍需要更多真实工业数据校准。
  • hard feature / industrial-safe 模式仍然可能过保守，尤其是 Casting 这类密集工业特征模型。
  • 局部 tolerance guard 比 sampled distance 更早介入，但还不是严格 Hausdorff envelope。
  • 当前 DynamicTopology 是 simplifier 内部结构，后续应逐步和公共 MeshTopology / 半边结构统一。

12.3 下一步建议

  1. 把 legality policy 显式模块化：拓扑、翻面、三角形质量、自交分别作为可组合检查。
  2. 把 feature hard-lock 改成分级策略：圆形 loop、长硬边、短噪声边使用不同保护强度。
  3. 实现 normal tensor 或 normal voting 风格的特征评分，用于替代单一 dihedral threshold。
  4. 在 10 个大模型验证集上固定 nightly/CI 风格的 topology delta 检查。
  5. 把当前内部 DynamicTopology 演进成面向 repair、boolean、remesh 都可复用的 editable topology。
最终结论

当前程序的改进方向是有明确依据的：QEM 来自经典误差度量，line quadrics 补充切向约束，normal tensor/feature-line 文献提醒我们特征应作为曲线结构处理，CGAL/OpenMesh 风格的 legality-first 思路保证不生成坏拓扑，增量邻接则让这些严格检查在 10w 面模型上仍然可运行。
