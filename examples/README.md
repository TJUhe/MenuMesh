# Examples Layout

Small source-level examples for using the library.

| Path | Purpose |
| --- | --- |
| `basic_simplify.cpp` | Minimal C++ API example. |
| `c_api_basic.c` | Minimal C API example. |
| `CMakeLists.txt` | Example build integration. |

This directory should stay source-only. Demo outputs belong under `output/`.
Validation inputs belong under `tests/data/`; validation outputs belong under
`tests/output/`.
