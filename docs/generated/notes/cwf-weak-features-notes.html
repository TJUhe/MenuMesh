1论文主要讲了什么

这篇论文关注一个很具体、但在网格简化里很难的问题：简化后既要几何误差小，又要三角形质量高，还要让强特征和弱特征对齐。传统方法经常只能偏向其中一两项。

QEM 的长处和短处

QEM 根据局部平面距离评估 collapse 或顶点移动，强在几何保真，也能自然吸住硬边和角点。但它不直接优化三角形质量，而且弱特征如果没有足够大的二面角，很容易被简化过程磨平。

CVT 的长处和短处

CVT 通过移动采样点，让点分布更均匀，生成的三角形通常质量更好。但标准 CVT 并不知道哪里是特征线，可能把点均匀地铺开，而不是沿着弱脊线或过渡线聚拢。

CWF 的核心就是把这两种力量合到一个目标函数里：用 normal anisotropy 项继承 QEM 的特征对齐能力，用 CVT 项保持均匀采样，再用一个逐步衰减的权重自动调平两者。

一句话版

CWF 不是先检测特征再保护特征，而是让优化过程自己把采样点拉向强/弱特征，同时维持尽量好的三角形质量。

2它和当前程序的关系

当前仓库的核心是 edge-collapse 风格的 QEM / line quadrics。CWF 则更像“点集重采样 + RVD + 连续优化 + 对偶三角化”。所以它不是当前代码的一个小参数，而是另一类简化框架。

不要混淆

当前程序可以做“受 CWF 启发的演示”，例如弱特征评分、权重调度、质量-特征对照实验；但如果要完整复现 CWF，需要实现 RVD、数值积分、L-BFGS、RVD 对偶网格生成，这会是一条新的算法管线。

3CWF 算法流程

1. 初始化点集在输入曲面 $S$ 上放置目标数量的 movable sites：$\{x_i\}_{i=1}^{N}$。
2. 曲面分解根据 sites 计算 Restricted Voronoi Diagram，得到每个点控制的区域 $\Omega_i$。
3. 积分求能量对每个 $\Omega_i$ 上的多边形做数值积分，计算 $E_{NA}$ 和 $E_{CVT}$。
4. 优化点位置用 L-BFGS 最小化总能量，移动 sites 使它们更均匀并贴近特征。
5. 生成网格取 RVD 的对偶生成简化三角网格；每轮降低 CVT 权重。

这个流程的关键是“点的位置”和“点之间的连接”被解耦了。先只优化点在曲面上的位置，再从 RVD 的对偶关系生成三角网格。

4总目标函数

论文把目标函数写成两项：

$$E(\{x_i\}_{i=1}^{N})=\lambda_{NA}E_{NA}+\lambda_{CVT}E_{CVT}$$ (1)

其中：

  • $E_{NA}$ 是 normal anisotropy 项，主要负责几何保真和特征对齐。
  • $E_{CVT}$ 是 CVT 项，主要负责均匀点分布和三角形质量。
  • $\lambda_{NA}$ 在优化过程中保持不变。
  • $\lambda_{CVT}$ 会逐轮衰减，让优化从“先铺匀点”逐渐转向“对齐特征”。
为什么只两项就够

论文的设计很漂亮：它没有把“弱特征”作为显式标签输入，而是通过 normal anisotropy 的能量地形，让位于特征附近的点自然被拉向点、线或角点。

5Normal Anisotropy 项推导

对每个 site $x_i$，它控制一个曲面区域 $\Omega_i$。对区域里的任意曲面点 $x$，记该点法向为 $n_x$。normal anisotropy 项定义为：

$$E_{NA}=\sum_i\int_{\Omega_i}\left((x-x_i)^T n_x\right)^2\,ds$$ (2)

把平方项写成二次型：

$$\left((x-x_i)^T n_x\right)^2=(x-x_i)^T n_x n_x^T (x-x_i)$$ (3)

因此：

$$E_{NA}=\sum_i\int_{\Omega_i}(x-x_i)^T M_{NA}(x)(x-x_i)\,ds,\qquad M_{NA}(x)=n_xn_x^T$$ (4)

5.1 和 QEM 的关系

QEM 的基本项是点到平面的平方距离。如果平面法向为 $n$，平面上一点为 $p$，则：

$$d^2=(n^T(y-p))^2=(y-p)^Tnn^T(y-p)$$ (5)

可以看到，QEM 的局部平面误差和 CWF 的 normal anisotropy 用的是同一个核心矩阵 $nn^T$。区别在于：

方法误差被谁评估积分/求和范围
QEMcollapse 后的新顶点 $y$边端点邻接三角面
CWF normal anisotropymovable site $x_i$RVD 区域 $\Omega_i$ 上的连续曲面点

所以可以把 CWF 的 $E_{NA}$ 理解为“区域化、连续化的 QEM”。这也是它能保几何、吸特征的根源。

5.2 固定区域时的最小化

先暂时假设 $\Omega_i$ 不随 $x_i$ 变化，并且矩阵 $M(x)$ 已知。单个 cell 的能量是：

$$E_i(x_i)=\int_{\Omega_i}(x-x_i)^TM(x)(x-x_i)\,ds$$ (6)

展开：

$$E_i=x_i^T\left(\int_{\Omega_i}M\,ds\right)x_i-2x_i^T\left(\int_{\Omega_i}Mx\,ds\right)+\int_{\Omega_i}x^TMx\,ds$$ (7)

对 $x_i$ 求导：

$$\nabla_{x_i}E_i=2\left(\int_{\Omega_i}M\,ds\right)x_i-2\int_{\Omega_i}Mx\,ds$$ (8)

令梯度为零，得到固定 cell 下的最优点：

$$x_i^*=\left(\int_{\Omega_i}M\,ds\right)^{-1}\left(\int_{\Omega_i}Mx\,ds\right)$$ (9)

这条式子很有用：如果 $M=I$，它就是普通质心；如果 $M=n_xn_x^T$，它会偏向让 site 靠近局部平面、折线或角点。

6CVT 项推导

CVT 项写成：

$$E_{CVT}=\sum_{i=1}^{N}\int_{\Omega_i}(x-x_i)^TM_{CVT}(x-x_i)\,ds$$ (10)

最常见选择是 $M_{CVT}=I$，此时它就是点到 site 的欧氏平方距离积分：

$$E_{CVT}=\sum_i\int_{\Omega_i}\|x-x_i\|^2\,ds$$ (11)

固定 $\Omega_i$ 时，对 $x_i$ 求导：

$$\nabla_{x_i}E_{CVT}=\int_{\Omega_i}-2M_{CVT}(x-x_i)\,ds$$ (12)

当 $M_{CVT}=I$，令梯度为零得到：

$$x_i^*=\frac{\int_{\Omega_i}x\,ds}{\int_{\Omega_i}1\,ds}$$ (13)

这就是 cell 的曲面质心。CVT 的本质是让每个 site 回到自己 Voronoi 区域的质心，因此点会趋于均匀铺开。

7统一核矩阵

论文把两个能量项统一写成一个核矩阵：

$$E(\{x_i\})=\sum_i\int_{\Omega_i}(x-x_i)^TM(x)(x-x_i)\,ds$$ (14)
$$M(x)=\lambda_{NA}M_{NA}(x)+\lambda_{CVT}M_{CVT}$$ (15)

其中：

$$M_{NA}(x)=n_xn_x^T$$ (16)

如果 $M_{CVT}=I$，则：

$$M(x)=\lambda_{NA}n_xn_x^T+\lambda_{CVT}I$$ (17)
几何解释

$n_xn_x^T$ 只惩罚法向方向的偏离，像 QEM；$I$ 惩罚所有方向的偏离，像普通 CVT。两者合起来，就是“既靠近原曲面，又不要让点分布坏掉”。

7.1 和 line quadrics 的互补关系

当前程序里的 line quadric 使用的是点到法线方向直线的距离。它的投影矩阵是：

$$P_n=I-nn^T$$ (18)

这恰好与 CWF 的 $nn^T$ 互补：

$$nn^T+(I-nn^T)=I$$ (19)

QEM / CWF NA法向方向不要离开原曲面；靠近特征线交汇处
Line Quadric切向方向不要在平面内乱滑；改善采样均匀性

8梯度与 L-BFGS

论文使用 L-BFGS 最小化目标函数。CVT 项的梯度相对直接：

$$\nabla_{x_i}E_{CVT}=\int_{\Omega_i}-2M_{CVT}(x-x_i)\,ds$$ (20)

normal anisotropy 项更复杂，因为 $\Omega_i$ 本身依赖 sites，移动 $x_i$ 会改变 RVD 边界。完整推导会出现区域内部项和 cell 边界项：

$$\nabla_{x_i}E_{NA}=\int_{\Omega_i}-2((x-x_i)\cdot n_x)n_x\,ds+\text{boundary terms}$$ (21)

论文观察到后面的边界项相对较小，因此实际优化中采用近似：

$$\nabla_{x_i}E_{NA}\approx\int_{\Omega_i}-2((x-x_i)\cdot n_x)n_x\,ds$$ (22)

合并两项后：

$$\nabla_{x_i}E\approx \lambda_{NA}\int_{\Omega_i}-2((x-x_i)\cdot n_x)n_x\,ds +\lambda_{CVT}\int_{\Omega_i}-2M_{CVT}(x-x_i)\,ds$$ (23)

8.1 数值积分

RVD 的每个 cell 由曲面上的若干凸多边形组成。论文把每个 $k$ 边形分成 $k-2$ 个三角形，然后使用 Albrecht-Collatz quadrature，在每个三角形上取 6 个积分点近似积分。

$$\int_{\Omega_i}f(x)\,ds\approx\sum_{T\subset\Omega_i}\sum_{q=1}^{6}w_q\,A_T\,f(x_q)$$ (24)

这一步是完整 CWF 和当前 edge-collapse QEM 差异最大的地方：当前程序没有 RVD，也没有区域积分。

9衰减权重与停止条件

论文指出，$E_{NA}$ 和 $E_{CVT}$ 的数量级可能差很多。CAD 模型中，$E_{NA}$ 甚至可以接近 0；如果 $E_{CVT}$ 一直很强，就可能阻止点真正贴到特征上。

因此论文固定 $\lambda_{NA}$，让 $\lambda_{CVT}$ 逐轮衰减：

$$\lambda_{CVT}^{(k)}=\lambda_{CVT}^{(k-1)}\tau,\qquad \tau=0.95$$ (25)

直观上：

早期CVT 权重大，先把采样点铺匀，避免糟糕三角形。
中期两项竞争，点分布仍稳定，同时开始向特征移动。
后期CVT 权重变小，normal anisotropy 更能把点拉到弱特征上。

10为什么它能巩固弱特征

先看强特征。若一个 cell 横跨两张平面，法向分别为 $n_1,n_2$，忽略 CVT 项时有：

$$E_i(x_i)\approx \int_{\Omega_i^1}((x-x_i)^Tn_1)^2ds+\int_{\Omega_i^2}((x-x_i)^Tn_2)^2ds$$ (28)

这等价于让 $x_i$ 同时靠近两张平面。两张平面的交线就是能量低谷，所以点会向特征线移动。

能量图像：

单平面只有一个法向约束，切向自由；两平面相交时，两个法向约束共同作用，最低能量区域变成两平面的交线；三组法向相交时，最低区域变成角点。

弱特征没有明显的硬折角，但在较大范围内存在持续的法向变化。normal anisotropy 不是只看一条边的二面角，而是积分整个 $\Omega_i$ 内的法向矩阵：

$$A_i=\int_{\Omega_i}n_xn_x^T\,ds$$ (29)

当一个区域覆盖弱脊线两侧，$A_i$ 会记录这种跨区域的法向分布，优化点会向能同时降低多侧法向误差的位置移动。这个位置往往就是弱特征附近。

和二面角检测的差别

二面角方法问的是“这条边两侧法向差是否超过阈值”；CWF 问的是“这个区域里哪个 site 位置能同时解释所有法向变化”。前者容易漏掉缓变弱特征，后者更适合捕捉大尺度的柔和结构。

11当前程序可以增加什么

完整 CWF 是一条新管线，但当前程序已经有 QEM、line quadrics、曲线特征约束和验证指标。最现实的做法是先加一个 CWF-inspired 实验层。

11.1 增加弱特征评分

可以为每个顶点计算一个 normal-variation score，而不是只用二面角阈值：

$$C_i=\sum_{f\in N(i)}A_f\,n_fn_f^T$$ (30)

对 $C_i$ 做特征值分解，设 $\sigma_1\ge\sigma_2\ge\sigma_3$。一种简单弱特征分数可以是：

$$s_i=\frac{\sigma_2}{\sigma_1+\epsilon}$$ (31)

强平面区域 $\sigma_2$ 很小；折线或弱脊线附近，法向分布有第二主方向，$s_i$ 会变大。

11.2 增加动态权重调度

当前程序已有 `lineWeight`、`featureBoost`、`featureCurveWeight`。可以模仿 CWF 的衰减思想，建立随 collapse 进度变化的权重：

$$w_{quality}(t)=w_{quality}^{0}\tau^t,\qquad w_{feature}(t)=w_{feature}^{0}\left(1-\tau^t\right)$$ (32)

前期更重采样质量，后期更重特征保护。这不等价于 CWF，但可以做出同样的“先铺匀、再对齐”演示逻辑。

11.3 增加弱特征验证模型

现有 `ridge`、`terrace`、`bump`、`flange` 适合继续扩展。建议新增：

  • `soft-ridge`：低二面角、宽过渡的弱脊线。
  • `shallow-groove`：浅槽，普通二面角阈值容易漏。
  • `mobius-band` 或 `smooth-twist`：类似论文里 Mobius-ring 的柔和结构。
  • `weak-flange-fillet`：圆孔和倒角混合，测试强/弱特征同时存在。

11.4 增加新的 CLI 演示命令

linequadrics validate-weak-features --ratio 0.20 --n 96 --samples 1000

linequadrics simplify input.stl output.stl ^
  --method line ^
  --weak-feature-mode normal-anisotropy ^
  --weak-feature-boost 0.04 ^
  --weight-schedule cwf-decay ^
  --quality-weight 0.05 ^
  --quality-decay 0.95

这组命令可以明确告诉读者：当前程序不是完整 CWF，而是在 QEM/line-quadrics 框架内吸收 CWF 的弱特征与权重调度思想。

Feature Protection Roadmap

The latest external-model probe shows that --preserve-feature-curves can over-protect fragmented industrial STL feature graphs such as CubeSat, Mars wheel, and differential gear. The mesh topology counters stay clean; the main problem is an overly hard feature policy.

The next implementation should follow CGAL Surface Mesh Simplification, OpenMesh Decimater, MeshLab/VCG quadric decimation, and CWF weak-feature simplification patterns: keep QEM/line quadrics as candidate costs, then separate topology, normal deviation, triangle quality, feature placement, envelope/tolerance, and feature ownership into independent policies.

  • Add FeatureProtectionMode: none, primitive-curves, circular-only, and all-feature-edges.
  • Hard-protect only primitive curves by default: circle, near-circle, and ellipse.
  • Move generic polygonal and dihedral creases to soft cost, normal guard, and placement/envelope filters.
  • Add multi-loop ownership for dense CAD/STL feature graphs.
  • Keep validation honest by reporting rejection-limit, feature rejected collapses, projection count, target-face miss, and feature-compare recall.
