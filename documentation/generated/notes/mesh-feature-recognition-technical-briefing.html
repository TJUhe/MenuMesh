三角表面网格特征识别

从离散边证据、多尺度微分证据到特征图、闭环、几何基元与表面分片的完整实现原理

适用对象工程管理、算法评审、技术决策
分析范围三角形表面网格，不含实体与特征树
复核日期2026-07-16

汇报结论

该实现不是单一“角度阈值”检测器，而是一条确定性的分层流水线。它先以边界、非流形和有向二面角建立高可信离散证据，再以法向张量和三次 Monge 曲面拟合补充弱折痕、光滑脊线与谷线；随后把局部响应组织成可追踪的图，执行去毛刺、断点桥接、闭环恢复、圆/椭圆拟合、组件置信度计算，并可把特征边作为屏障进行面片分割。

  • 核心目标：输出可供简化、保护、分片和质量评估直接消费的显式特征图，而非仅输出逐点分数。
  • 主路径：边界、非流形、二面角是默认强证据；法向张量默认启用，光滑曲率通道默认关闭。
  • 稳定机制：局部尺度归一化、多尺度持久性、符号一致性、切向一致性和图级连续性共同抑制噪声。
  • 工程边界：结果受三角剖分方向、局部采样密度、绕序一致性与阈值配置影响；不等同于 CAD 实体特征恢复。

01对象、输入与输出

算法处理的是带顶点坐标与三角面片索引的二维流形或近似流形表面。它识别的是网格上的几何不连续、微分极值和可组织的曲线结构，不推断孔、倒角、口袋等制造语义。

M = (V, F),   V = {pi ∈ ℝ³},   F = {(i, j, k)} 输入要求：坐标有限、面索引合法、同一三角面不重复顶点索引。零面积面被容忍并计数，但不贡献可靠的法向证据。

02九阶段执行流程

每次分析先验证参数和输入，再构造共享几何缓存。之后九个阶段按固定顺序执行；网格、邻接、法向与局部尺度在同一次运行中保持一致，候选边按端点编号排序，因此相同输入与参数得到确定性结果。

阶段执行内容关键产物或约束
1汇集边证据五类来源：边界、二面角、非流形、法向张量、光滑曲率
2退化证据降级移除零面积面邻边上无意义的二面角证据
3初始化特征图把候选边变为带来源标签的图边并建立邻接
4局部图清理删除弱毛刺，桥接短缺口，合并过近交汇点
5组件整合可选地连接不同组件中相容的端点
6曲线与闭环恢复追踪链、恢复小环/圆环，并进行基元约束验证
7组件汇总计算闭合率、证据统计、拟合残差和置信度
8图角色定稿确定端点、拓扑交汇点、共享顶点和分支配对
9表面分片可选地以有效特征边为屏障对面进行洪泛分区
参数验证 → 输入验证 → 共享缓存 → 证据 → 退化降级 → 图初始化 → 图清理 → 组件整合 → 曲线恢复 → 组件汇总 → 图角色定稿 → 可选分片

03离散强特征证据

强证据只依赖网格边的面关联关系和相邻面法向。它们对干净 CAD/STL 网格最直接，也是默认检测路径的主体。

3.1 边的拓扑分类

type(e) = { boundary,   |F(e)| = 1;
  manifold interior,   |F(e)| = 2;
  non-manifold,   |F(e)| > 2 } 边界边和非流形边直接进入候选集；只有恰好邻接两个面的内部边需要计算二面角。

3.2 绕序协调与有向二面角

三角面输入可能整体朝向不一致。实现先在双面邻接图上做广度优先遍历，为每个面求一个翻转符号 sf ∈ {−1,+1}，使共享边两侧的方向尽量相反。协调后的法向内积为：

d = clamp((n0 · n1) s0s1, −1, 1),   θ = arccos(d) 式 3-1 当 θ ≥ θfeature 时，内部边被标记为二面角特征。默认阈值 θfeature = 40°。

若边方向有效且两侧绕序一致，以协调后的单位边方向 u 计算：

q = ((s0n0) × (s1n1)) · u,   signedKind = sign(q) 式 3-2 实现把正、负分别记录为两种有向折痕类别；|q| ≤ 10−12 时符号未知。

3.3 绕序冲突时的降级

如果共享边在协调后仍呈相同方向，算法不再输出凸/凹符号，而把强度降级为无向法向夹角：

θfallback = arccos(|d|),   signedKind = 0 式 3-3 这会把角度折叠到 [0°, 90°]。它能避免错误绕序制造虚假符号，但无法保留大于 90° 的原始夹角信息。

3.4 退化面处理

零面积面法向为零，与正常面点乘会产生伪 90° 折痕。证据汇集后，第二阶段会删除与退化面相邻内部边上的二面角标志；若该边没有其他来源，则整条候选边被移除。边界和非流形证据属于拓扑证据，不因法向退化而删除。

源码依据：src/common/MeshQueries.cpp:73-163；src/feature_detection/FeatureEvidence.cpp:132-149, 295-335；src/feature_detection/FeatureDetector.cpp:189-256。

04可选法向预处理

预处理只更新本次分析缓存中的面法向，不移动顶点，也不修改拓扑。目标是在噪声区域平滑法向，同时阻止强不连续两侧相互平均。

4.1 角度相容权

φij = arccos(clamp(ni · nj, −1, 1))
gij = exp[−½(φij/σ)2],   φij < φkeep
gij = 0,   φij ≥ φkeep 式 4-1 默认 σ = 20°，保护角 φkeep = 50°。超过保护角的相邻面不交换平滑支持。

4.2 面积加权松弛

wij = gij √(AiAj)
mi = normalize[(Aini + Σjwijnj) /(Ai + Σjwij)]
n′i = normalize[(1−ρ)ni + ρmi] 式 4-2 ρ ∈ [0,1] 为松弛系数，默认 0.8；默认执行 4 轮，但整个预处理默认关闭。
作用范围：过滤后的面法向直接影响二面角计算，并通过面积加权顶点法向影响光滑曲率拟合的局部坐标系；法向张量通道在当前实现中重新由原始三角形几何计算法向，因此不受该过滤器影响。

源码依据：src/feature_detection/FeatureNormalFilter.cpp:38-195；src/feature_detection/NormalTensor.cpp:62-78；src/feature_detection/SmoothCurvature.cpp:108-130, 610-640。

05多尺度法向张量

法向张量把一个顶点周围多个面法向的分布压缩成 3×3 对称矩阵。特征值谱用于区分近似平面、折痕和多方向交汇；多尺度投票用于抑制只在单一邻域出现的响应。

5.1 面积加权张量

Tv = [Σf∋v Af nfnfT] / [Σf∋vAf] 式 5-1 退化面满足 Af ≈ 0 或 nf = 0，不进入累加。外积 n nT 对法向正负不敏感。

5.2 空间平滑与尺度推进

T′v = [Tv + Σu∈N(v) exp(−(‖pu−pv‖/rv)2)Tu] / [1 + Σu∈N(v) exp(−(‖pu−pv‖/rv)2)] 式 5-2 rv 由顶点局部平均边长乘以当前尺度倍率得到。每个新尺度都在上一尺度张量上继续平滑。

5.3 特征值谱与方向

令 λ0 ≥ λ1 ≥ λ2 ≥ 0 为张量特征值，e0、e1、e2 为对应特征向量。实际执行语句采用：

Ssurface = max(0, λ0−λ1)
Screase = max(0, λ1−λ2)
Scorner = λ2
S = max(Screase, Scorner) 式 5-3
方向含义：主法向取最大特征值方向 e0；折痕切向取最小特征值方向 e2。部分接口注释仍写“中间特征方向”，但源码实际使用最小特征值对应列，汇报与验收应以执行代码为准。

5.4 跨尺度持久分数

设总尺度数为 K，单尺度分数为 Sk，阈值为 τT；令 m 为满足 Sk ≥ τT 的尺度数，Smax 为最大单尺度分数，S̄ 为所有尺度分数均值：

PT = (0.65 Smax + 0.35 S̄) · (m/K) 式 5-4

5.5 从顶点响应到网格边

内部边 e=(a,b) 只有同时通过以下门控，才被标记为法向张量弱特征：

1. e 不是边界、二面角或非流形强特征； 2. a、b 均未被离散强特征顶点掩码覆盖； 3. min(mₐ, mᵦ) ≥ 配置的最少持久尺度数； 4. min(Pₜ,ₐ, Pₜ,ᵦ) ≥ τₜ； 5. 两端均满足 Screase ≥ Scorner； 6. max(|ê·tₐ|, |ê·tᵦ|) ≥ αₜ。

其中 ê 为单位边方向，t 为张量折痕切向。注意第 6 条使用两端对齐度的最大值，即只要求至少一端与网格边充分对齐；默认 αT=0.45。

源码依据：src/feature_detection/NormalTensor.cpp:27-151；src/feature_detection/FeatureEvidence.cpp:183-233。

06光滑曲率特征

该通道面向没有明显折角、但存在脊线或谷线的光滑表面。它在多个 k-ring 邻域中拟合带三次项的局部 Monge 曲面，由二次项求主曲率，由三次项求曲率沿主方向的变化，再通过零交叉、主曲率占优、显著性与跨尺度一致性完成筛选。该通道默认关闭。

6.1 局部尺度与 Monge 坐标

对顶点 v 和当前 ring 数 h，先取局部半径：

r = max(ℓ̄v · h, 10−12)
u = Δp·eu/r,   v = Δp·ev/r,   z = Δp·n/r 式 6-1 ℓ̄v 是局部平均边长；坐标和高度都除以 r，使曲率分数在网格整体等比缩放后保持稳定。

6.2 九未知量三次拟合

z(u,v) ≈ a u² + b uv + c v² + d u + e v + f u³ + g u²v + h uv² + i v³ 式 6-2 未知量 β=(a,b,c,d,e,f,g,h,i)T 共 9 个，因此有效邻点少于 9 个时直接判定拟合无效。

空间权重为 ωs=exp[−½(u²+v²)]。求解加权正规方程：

(XTWX)β = XTWz 式 6-3 使用 9×9 LDLT 分解；若分解失败、系数非有限，或最小绝对主元不大于 10−13·max(1, 最大主元)，则拒绝该尺度。

6.3 确定性稳健重加权

初次求解后，令残差 εj=xjTβ−zj，以零中心绝对中位数估计尺度：

σ̂ = max(10−8, 1.4826 · median(|ε|)),   c = 1.5σ̂
ωr,j = {1, |εj|≤c;   c/|εj|, |εj|>c}
Wjj = max(10−16, ωs,jωr,j) 式 6-4 配置值表示重加权轮数；默认 2 轮意味着一次初始求解加两次重加权求解。

6.4 第一、第二基本形式与主曲率

由于拟合保留了线性项，不能直接把 Hessian 特征值当作主曲率。实现构造：

I = [[1+d², de], [de, 1+e²]]
nz = 1/√(1+d²+e²)
II = [[2a nz, b nz], [b nz, 2c nz]]
II q = κ I q 式 6-5 广义对称特征问题给出两个主曲率 κ0≤κ1 及其局部主方向。

6.5 曲率极值与脊/谷判定

沿归一化主方向 q=(t1,t2)，三次项给出曲率沿该方向的一阶变化代理：

e(q) = 6[f t1³ + g t1²t2 + h t1t2² + i t2³] 式 6-6

候选必须先满足主曲率占优：

ridge: κ1 > |κ0|,    valley: κ0 < −|κ1| 式 6-7

然后在近似沿该主方向的邻边上寻找 e 的符号翻转。相邻顶点的线场方向先同步正负，邻点 extremality 再按 (rcenter/rneighbor)² 变换到中心尺度。只有以下条件同时满足才接受：

  1. 中心与邻点的 e 异号，表示边上存在零交叉；
  2. 中心 |e| 不大于邻点 |e|，由中心顶点单侧认领交叉，避免生成双顶点宽带；
  3. 脊/谷的一阶最大值方向测试在交叉两端均为正；
  4. 交叉显著性不小于 0.15κ²，以排除球、柱、锥、环面等 Dupin cyclide 上由离散误差制造的伪极值。

6.6 单尺度分数

A = clamp(|κ−κ′|/(|κ|+|κ′|+0.025), 0, 1)
E = clamp(extremum/(|κ|+0.025), 0, 1)
Q = 1/(1+25Rfit)
SC = min(|κ|,4) · √(A E) · Q 式 6-8 κ′ 为另一个主曲率，Rfit 为加权 RMS 拟合残差。特征曲线切向取与极值方向正交的另一主方向。

6.7 跨尺度选择与持久性

一个尺度支持参考候选，当且仅当符号相同、分数不低于 max(τC,0.3Sref)，且切向绝对点积不低于配置阈值。设支持尺度数为 m、平均切向一致性为 ā、支持尺度平均分数为 S̄support：

stability = (m/K) · ā · 1/(1+Rfit)
PC = (0.65Sref + 0.35S̄support) · (m/K) · ā 式 6-9

默认按原始分数选择参考尺度；启用稳定尺度选择后，目标值变为 Sref(0.5+0.5·stability)。

6.8 从顶点候选到曲率边

1. 两端均未落在离散强特征顶点掩码上； 2. min(mₐ, mᵦ) ≥ 配置的最少持久尺度数； 3. min(Pc,ₐ, Pc,ᵦ) ≥ τc； 4. 两端均有非零且相同的 ridge/valley 符号； 5. min(|ê·tₐ|, |ê·tᵦ|) ≥ αc； 6. |tₐ·tᵦ| ≥ βc。

与法向张量通道不同，这里要求两端都与网格边充分对齐。默认 αC=0.55，βC=0.65。

源码依据：src/feature_detection/SmoothCurvature.cpp:182-230, 233-603, 618-725；src/feature_detection/FeatureEvidence.cpp:235-284。

07特征图清理与整合

局部检测给出的是离散边集合。图阶段把它们变成顶点—边拓扑，并以证据类型、符号、距离、切向和局部尺度为约束进行去噪与连续性修复。

7.0 证据边与追踪边并不等价

所有边界、非流形和弱证据边都可进入追踪图；二面角边还要满足单独的追踪角阈值。若追踪角配置为负值，则复用硬特征角：

θtrace = {θfeature, 配置值<0;   配置值, 其他}
trace(e) ⇔ boundary ∨ nonManifold ∨ tensor ∨ curvature ∨ [dihedral ∧ θe≥θtrace] 式 7-0

因此“已检测证据边数”和“被追踪边数”是两个诊断量。追踪角只能从已经通过硬特征角的二面角边中继续筛选；把它设得低于硬特征角，不能补回此前未进入候选集的边。

7.1 弱毛刺删除

只有“纯法向张量或纯光滑曲率”且不含边界、二面角、非流形和恢复桥标签的悬垂链，才属于可删除弱毛刺。默认策略删除边数不超过 2 的弱链。若启用强度阈值，则计算：

Δse = length(e) / [½(ℓa+ℓb)]
qe = max(PT,e/τT, PC,e/τC)
L = ΣΔse,   I = ΣqeΔse,   T = L·I 式 7-1 T 小于阈值才删除。长度因子让“长而弱”的连续曲线比“短而强”的孤立噪点更容易保留。

7.2 端点短缺口桥接

对度数为 1 的两个端点 a、b，首先要求：

‖pa−pb‖ ≤ γ · ½(ℓa+ℓb) 式 7-2

再令 g 为从 a 指向 b 的单位缺口方向，oa、ob 为沿各自链向外的切向，要求：

min(oa·g, ob·(−g)) ≥ 0.5,   oa·ob ≤ 0 式 7-3 即缺口方向与两端延伸方向的夹角均不超过 60°，且两条外向切向不能朝同一侧，避免把平行曲线横向焊接。

证据类型和有向符号也必须相容。候选按“距离 / 平均切向对齐度”排序，每个端点最多参加一次桥接。默认 γ=1.25；端点超过 512 个时跳过本轮并记录诊断。

7.3 交汇点短接

度数大于 2 的节点视为候选交汇点。两个近距离交汇点只有在各自能找到朝向对方、对齐度至少 0.35 且证据相容的分支时才允许合并。候选代价为距离加对齐惩罚；交汇点超过 256 个时跳过。

7.4 可选组件整合

组件整合发生在局部清理之后，只连接不同连通组件的端点。允许距离仍按局部平均边长归一化，候选代价为：

Cbridge = d/dallowed + ½[(1−aL) + (1−aR)] 式 7-4 aL、aR 是两端最佳延续分支与缺口方向的对齐度。该阶段默认关闭，端点上限为 512。
恢复桥的含义：清理桥和组件整合桥属于“图中的推断连接”，不等同于原始网格边证据。它们进入曲线拓扑和组件统计，但不会增加最初的证据边计数。

源码依据：src/feature_detection/FeatureGraphCleanup.cpp:72-243, 246-464；src/feature_detection/FeatureGraphConsolidation.cpp:42-175。

08曲线追踪与闭环恢复

图清理完成后，算法不是简单地把每个连通分量当作一条曲线，而是按固定顺序处理交汇点环、小周期、剩余链、基元组件和圆形顶点簇，以减少交汇点处漏环和同一环重复发布。

顺序恢复器主要目的
1穿越交汇点的圆环恢复利用方向连续性从多分支节点中找圆形闭环
2小周期基恢复从生成树非树边构造基本周期，保留受支持的小环
3剩余链与度 2 环追踪发布开放链、简单闭环和未被前两步消费的路径
4基元组件恢复尝试从整组件中恢复满足拟合约束的闭合基元
5圆形顶点簇恢复在允许的小证据缺口下恢复几何上连续的圆形簇

闭环身份不是按起点顺序定义，而是把环上无向边键排序后形成签名；同一组边只发布一次。恢复周期还要求顶点不重复、边存在、长度达到最小顶点数，并通过对应的圆形或多边形基元验证。

组合恢复采用明确的工作上限：小周期基只处理顶点数不超过 160、边数不超过 240、周期秩不超过 32 的组件，单个周期最多 80 个顶点；圆形顶点簇恢复只处理最多 120 个顶点的组件，每组件三点种子扫描最多 32768 次，并要求角覆盖至少 1.5π、无图支撑的总角隙不超过全圆的 25%。这些上限把最坏情况运行时间转化为可见诊断，而不是无界搜索。

最小顶点数的真实语义：默认值为 8。直接追踪得到的短开放链或短闭环仍可报告；该阈值主要约束恢复周期的接受以及闭环的几何基元拟合，不是“短于 8 个点全部删除”。

一个环中边界证据达到边数的 60% 时标记为“主要边界”。环的凸、凹和未知符号边分别计数，供报告和下游策略使用。

源码依据：src/feature_detection/FeatureLoopRecovery.cpp:18-25；src/feature_detection/FeatureLoopBuilder.cpp:61-81, 156-262。

09圆、椭圆与多边形拟合

闭环达到拟合条件后，先用 PCA 求最佳平面，再在平面内归一化坐标。圆拟合采用 Taubin 方法并以 Kåsa 为降级路径；椭圆采用 Halíř–Flusser 稳定直接最小二乘。最终分类同时看 RMS 与最大误差。

9.1 最佳拟合平面

μ = (1/N)Σpi,   C = Σ(pi−μ)(pi−μ)T 式 9-1 C 最小特征值方向为平面法向；最大特征值方向作为第一个平面轴，第二轴由叉乘得到。

平面坐标以质心为原点，并除以 RMS 半径 s=√mean(x²+y²)，避免椭圆设计矩阵中的四阶项导致尺度病态。

9.2 圆拟合

首选 Taubin 的中心化代数圆拟合。实现由样本矩 Mxx、Myy、Mxy、Mxz、Myz、Mzz 构造特征三次多项式，从 η=0 开始做最多 32 次受保护 Newton 迭代，再恢复圆心与半径。若导数、行列式或半径退化，则降级到 Kåsa 线性最小二乘：

2cxxi + 2cyyi + q ≈ xi² + yi²
r = √(q + cx² + cy²) 式 9-2

9.3 椭圆拟合

在归一化平面坐标中拟合一般二次曲线：

ax² + bxy + cy² + dx + ey + f = 0,   4ac−b² > 0 式 9-3

实现把二次项与线性/常数项分块，求解 3×3 约化特征问题，只接受满足椭圆约束的实特征向量；随后由二次型中心和 2×2 对称特征分解恢复长短轴。若稳定直接拟合失败，则退回 PCA 轴上的二阶矩半径估计。

9.4 误差定义

eplane,i = (pi−c)·n
ecircle,i = ‖(pi−c)−eplane,in‖−r
eellipse,i = [√((xi/a)2+(yi/b)2)−1]√(ab) 式 9-4 每类误差同时计算 RMS 与最大绝对值。椭圆误差是按几何平均半径缩放的隐式径向误差，不是严格欧氏最近点距离。

9.5 分类门控

Rcircle = (RMSradial+RMSplane)/r
Mcircle = max(Maxradial,Maxplane)/r 式 9-5

圆模型要求 Rcircle≤τcircle，且 Mcircle≤max(3τcircle,0.08)。椭圆使用 √(ab) 作尺度并应用同样结构的门控。分类优先级如下：

  1. 圆误差通过且轴比误差极小：圆；
  2. 圆误差通过且轴比接近 1：近圆；
  3. 圆误差通过但轴比偏离，或椭圆误差通过：椭圆/近圆；
  4. 两者均不通过：多边形环。

源码依据：src/feature_detection/PrimitiveFit.cpp:48-121, 132-253, 267-445, 448-553。

10组件置信度

置信度不是统计概率，而是一个 0 到 1 的工程排序分数，用于综合“证据强度、闭合程度、基元拟合、弱证据持久性和交汇复杂度”。

10.1 图拓扑量

对一个连通组件，设顶点数 V、活动边数 E、端点数 d1、交汇点数 J：

μ = E−V+1
closure = {1, d1=0;   max(0,1−0.25d1), d1>0 且 μ>0;   0.5max(0,1−0.25d1), 其他} 式 10-1 μ 是连通图的周期秩。实现中的 closed 标志还要求无端点、E>0 且 μ≥0。

10.2 证据与拟合分数

WT = clamp(mean(PT)/τT,0,1)
WC = clamp(mean(PC)/τC,0,1)
W = max(WT,WC)
Esupport = max(strongEdges/E, 0.8W) 式 10-2
R = clamp(1−meanPrimitiveResidual/0.12,0,1) 若组件没有可用基元残差，R 固定为 0.5，而不是 0。

10.3 最终组合

penaltyJ = {0, J≤2;   min(0.25,0.04(J−2)), J>2}
confidence = clamp(0.45Esupport + 0.25closure + 0.20R + 0.10W − penaltyJ, 0, 1) 式 10-3

默认高置信组件阈值为 0.35。组件若“弱证据来源计数”大于“强证据来源计数”，则标记为弱组件；该标记与置信度阈值是两套不同判断。来源计数按标签累加，同一边若同时带多个弱来源，可能贡献多次，因此不应把弱来源数误读成去重后的边数。

源码依据：src/feature_detection/FeatureGraphCleanup.cpp:466-516, 559-703。

11交汇点与表面分片

11.1 图角色

最终图角色只看未被清理删除的活动边：

endpoint(v) ⇔ degree(v)=1
junction(v) ⇔ degree(v)>2
shared(v) ⇔ |loopIds(v)|>1 式 11-1

“拓扑交汇点”和“被多个恢复环共享的顶点”分开报告。后者在下游保护策略中也可能被固定，但不能因此把所有度数为 2 的共享点称为分支点。

11.2 交汇分支配对

每条分支切向均从交汇点向外。两条分支 i、j 的延续对齐度定义为：

Aij = −ti·tj 式 11-2 Aij≥0.65 且有向类别相容时进入候选。候选按对齐度从高到低贪心配对，每条分支最多使用一次；未配对分支超过 1 条时标记为歧义交汇点。

11.3 特征屏障分片

分片阶段先构造屏障边集合 B。强证据边始终可作为屏障；弱证据边是否作为屏障由配置决定。被清理删除的边不参与。对共享边 e 的两个相邻面 f0、f1：

f0 ↔ f1 可跨越 ⇔ |F(e)|=2 且 e∉B 式 11-3

随后在面邻接图上做广度优先洪泛。每个面片累加面数、面积、面积法向和边界类别；没有网格边界和非流形边界的面片标记为闭合。两个面片之间由多少条有效特征边分隔，也会被记录为面片邻接权重。

边界说明：清理桥与组件整合桥通常不是原始网格边，因此不会成为面洪泛屏障。当前实现的分片目标是“按已有网格特征边切开连通性”，不是解析曲面识别或几何切割。

源码依据：src/feature_detection/FeatureGraph.cpp:217-323；src/feature_detection/FeatureSegmentation.cpp:28-168。

14验证口径

正确性不能只看“线条是否好看”。实现已经提供边、交汇点、分支配对、闭环、组件置信度和面片邻接的量化指标，应按数据来源分层验收。

离散边检测

Precision = TP/(TP+FP)
Recall = TP/(TP+FN)
F1 = 2PR/(P+R)

分别对特征边与交汇点计算，不用单一总准确率掩盖类别不平衡。

图连续性

loopClosureRate = closedLoops / allLoops

同时检查未追踪边、端点数、恢复桥数、歧义交汇点和分支配对 F1。

几何基元

检查圆/椭圆的平面、径向、隐式椭圆 RMS 与最大误差；对简化前后曲线还应比较圆心、半径、法向和方向性曲线误差。

表面分片

使用标注面相邻关系评估 patch adjacency accuracy，并检查网格边界、非流形边界和闭合面片数量。

建议的分层数据集

  1. 解析夹具：平面折角、立方体、圆柱孔、圆环、光滑 bump/ridge，用于验证公式和尺度不变性。
  2. 工程件标注：同轴孔、椭圆孔、凸台与口袋等带边标签和交汇点标签的网格。
  3. 外部模型：不同来源、密度、噪声和绕序质量的 STL/OBJ，用于评估鲁棒性与性能上限。
  4. 下游闭环：特征保护简化前后比较边召回、闭环保持、基元误差和面片邻接，而不是只比较三角形数量。
