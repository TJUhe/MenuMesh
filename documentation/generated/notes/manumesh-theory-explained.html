QEM 二次型展开速查：当前到底加了哪些项

ManuMesh 当前把所有软几何成本统一累积到齐次二次型。设 x 是候选新顶点位置，x_h=[x,1]^T，每个顶点保存 Q=[[A,b],[b^T,c]]，则候选代价为 E(x)=x_h^T Q x_h=x^T A x+2 b^T x+c。折叠边 (i,j) 时先做 Q_edge=Q_i+Q_j，再解 A x=-b；求解采用 GH97 三级回退链：全空间最优解被拒绝（病态）时，先退到沿折叠边的一维最优（对 rank-2 quadric——直折痕、边界折边——是良定的中间档），仍失败才退到端点/中点候选。边界边的 placement 另用 Lindstrom-Turk 边界守恒约束（src/simplification/Placement.cpp）。

二次型项展开到 A,b,c参数与默认值作用与引用
面平面 QEMpi=[n,-n.p]，Q += area/3 * pi*pi^T。等价于 E=a(n.x-n.p)^2，所以 A+=a nn^T、b+=-a(n.p)n、c+=a(n.p)^2。无独立开关；退化面使用 1e-6 * representativeArea * pointQuadric，保持与正常 QEM 相同的 L^4 缩放量纲。主几何误差，来自 M002 Garland-Heckbert 1997。
普通 Line QuadriclineQuadric(p,n) 取两个与局部法线 n 垂直的单位方向 u,v，加入 Q_l=pi_u*pi_u^T+pi_v*pi_v^T。展开为 E_l=||(I-nn^T)(x-p)||^2，即惩罚切向漂移。useLineQuadrics=true，lineWeight=1e-3。默认分支：Q_i += w_i area_i Q_l。补平坦区 QEM 切向不满秩问题，来自 M004 Liu-Rahimzadeh-Zordan 2025。
特征加权 Line Quadric非 uniform 模式下 w_i=lineWeight+featureBoost*s_i；s_i 来自 dihedral、normal-tensor persistence、height 或 xband。normal-tensor 模式只给满足 normalTensorMinPersistentScales 的顶点写入 persistent score。weightMode=uniform，featureBoost=0.05；常用调试值 dihedral/normal-tensor + 0.08。featureAngleDeg=40，normalTensorFeatureThreshold=0.16，normalTensorScaleCount=1。让硬边、弱 ridge 或指定区域获得更高排序成本；feature evidence 参考 M007/M012/M013/M015/M016，弱特征参考 M026。
Adaptive Scale 分支若 adaptiveScale=true，当前实现先加 adaptiveBaseLineWeight*area_i*Q_l；featureBoost 不再改写 quadric，而是按 Wang 2008 解耦成逐顶点队列优先级因子 priorityScale = 1+max(0,featureBoost)*s_i——它只缩放候选在优先队列里的排序代价，placement 求解用的是干净 quadric。adaptiveScale=false，adaptiveBaseLineWeight=1e-2。这是实验性尺度归一化路径，不是默认推荐。用于跨尺度模型的 line weight 可比性；排序/求解解耦参考 M029 Wang 2008。
边界 Plane Quadric边界边 (a,b) 只有一个邻接面时，取 m=normalize(n_face x e_hat)，加入 Q_b=boundaryWeight*|e|^2*pi_m*pi_m^T 到两个端点。它的 A=boundaryWeight*|e|^2*mm^T，秩 1；边长平方使该项与面积加权 face QEM 同为 L^4 缩放量纲。boundaryWeight=0.0 默认关闭；常用 1-10。硬边界保护另看 preserveBoundary。减少开放边界沿面内法向漂移；扩展 QEM 思路参考 M003，工程 guards 参考 M030-M033。
特征曲线 Tangent-Line Quadric当检测到 loop/primitive 后，对特征顶点用切线 t 调用 lineQuadric(p,t)，即 E_curve=eta*rho*area*||(I-tt^T)(x-p)||^2。这里 rho=0.35+0.65*confidence。preserveFeatureCurves=false 默认关闭；featureCurveWeight=0.05，常用 0.08；featureComponentMinConfidence=0.35 只影响 high-confidence component 报告计数，不过滤 component 或保护。允许沿特征线滑动，惩罚离开曲线；组合 M004 line quadrics、M016 CAD feature line、M026 weak-feature consolidation、M028/M029 feature-preserving simplification。
Primitive 投影与硬过滤圆/椭圆/多边形不是当前 Quadrics.cpp 里的单独径向二次型；当前代码用 tangent-line quadric 排序，再由 projectToCircle/projectToEllipse/projectToPolygonal、maxFeatureCurveDeviationRatio 和 featureProtectionMode 控制最终位置与是否拒绝折叠。maxFeatureCurveDeviationRatio=0 表示关闭曲线漂移预算；featureProtectionMode=PrimitiveCurves。圆/椭圆阈值默认均为 0.05。把“软成本排序”和“硬合法性保护”分开，符合 M030-M033 edge-collapse 工程建议。
带合理参数的数值展开例子

为了看清量级，假设坐标单位是 mm，某顶点 p=(10,5,0)，barycentric 顶点面积 a_i=2.0，候选新位置写作 x=(x,y,z)。实际折叠候选会把两端点 Q_i+Q_j 相加；下面先看单个顶点的一项怎样进入 A,b,c。

例子代入参数展开后的二次型读法

为什么识别到边界、dihedral 或 normal-tensor 特征后要提高 Line Quadric 权重

先把一个容易误解的点说清楚：提高 lineWeight 或 featureBoost，确实会改变 A x=-b 的最小误差位置。它会让位置从“纯 plane QEM 的最优点”偏向“更靠近原顶点法线支撑线、切向漂移更小”的点。因此这不是免费的精度提升，而是一个有意加入的软正则项。M004 line quadrics 的核心价值，正是给标准 QEM 在平坦或近似平坦区域缺失的切向方向补一个小惩罚；M030-M033 的 edge-collapse 工程路线也强调，QEM/line quadrics 负责候选排序，真正危险的 collapse 仍要交给拓扑、边界、特征和质量过滤器。

当前代码里，weightMode=dihedral 会把开边界边记为 score=1，把超过 featureAngleDeg 的二面角边按强度写入端点分数；weightMode=normal-tensor 则使用满足 normalTensorMinPersistentScales 的 persistent feature score。随后普通 line quadric 的权重变成 w_i=lineWeight+featureBoost*s_i。这意味着边界、硬折痕、弱 ridge 附近的候选点，如果试图沿局部切平面大幅滑走，会在优先队列里付出更高代价。

疑问准确回答对应代码/参数
为什么识别到特征还要加 line 权重？因为 plane QEM 主要惩罚离开局部平面，很多特征破坏发生在切向：点沿表面滑过折痕、孔边被拖圆、边界轮廓缩进。Line quadric 惩罚 ||(I-nn^T)(x-p)||^2，正好给这种切向漂移加成本。Quadrics.cpp::lineQuadric，lineWeight，featureBoost
这会不会让最小误差位置更偏？会。它会偏离纯 plane QEM 的最优点，但这个偏移的方向是“少做切向漂移”。如果纯 plane QEM 本来在切向不满秩或近似不满秩，那么这个偏移反而让候选 placement 更稳定。solvePlacementCandidates() 用合并后的 Q_i+Q_j 求解
为什么特征附近要比普通平面更强？普通平面内的小滑动通常视觉影响不大；特征线附近同样大小的滑动可能跨过 CAD patch boundary、浅 ridge 或孔边。提高 w_i 让这些 collapse 排序靠后，给非特征区域优先被简化的机会。w_i=lineWeight+featureBoost*s_i
边界线也靠 line 权重保护吗？不是只靠它。开边界在 dihedral weight mode 下会得到高 feature score，从而减少切向漂移；但真正的边界形状和拓扑还要看 boundaryWeight 的边界 plane quadric、preserveBoundary 的硬策略和 topology guards。addBoundaryQuadrics()，preserveBoundary
normal tensor 弱特征会不会误检后过度保护？会有这个风险。normal-tensor 路径用 persistent score、最少支持尺度和 edge alignment 降低单尺度噪声；component confidence 在 Quadrics.cpp:195 通过 0.35 + 0.65·confidence 连续缩放软 quadric。注意 featureComponentMinConfidence 只是报告阈值，不会过滤弱特征或关闭保护。normalTensorFeatureThreshold，normalTensorMinPersistentScales，VertexFeature::confidence

可以用一个二维化的例子看直觉。假设局部平面是 z=0，纯 plane QEM 是 E_plane=2*z^2。候选点从 (10,5,0) 滑到 (11,5,0) 时，纯 plane QEM 代价仍是 0，因为它没有离开平面。加入普通 line quadric 后，代价多出 0.002；如果 normal-tensor persistent score 是 0.6 且 featureBoost=0.08，同样 1 mm 切向滑动代价变成 0.098。这并不是说几何误差突然大了 49 倍，而是系统在告诉优先队列：“这里像特征支撑，不要把切向漂移很大的 collapse 排得太靠前。”

因此正确的调参原则不是“特征越强，line 权重越大越好”。更稳的顺序是：保持基础 lineWeight 小，让它只修补平坦区病态；让 featureBoost 只放大高置信的 dihedral/normal-tensor 证据；把圆、椭圆、polygonal loop 交给 featureCurveWeight、primitive projection 和 hard feature policy；最后用 feature_rejected、generic_feature_rejected、max_orig_to_simp 和 feature drift 去判断是否过度保护。这个取舍也对应 M026 弱特征整合和 M030-M033 collapse guards 的思路：先让特征证据形成可靠 support，再决定软成本、硬保护或后处理投影。

因此当前总能量可读成：E = E_plane + E_line(weightMode) + E_boundary + E_feature_curve；拓扑、边界、特征保护、法向翻转、三角形质量、局部误差和自交检查不是二次型项，而是候选折叠通过 QEM 排序之后的硬过滤。

1论文出处与核心问题

本页解释的数学逻辑主要来自两篇论文：

  • Michael Garland, Paul S. Heckbert. Surface Simplification Using Quadric Error Metrics. SIGGRAPH 1997. 这是标准 QEM 的来源。
  • Hsueh-Ti Derek Liu, Mehdi Rahimzadeh, Victor Zordan. Controlling Quadric Error Simplification with Line Quadrics. SGP 2025. 这是 Line Quadrics 控制 QEM 简化的来源。
核心问题

标准 QEM 衡量的是点到局部平面的平方距离。它非常适合保持曲面形状，但在平坦区域中，沿平面内移动的误差为零。于是很多边的代价完全相同，优先队列无法区分采样质量。Line Quadrics 的关键贡献，就是给这些原本为零的切向自由度加入一个小而可控的二次惩罚。

2点到平面的距离为什么是二次型

设平面 $\Pi$ 的单位法向为 $n\in\mathbb{R}^3$，平面上一点为 $p$。平面方程可写为：

$$n^\top(x-p)=0$$ (1)

令 $d=-n^\top p$，则：

$$n^\top x+d=0$$ (2)

点 $x$ 到平面的有符号距离是 $r(x)=n^\top x+d$。因为 $n$ 是单位向量，所以这个值本身就是距离；若 $n$ 不是单位向量，还需要除以 $\|n\|$。程序里三角面法线由 triangleNormal 归一化，因此使用单位法线。

平方距离为：

$$E_\Pi(x)=(n^\top x+d)^2$$ (3)

展开：

$$E_\Pi(x)=x^\top nn^\top x+2d\,n^\top x+d^2$$ (4)

这已经是关于 $x$ 的二次函数。为了用统一矩阵表示，引入齐次坐标：

$$\bar{x}=\begin{bmatrix}x\\1\end{bmatrix},\qquad \pi=\begin{bmatrix}n\\d\end{bmatrix}$$ (5)

于是：

$$E_\Pi(x)=(\pi^\top\bar{x})^2=\bar{x}^\top(\pi\pi^\top)\bar{x}$$ (6)

定义：

$$Q_\Pi=\pi\pi^\top= \begin{bmatrix} nn^\top & dn\\ dn^\top & d^2 \end{bmatrix}$$ (7)

这就是平面 quadric。它是一个半正定矩阵，因为对任意 $\bar{x}$，都有 $\bar{x}^\top Q_\Pi\bar{x}=(\pi^\top\bar{x})^2\ge0$。

3顶点 QEM 为什么可以相加

顶点 $i$ 周围有一圈三角面 $N(i)$。希望顶点移动到新位置 $x$ 后仍然靠近这些面，于是定义顶点误差为所有相邻面误差之和：

$$E_i(x)=\sum_{f\in N(i)} w_{if}E_f(x)$$ (8)

其中当前程序使用 barycentric area 权重：

$$w_{if}=\frac{A_f}{3}$$ (9)

代入二次型：

$$E_i(x)=\sum_{f\in N(i)}w_{if}\bar{x}^\top Q_f\bar{x}$$ (10)

由于 $\bar{x}$ 与求和无关，可把矩阵先加起来：

$$E_i(x)=\bar{x}^\top\left(\sum_{f\in N(i)}w_{if}Q_f\right)\bar{x}$$ (11)

定义顶点 quadric：

$$Q_i=\sum_{f\in N(i)}w_{if}Q_f$$ (12)
本质

QEM 能高效，是因为“多个平方距离的和”仍然是一个二次型，多个约束可以压缩进一个 4×4 矩阵。后续边坍缩时只需要加矩阵，而不用重新遍历所有历史面。

4边坍缩为什么变成线性系统

坍缩边 $(i,j)$ 后，新点 $x$ 同时代表原来的 $i$ 和 $j$。因此误差为：

$$E_{ij}(x)=E_i(x)+E_j(x) =\bar{x}^\top(Q_i+Q_j)\bar{x}$$ (13)

记 $Q=Q_i+Q_j$，并分块：

$$Q=\begin{bmatrix}A&b\\b^\top&c\end{bmatrix}$$ (14)

其中 $A$ 是 3×3，$b$ 是 3×1。展开：

$$\bar{x}^\top Q\bar{x} = \begin{bmatrix}x^\top&1\end{bmatrix} \begin{bmatrix}A&b\\b^\top&c\end{bmatrix} \begin{bmatrix}x\\1\end{bmatrix} =x^\top Ax+2b^\top x+c$$ (15)

对 $x$ 求梯度：

$$\nabla_x(x^\top Ax)=2Ax\quad(A=A^\top),\qquad \nabla_x(2b^\top x)=2b$$ (16)

令梯度为零：

$$2Ax+2b=0\quad\Longrightarrow\quad Ax=-b$$ (17)

所以 QEM 的最优坍缩点来自一个 3×3 线性系统。若 $A$ 满秩且条件良好，解唯一；若 $A$ 奇异或病态，最优位置不稳定，需要 fallback。

5标准 QEM 的本质缺陷：切向零能量

考虑完全平坦区域，平面为 $z=0$，法线 $n=(0,0,1)^\top$。平面误差为：

$$E(x,y,z)=z^2$$ (18)

它的矩阵部分是：

$$A=nn^\top= \begin{bmatrix} 0&0&0\\ 0&0&0\\ 0&0&1 \end{bmatrix}$$ (19)

这个矩阵秩为 1。沿 $x$ 和 $y$ 方向移动时：

$$E(x+\Delta x,y+\Delta y,0)=0$$ (20)

从“点到原平面距离”的角度看，这没错；但从“网格采样质量”的角度看，这意味着所有平面内移动都没有代价区别。于是标准 QEM 无法控制平坦区域中的顶点分布，容易出现细长三角形、局部采样堆积和优先队列随机化。

为什么简单缩放没用

若某条边在平坦区域的标准 QEM 代价为 $E=0$，任何标量缩放 $\tilde{E}=sE$ 仍然是 0。缩放只能改变非零误差之间的相对大小，不能给零能量自由度制造新的约束。

6Line Quadric 的本质：到直线的平方距离

Line Quadric 定义的是点到一条直线的平方距离。设直线经过 $p$，单位方向为 $t$：

$$\ell=\{p+\alpha t\mid\alpha\in\mathbb{R}\},\qquad\|t\|=1$$ (21)

点 $x$ 到直线的最近点是把 $x-p$ 投影到 $t$ 方向：

$$x_{\ell}=p+t\,t^\top(x-p)$$ (22)

垂直残差为：

$$r_\ell(x)=x-x_{\ell}=(I-tt^\top)(x-p)$$ (23)

令 $P_t=I-tt^\top$，它是投影到 $t$ 的正交补空间的投影矩阵。因为 $P_t^\top=P_t$ 且 $P_t^2=P_t$，平方距离为：

$$E_\ell(x)=\|P_t(x-p)\|^2=(x-p)^\top P_t(x-p)$$ (24)

展开为二次型：

$$E_\ell(x)=x^\top P_t x-2(P_tp)^\top x+p^\top P_t p$$ (25)

对应齐次矩阵：

$$Q_\ell(p,t)= \begin{bmatrix} P_t&-P_tp\\ -p^\top P_t&p^\top P_t p \end{bmatrix}$$ (26)

6.1 为什么程序用两张平面相加

若 $u,v$ 是垂直于 $t$ 的两个单位正交向量，则：

$$u^\top t=0,\qquad v^\top t=0,\qquad u^\top v=0$$ (27)

三维空间的正交分解给出：

$$uu^\top+vv^\top+tt^\top=I$$ (28)

所以：

$$uu^\top+vv^\top=I-tt^\top=P_t$$ (29)

经过直线 $\ell$ 且法向分别为 $u$ 和 $v$ 的两张平面，平方距离相加就是点到直线的平方距离：

$$((x-p)^\top u)^2+((x-p)^\top v)^2=(x-p)^\top P_t(x-p)$$ (30)

这就是当前程序 lineQuadric 的实现方式。

7Line Quadrics 如何修复平坦区域排序

在平面 $z=0$ 中，标准 QEM 的矩阵是：

$$A_{plane}=\alpha \begin{bmatrix} 0&0&0\\ 0&0&0\\ 0&0&1 \end{bmatrix}$$ (31)

当前程序取顶点法线方向作为 line direction，即 $t=n=(0,0,1)^\top$。于是：

$$P_t=I-tt^\top= \begin{bmatrix} 1&0&0\\ 0&1&0\\ 0&0&0 \end{bmatrix}$$ (32)

加入权重 $w a$ 后：

$$A=A_{plane}+waP_t= \begin{bmatrix} wa&0&0\\ 0&wa&0\\ 0&0&\alpha \end{bmatrix}$$ (33)

如果 $w>0$，$a>0$，$\alpha>0$，则矩阵满秩。能量从只惩罚 $z$ 方向，变为同时惩罚 $x,y,z$ 三个方向，只是 $x,y$ 的惩罚通常很小：

$$E(x,y,z)=wa\big((x-x_i)^2+(y-y_i)^2\big)+\alpha z^2+\text{linear/constant terms}$$ (34)
最本质的一句话

标准 QEM 在平坦区域没有切向能量；Line Quadrics 用点到法线直线的距离，给切向移动补上能量。它不是替代 QEM，而是在 QEM 的零空间里加了一个温和正则项。

8权重项的数学意义

当前程序的顶点能量可以抽象为：

$$E_i(x)=E_i^{plane}(x)+w_i a_iE_{\ell_i}^{normal}(x)$$ (35)

其中：

$$w_i=w_0+\beta s_i$$ (36)

$w_0$ 是基础 line weight，$s_i$ 是特征分数，$\beta$ 是增强强度。不同权重模式只是在定义 $s_i$：

  • uniform：$s_i=0$，所有点同等处理。
  • height：$s_i$ 随高度增加，用来做空间区域实验。
  • xband：$s_i$ 在 x 方向中间区域较大。
  • dihedral：$s_i$ 与二面角超过阈值的程度有关，硬边附近更大。

数学上，$w_i$ 控制的是正则项和几何保真项的相对强弱。$w_i$ 太小，平坦区域排序仍然弱；$w_i$ 太大，切向正则可能压过几何保真。

9边界与特征曲线的二次型解释

9.1 边界 plane quadric

边界边 $(a,b)$ 的方向为 $e=b-a$，相邻面法线为 $n_f$。程序构造：

$$m=\frac{e\times n_f}{\|e\times n_f\|}$$ (37)

$m$ 垂直于边方向，也垂直于相邻面法线，因此以 $m$ 为法向、经过边界边的平面像一堵侧墙，阻止边界横向漂移。加入项为：

$$E^{boundary}(x)=\gamma\|e\|(m^\top(x-a))^2$$ (38)

9.2 特征曲线 tangent-line quadric

若顶点位于特征曲线上，程序估计曲线切线 $\tau_i$，并添加：

$$E_i^{curve}(x)=\eta a_i\,\operatorname{dist}^2(x,\{v_i+\alpha\tau_i\})$$ (39)

这与普通 line quadric 的方向不同。普通项的方向是法线 $n_i$，主要惩罚切向漂移；曲线项的方向是特征切线 $\tau_i$，主要惩罚离开特征曲线的横向漂移。

10圆形特征拟合的最小二乘推导

2026-07-12 起的实现现状

本节先推导最直观的 Kåsa 线性最小二乘圆拟合。当前 PrimitiveFit.cpp 已把它降级为确定性回退：主拟合改用 Taubin 代数拟合（Taubin 1991），椭圆改用 Halíř-Flusser 直接最小二乘（Fitzgibbon 约束），见本节末尾的说明。

候选特征 loop 有点集 $\{p_i\}_{i=1}^N$。先求均值：

$$\mu=\frac1N\sum_i p_i$$ (40)

再求协方差：

$$C=\sum_i(p_i-\mu)(p_i-\mu)^\top$$ (41)

$C$ 的最小特征值方向作为拟合平面法线 $n_c$。选平面内正交基 $u,v$，将点投影到二维：

$$x_i=(p_i-\mu)^\top u,\qquad y_i=(p_i-\mu)^\top v$$ (42)

圆方程：

$$(x-c_x)^2+(y-c_y)^2=r^2$$ (43)

展开：

$$x^2+y^2-2c_xx-2c_yy+c_x^2+c_y^2-r^2=0$$ (44)

移项并令 $\rho=r^2-c_x^2-c_y^2$：

$$2c_xx+2c_yy+\rho=x^2+y^2$$ (45)

对每个点建立线性方程：

$$ \begin{bmatrix}2x_i&2y_i&1\end{bmatrix} \begin{bmatrix}c_x\\c_y\\\rho\end{bmatrix} =x_i^2+y_i^2 $$ (46)

最小二乘正规方程为：

$$(A^\top A)z=A^\top b,\qquad z=[c_x,c_y,\rho]^\top$$ (47)

解出 $z$ 后：

$$r=\sqrt{\rho+c_x^2+c_y^2},\qquad center=\mu+c_xu+c_yv$$ (48)

最后用径向误差和平面误差做阈值判定。若通过，坍缩后的新点可以投影回圆：

$$x_{proj}=center+r\frac{(I-n_cn_c^\top)(x-center)}{\|(I-n_cn_c^\top)(x-center)\|}$$ (49)

10.1 为什么主拟合换成 Taubin：Kåsa 的系统性偏差

上面的线性推导最小化的是代数残差 $(x_i^2+y_i^2-2c_xx_i-2c_yy_i-\rho)$ 的平方和，这就是 Kåsa 拟合。它在完整均匀采样的圆上是精确的，但在短弧、噪声或非均匀采样下有 $O(\sigma^2)$ 的本质偏差，会系统性低估半径（代数残差在圆内侧权重更大）。Taubin 1991 把同一代数残差按其梯度范数归一化后最小化，本质偏差降到 $O(\sigma^4)$（一阶无偏）。当前实现按 Chernov 的 Newton 形式解 Taubin 的特征三次方程（从 $\eta=0$ 起的受控 Newton 迭代）；任何退化（导数消失、中心系统行列式过小）都会回退到 Kåsa，因此病态输入上的行为与旧实现一致，而正常输入上短弧与噪声 loop 的半径估计不再塌缩。

10.2 椭圆：Halíř-Flusser 直接最小二乘

椭圆参数不再用 PCA/二阶矩近似，而是解 Fitzgibbon 约束最小二乘：在 conic 系数 $\theta=[a,b,c,d,e,f]$ 上最小化代数残差，同时施加 $4ac-b^2=1$——这个约束保证解一定是椭圆而不是双曲线/抛物线。Halíř-Flusser 的数值稳定版把 6×6 广义特征问题化简为 3×3 缩减系统（当前实现即此形式），再从 conic 系数解析出中心、长短半轴与轴向：轴向来自 conic 的转角（$Q=[[a,b/2],[b/2,c]]$ 的特征向量），对精确椭圆上的任意顶点分布都是精确的；旧的 PCA 二阶矩估计只保留为退化回退。分类阈值（circleFitRelativeThreshold、ellipseFitRelativeThreshold 均默认 0.05，nearCircleAxisRatioTolerance 默认 0.08）不变，仍作用于几何残差。

10A为什么“特征边数量”不是理论上足够的指标

从数学上看，单条边的二面角或单个顶点的 normal tensor 分数只是局部证据。它们回答的是“这个局部是否不平滑”，不是“这里是否存在一条应该被 QEM 保护的设计曲线”。要成为可保护特征，还需要三个额外性质：

  1. 连续性：局部证据必须能连成 curve graph。M016 和 M018/M019 这类 CAD mesh feature extraction / polygon crawling 方法强调追踪连续边，而不是孤立打分。
  2. 闭合性或稳定端点：圆孔、patch boundary 和 segmentation 分界需要闭合或端点可信。M024/M025 的工程对象 segmentation 都把边界 closure 当成前提。
  3. 尺度稳定性：弱特征在不同 smoothing scale 下都存在时更可信。M009、M012/M013、M015 给 normal tensor / voting / multiscale 路线提供依据。

因此 ManuMesh 把特征质量拆成 edge precision/recall、loop closure rate、junction correctness、component confidence 和 feature drift/Hausdorff envelope。只看 feature_edges 增加，可能只是噪声增多；只有 feature edges 形成高 confidence component，并且简化后 drift 受控，才说明特征识别真正被 QEM 消费了。

连续曲线FeatureLooploop closure rate，断裂数，cleanup bridge 数。

11还有没有更强的理论路线

有。当前程序把所有软约束都塞进同一个 quadric，优点是简单、快、和 QEM 框架兼容；缺点是它仍然是局部二次近似，不能天然保证拓扑、Hausdorff 误差或特征图结构。更强方法通常把“代价函数”和“硬约束/验收条件”分开。

11.1 从软惩罚升级到硬约束

当前边界项是：

$$E^{boundary}(x)=\gamma\|e\|(m^\top(x-a))^2$$ (50)

它只是让离开边界支撑平面的代价变大，不是绝对禁止。更强的做法是把边界边或特征边标记为 constrained edge，并规定：

$$collapse(e)\ \text{is valid only if constrained-edge graph is preserved}$$ (51)

这类思路在 CGAL Surface Mesh Simplification 的 constrained edge / placement filter 机制中很明确；Hoppe 的 Progressive Meshes 也把 discontinuity curves 作为需要保留的结构处理。数学上，这相当于把一部分条件从目标函数 $E(x)$ 中拿出来，变成可行域 $\Omega$：

$$x^*=\arg\min_{x\in\Omega}E(x)$$ (52)

11.2 从 QEM placement 升级到体积/边界约束 placement

Lindstrom-Turk 1998 的 memoryless simplification 不是累积原始面 quadric，而是按优先级建立约束：边界形状、体积保持、局部体积变化、边界面积变化、三角形形状。它的思想不是“把所有东西加权求和”，而是“重要约束先占住自由度”。

$$ \text{choose } x \text{ by accepting compatible linear constraints until position is determined} $$ (53)

这对工业模型很有价值：如果边界或体积绝不能漂，硬约束往往比调一个很大的 quadric 权重更可靠。2026-07-12 起，ManuMesh 已把这条思路的第一步落地：边界边的 placement 改用 Lindstrom-Turk 边界守恒约束求解（src/simplification/Placement.cpp），不再只靠边界 plane quadric 的软惩罚；内部边则沿用 GH97 三级回退链（全空间最优 → 沿折叠边一维最优 → 端点/中点）。

11.3 从二面角检测升级到特征图检测

当前程序的二面角判据已是有向版本：先按共享边在两面中的遍历方向做绕向一致性判断，一致时用带符号法向点积求转角：

$$\theta=\arccos(n_1^\top n_2)\ge\theta_0\quad\text{（绕向一致时）}$$ (54)

带符号 dot 能识别 $\theta>90^\circ$ 的反折刀边——旧的 $|n_1^\top n_2|$ 会把 120° 的法向夹角读成 60°、把薄片折边读成平面而漏检。绕向不一致的边回退到无符号角（只会低报锐度），并计入 FeatureAnalysis::inconsistentWindingEdges 诊断。单阈值仍对噪声、圆角、弱特征、非均匀三角化不够稳。CAD/扫描模型中更强的路线是先提取 feature graph，例如 C0/C1/C2 discontinuity、normal tensor surface-feature line 或 robust CAD triangular mesh feature-line extraction。对应参考包括 Jiao-Bayyana 2008、Vidal-Wolf-Dupont 2011、Tsuchie-Higashi 2014。

11.4 从局部 QEM 升级到误差界过滤

QEM 是局部二次近似，不等于真实 Hausdorff 误差。若要工业级精度，可以把 QEM 当成候选排序，把 Hausdorff/tolerance volume 当成硬验收：

$$ collapse(e)\ \text{accepted only if}\ d_H(M_{new},M_{ref})\le\varepsilon $$ (56)

这会更慢，但结果更可控。很多高可靠简化/重网格化方法都会采用“局部代价排序 + 全局或局部误差界过滤”的组合。

对当前程序的结论

当前 tangent-line quadric 是很好的轻量实验项；如果目标是工业 CAD/STL 简化，下一步更值得做的是 constrained feature graph、Hausdorff/tolerance filter、以及更稳健的 feature-line detector。Line Quadrics 仍然保留，因为它解决的是平坦区采样和优先级退化问题，和这些硬约束并不冲突。

11.5 针对圆孔识别的较新路线

圆孔识别不是单纯的 QEM 问题，而是“边界/特征候选提取 + 几何拟合 + 语义判定”。当前程序已经有圆拟合，但候选 loop 仍较朴素。较新的论文可以按输入类型分三类：

输入类型更强路线理论收益
三角网格/STLRobust hole detection on triangular meshes，尤其处理 singular vertices 和复杂边界。先保证 hole boundary loop 提取正确，再谈圆拟合。否则最小二乘拟合再好，也会被错误 loop 污染。
扫描点云圆孔边界点云分割、多尺度圆孔特征提取、曲率中心收缩等方法。直接在原始测量点中找孔边界，避免重建网格和简化过程引入的拓扑/采样误差。
STEP/B-RepB-Rep graph neural network 或规则/图匹配式 machining feature recognition。在 CAD 拓扑层识别孔，比从三角片上反推圆孔更接近制造语义，可区分通孔、盲孔、沉孔、锥孔等。

因此，如果仍保持当前 STL 输入，最实际的增强不是先上深度学习，而是把圆孔识别拆成：

$$ \text{edge-manifold boundary traversal} \rightarrow \text{hole/main-boundary classification} \rightarrow \text{plane fit} \rightarrow \text{circle/ellipse robust fit} \rightarrow \text{cylinder-axis and radius consistency check} $$ (57)

这条路线和 Yip et al. 2024 的 triangular-mesh hole detection 最贴近；如果将来支持点云输入，再参考 CHBS-Net 2023 或 Zhang et al. 2024 的多尺度圆孔点提取。

11.6 推荐给当前程序的圆孔识别数学规格

为了把论文和 GitHub 项目真正落到当前代码里，可以把“圆孔识别”定义成一个独立模块：

$$ \mathcal{D}_{hole}: M=(V,F)\longrightarrow \{(L_k,c_k,n_k,r_k,\sigma_k,score_k)\}_{k=1}^{K} $$ (58)

其中 $L_k=(v_{k,1},\ldots,v_{k,m})$ 是一个有序边界环或特征环，$c_k$ 是圆心，$n_k$ 是圆所在平面法线，$r_k$ 是半径，$\sigma_k$ 是残差统计，$score_k$ 是置信度。这个模块可以吸收 Mauhing/hole-detection-on-triangle-mesh 的边界追踪、PCL/pyRANSAC-3D 的 RANSAC 拟合，以及当前程序已有的最小二乘圆拟合。

步骤 A：边界半边与奇异顶点

对三角网格，先定义无向边的 incident face 数：

$$ \operatorname{inc}(e)=|\{f\in F\mid e\subset f\}| $$ (59)

边界边为：

$$ E_{\partial}=\{e\in E\mid \operatorname{inc}(e)=1\} $$ (60)

普通边界环要求每个边界顶点的边界度为 2：

$$ \deg_{\partial}(v)=|\{e\in E_{\partial}\mid v\in e\}|=2 $$ (61)

但真实 STL 常有 singular boundary vertex，即 $\deg_{\partial}(v)\ne2$。Yip et al. 2024 和对应 GitHub 项目的价值就在这里：不要简单地把边界边连通分量当作一个 loop，而要在半边层面追踪 boundary，使每条半边关联到唯一边界，避免多个孔在奇异点处被错误合并。

步骤 B：平面拟合

给定候选环 $L=\{p_i\}_{i=1}^{m}$，先拟合圆所在平面。均值：

$$ \mu=\frac{1}{m}\sum_{i=1}^{m}p_i $$ (62)

协方差：

$$ C=\sum_{i=1}^{m}(p_i-\mu)(p_i-\mu)^\top $$ (63)

平面法线是最小特征值对应的特征向量：

$$ n=\arg\min_{\|u\|=1}\sum_i(u^\top(p_i-\mu))^2 $$ (64)

平面残差定义为：

$$ \sigma_{plane}^{2}=\frac{1}{m}\sum_i(n^\top(p_i-\mu))^2 $$ (65)

步骤 C：鲁棒圆拟合

在平面内选正交基 $u,w$，投影：

$$ x_i=(p_i-\mu)^\top u,\qquad y_i=(p_i-\mu)^\top w $$ (66)

当前程序的圆拟合已升级为 Taubin 代数拟合（梯度归一化的代数残差，一阶无偏；见 10.1），Kåsa 线性最小二乘保留为确定性回退，其方程为：

$$ 2c_xx_i+2c_yy_i+\rho=x_i^2+y_i^2 $$ (67)

为了处理破损孔、噪声孔和非完整圆，建议升级为 RANSAC + 几何残差 refinement。几何残差为：

$$ e_i=\left|\sqrt{(x_i-c_x)^2+(y_i-c_y)^2}-r\right| $$ (68)

RANSAC 的内点集合：

$$ I=\{i\mid e_i<\tau_r,\ |n^\top(p_i-\mu)|<\tau_p\} $$ (69)

最终可用 Huber 或 Tukey 损失做鲁棒 refinement：

$$ \min_{c_x,c_y,r}\sum_i\rho_{\delta} \left(\sqrt{(x_i-c_x)^2+(y_i-c_y)^2}-r\right) $$ (70)

步骤 D：圆孔而不是普通圆环的判定

圆形轮廓不一定是孔，也可能是凸台、装饰环或噪声边。建议加入轴向和邻域一致性。若孔轴为 $n$，圆心为 $c$，对环上点 $p_i$ 的径向方向：

$$ \hat{r}_i=\frac{(I-nn^\top)(p_i-c)}{\|(I-nn^\top)(p_i-c)\|} $$ (71)

若能找到孔壁相邻面法线 $m_i$，圆柱孔壁应满足：

$$ |m_i^\top n|\approx0,\qquad |m_i^\top\hat{r}_i|\approx1 $$ (72)

如果是通孔并检测到两个边界环 $L_1,L_2$，还应检查：

$$ |r_1-r_2|<\tau_{r2},\qquad \frac{|(c_2-c_1)^\top n|}{\|c_2-c_1\|}\approx1 $$ (73)

这样可以区分“一个孤立圆形边界”和“真实圆柱孔特征”。这一步是当前程序最需要补的，因为现有 fitCircle 只判断 loop 是否像圆，不判断它是否是孔。

步骤 E：把识别结果反馈给简化器

识别出的圆孔环应转换成硬约束图：

$$ G_{hole}=(V_{hole},E_{hole}),\qquad E_{hole}=\{(v_i,v_{i+1})\} $$ (74)

坍缩合法性应从“软惩罚”升级为：

$$ collapse(e)\ \text{valid} \Longleftrightarrow \text{hole graph topology, radius, plane, and axis tolerances remain valid} $$ (75)

这就是 GitHub 参考项目和论文最应该带给当前程序的改变：圆孔识别先独立做准，再把圆孔作为受保护的语义 feature graph 喂给 QEM/Line Quadrics 简化器。

12从能量函数看当前程序

把当前程序的主要项合在一起，边 $(i,j)$ 坍缩到 $x$ 的代价可理解为：

$$ E_{ij}(x)= \sum_{q\in\{i,j\}} \left[ \sum_{f\in N(q)}\frac{A_f}{3}(n_f^\top x+d_f)^2 +w_q a_q\operatorname{dist}^2(x,\ell_q^{normal}) +E_q^{boundary}(x) +E_q^{curve}(x) \right] $$ (76)

其中：

  • 第一项是标准 QEM，来自 Garland-Heckbert 1997。
  • 第二项是 Line Quadrics，来自 Liu、Rahimzadeh、Zordan 2025。
  • 第三项是边界保护扩展，和 Garland-Heckbert 1998、Garland 博士论文以及 CGAL 中 border pseudo-faces / boundary quadrics 的工程做法同源。
  • 第四项是当前程序为 CAD/STL 特征曲线实验加入的 tangent-line 约束。它不是某篇论文的逐字实现，而是把 Liu-Rahimzadeh-Zordan 2025 的 line quadric 控制思想，用在 Vidal-Wolf-Dupont 2011、Jiao-Bayyana 2008 这类 CAD 特征线检测得到的曲线切线方向上，并结合特征保持简化文献中的 collapse 约束策略。

12.1 纹理感知代价的量纲分析

2026-07 起，当网格带逐角 UV 且调用方显式开启 preserveTexture 时，排序代价在 (76) 之外再加一个标量项（设计文档 documentation/design/texture_aware_qem.md）：

$$E_{total}(p)=E_{geometry}^{4\times4}(p)+w_{tex}\cdot E_{uv}^{local}(p)$$ (U1)

注意它不是一个新的二次型项：几何 quadric 保持 4×4 齐次矩阵，placement 仍解同一个 3D 线性系统，候选点仍是端点、中点和稳定 QEM 最优点。这与 Garland-Heckbert 1998 把颜色/纹理并入高维属性 quadric（矩阵扩到 $(3+m+1)$ 维）的路线不同：属性扩维会改变求解维度和数值条件，而这里 UV 只影响排序和局部合法性检查。$E_{uv}^{local}$ 的定义是：

$$E_{uv}^{local}=\ell^2\cdot\frac{\sum_{f}A_f\,\|\Delta uv_f\|^2}{\bar{s}_{uv}^{\,2}}$$ (U2)

其中 $\ell$ 是被坍缩边的 3D 长度，$A_f$ 是坍缩触及面的 3D 面积，$\Delta uv_f$ 是该面角点 UV 的位移，$\bar{s}_{uv}$ 是局部 UV 边的平均长度。做量纲分析：设 3D 长度量纲为 $L$，UV 长度量纲为 $U$。面积加权几何 QEM 的量纲是 $A_f\times\text{距离}^2=L^2\cdot L^2=L^4$。而 (U2) 中 $\|\Delta uv_f\|^2/\bar{s}_{uv}^2$ 的量纲是 $U^2/U^2=1$（无量纲），剩下 $\ell^2\cdot A_f=L^2\cdot L^2=L^4$。两项同为 $L^4$ 量纲，所以 $w_{tex}$（textureWeight，默认 1.0）是一个无量纲旋钮：默认值 1 表示"一份归一化的 UV 失真与一份同尺度的几何误差同等重要"，且这个解读不随模型物理尺寸变化。

对 $\bar{s}_{uv}^2$ 的除法还带来第二个不变性：把整个 UV atlas 均匀缩放 $s$ 倍（重新打包贴图、换分辨率时常见），$\|\Delta uv_f\|^2$ 放大 $s^2$，$\bar{s}_{uv}^2$ 同样放大 $s^2$，两者相消，$E_{uv}^{local}$ 不变。因此 textureWeight 不需要随 atlas 缩放重调。这两条不变性合起来，就是"标量失真项"设计的理论理由：用 $O(k)$ 的局部计算（$k$ 为 one-ring 规模）获得与几何 QEM 可直接相加的、量纲一致且缩放不变的排序代价，而把接缝与翻转这类离散约束交给显式的局部 chart 配对、UV 定向和有符号面积下限检查（作为硬合法性过滤，不进入代价函数）。preserveTexture=false（默认）时该项不存在，几何输出与旧无纹理路径逐位一致。

总括

标准 QEM 的本质是“保持到原始局部平面的距离”；Line Quadrics 的本质是“在标准 QEM 的零空间里加入可控正则”；特征曲线项的本质是“让特征点继续贴近曲线的一维局部模型”。当前程序把这些二次型全部加到同一个 4×4 quadric 中，再用边坍缩优先队列逐步最小化局部代价。开启 preserveTexture 时，排序层再叠加一个与几何项量纲一致的标量 UV 失真项（见 12.1），quadric 本身保持 4×4 不变。
