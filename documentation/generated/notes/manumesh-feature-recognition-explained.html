一句话结论：ManuMesh 的特征识别不是“把二面角大于 40° 的边涂出来”，而是一个分层的确定性图恢复系统。

1问题边界：程序到底识别什么

输入是 manumesh::Mesh：一组顶点和三角面。程序没有 STEP/B-Rep 的曲面类型、参数域、修剪环、孔语义或 CAD feature tree。因此，“特征”在这里不是 CAD 语义对象，而是由离散网格支持的几何与拓扑结构。

(1) \(M=(V,F),\qquad m(e)=|\{f\in F:e\subset f\}|\) \(G_{feature}=(V_{feature},E_{evidence}\cup E_{recovery})\)
\(m(e)\) 是无向边的相邻面数；特征图同时保存原始证据边与后续恢复边，但两者不会混为同一种来源。
程序目标当前表示不是
硬折痕与边界带来源和凸/凹符号的 FeatureGraphEdge解析曲面交线
弱 crease、ridge、valley带尺度 persistence 的弱证据边学习式语义边
曲线结构open chain、closed loop、junction、branch pair全局最优 wireframe
几何解释circle、near-circle、ellipse、polygonal loop完整孔、倒角或加工特征树
面片结构特征边诱导的 face connectivity partition解析曲面拟合与 region merge
先区分“证据、曲线、语义”

一条边被标记为 evidence，不等于它已经属于一条闭合 loop；一条 loop 拟合成圆，也不等于程序已经证明它是通孔；surface patch 更不等于 CAD 平面、圆柱面或 NURBS 曲面。当前系统的职责是给后续简化、报告和 benchmark 提供稳定的显式约束结构。

公开数据契约：include/algorithms/feature_detection/FeatureTypes.h；入口：FeatureDetector.h。

3拓扑与有向二面角硬证据

3.1 相邻面数先给出两类无需法向的证据

(2) \(m(e)=1\Rightarrow boundary\) \(m(e)=2\Rightarrow manifold\ interior\ edge\) \(m(e)>2\Rightarrow non\text{-}manifold\)

3.2 程序先协调绕向，再计算角度和凸凹符号

harmonizeFaceWindings() 对每个可定向 manifold component 做 BFS，得到每个 face 的虚拟翻转符号 \(s_f\in\{-1,+1\}\)，但不修改输入 mesh。对共享边 \((a,b)\) 的两个面：

(3) \(c=\operatorname{clamp}(\mathbf n_0^\mathsf T\mathbf n_1,-1,1)\,s_0s_1\) \(\theta=\arccos(c)\) \(q=\big((s_0\mathbf n_0)\times(s_1\mathbf n_1)\big)^\mathsf T\mathbf d\) \(q>10^{-12}\Rightarrow convex,\quad q<-10^{-12}\Rightarrow concave\)
\(\mathbf d\) 是按第一个面局部边方向定向的单位共享边。默认 \(\theta\ge40^\circ\) 时产生 dihedral evidence。
交互推导：角度、阈值与绕向冲突
接受为硬二面角证据
有效角度 65° ≥ 阈值 40°；凸/凹符号可计算。
绕向冲突回退会损失反折强度

若共享边方向无法形成相反绕向，代码把 \(c\) 替换为 \(|c|\)，于是有效角度被折到 \([0,90^\circ]\)，signed kind 归零，并增加 inconsistentWindingEdges。这保证未知绕向不会伪造凸凹符号，但不能说它仍保留了完整的 >90° 反折角。

3.3 退化面：容忍、降级，但存在顺序效应

输入允许零面积面；其法向为零。Evidence 构造后，第二 stage 会删除所有接触退化面的 dihedral 标记，并修正计数。但强边顶点排除掩码在此之前已经建立：零法向与正常法向点积为 0，可能先产生 90° 伪二面角并把端点标成 discrete vertex。后续删除伪边时没有重建该掩码，因此附近弱证据仍可能被抑制。这是当前程序顺序的真实边界。

绕向与角度：src/common/MeshQueries.cpp；证据策略：FeatureEvidence.cpp；退化降级：DegenerateEvidenceFilterStage。

4法线过滤及其真实作用范围

法线过滤默认关闭。它只更新检测 cache 中的 face normals，不移动顶点、不改三角面、不做扫描重建。每次迭代先计算相邻 manifold faces 的角度门：

(4) \(g_{ij}=0,\quad \theta_{ij}\ge\theta_p\) \(g_{ij}=\exp[-\tfrac12(\theta_{ij}/\sigma)^2],\quad \theta_{ij}<\theta_p\) \(w_{ii}=\max(A_i,10^{-12}),\quad w_{ij}=g_{ij}\sqrt{\max(A_iA_j,10^{-24})}\) \(\widehat{\mathbf n}_i=\operatorname{normalize}\!\left(\frac{w_{ii}\mathbf n_i+\sum_jw_{ij}\mathbf n_j}{w_{ii}+\sum_jw_{ij}}\right)\) \(\mathbf n_i^{new}=\operatorname{normalize}[(1-\rho)\mathbf n_i+\rho\widehat{\mathbf n}_i]\)
默认：4 次迭代，\(\sigma=20^\circ\)，\(\theta_p=50^\circ\)，\(\rho=0.8\)。
通道是否直接使用 filtered normals实际路径
有向二面角是EdgeEvidenceContext::normals = cache.faceNormals()
Normal tensor否逐 face 从顶点坐标重新计算 raw triangleNormal()
Graph cleanup不使用法向使用邻接、局部平均边长、证据来源和切向
为什么 tensor 仍会“间接变化”

过滤法向改变二面角结果，二面角又决定 discreteFeatureVertex 排除掩码。Tensor 自己的分数不变，但哪些 tensor edge 能被物化，可能因为强边排除区变化而不同。

FeatureNormalFilterReport::preservedEdges 的字段注释容易产生误解：实现统计的是最终 edgeIndicator <= 0.05 的边，不只包括超过 preserveAngleDeg 被硬冻结的边，也可能包括角度高但尚未越过保护门、权重已被高斯强烈衰减的边。

实现：src/feature_detection/FeatureNormalFilter.cpp；tensor 原始法向：NormalTensor.cpp。

5Normal tensor：从法向外积到多尺度弱证据

5.1 一个法向外积是一张“方向投票票据”

单位法向 \(\mathbf n\) 的外积 \(\mathbf n\mathbf n^\mathsf T\) 在法向方向上的响应为 1，在切平面内为 0。程序对顶点 incident faces 做面积加权平均：

(5) \(\mathbf T_i=\frac{\sum_{f\ni i}A_f\,\mathbf n_f\mathbf n_f^\mathsf T}{\sum_{f\ni i}A_f}\) \(\widetilde{\mathbf T}_i=\frac{\mathbf T_i+\sum_{j\in N(i)}e^{-(\|p_j-p_i\|/r_i)^2}\mathbf T_j}{1+\sum_{j\in N(i)}e^{-(\|p_j-p_i\|/r_i)^2}}\)
初始 tensor 使用 raw triangle normals。多尺度不是彼此独立的 k-ring 重算，而是在同一个 tensor 场上累计做高斯平滑。

5.2 特征值差把面、折痕和角点拆开

记代码重排后的特征值为 \(\lambda_0\ge\lambda_1\ge\lambda_2\ge0\)：

(6) \(S_{surface}=\max(0,\lambda_0-\lambda_1)\) \(S_{crease}=\max(0,\lambda_1-\lambda_2),\qquad S_{corner}=\lambda_2\) \(S=\max(S_{crease},S_{corner})\)

主法向是最大特征值方向；crease tangent 是最小特征值方向。当前两个源码注释写成了 middle eigendirection，但实现使用 Eigen 升序输出的 col(0)，也就是最小特征值方向；本文按程序实现解释。

5.3 多尺度 persistence 不是取最大值就结束

(7) \(\bar S=\frac1K\sum_{k=1}^{K}S_k,\qquad S_{max}=\max_kS_k\) \(P=\frac{|\{k:S_k\ge\tau\}|}{K}\) \(S_{persistent}=(0.65S_{max}+0.35\bar S)P\)

默认只有一个尺度、没有预平滑，所以 persistence 门相当宽松。增加 normalTensorScaleCount 后，尺度是累计平滑序列；localScale 报告的仍是该顶点平均边长，而不是“胜出尺度的真实半径”。

5.4 顶点分数物化为 edge 的条件

(8) \(\min(K_a^{support},K_b^{support})\ge K_{min}\) \(\min(S_a^{persistent},S_b^{persistent})\ge\tau\) \(S_{crease,a}\ge S_{corner,a},\quad S_{crease,b}\ge S_{corner,b}\) \(\max(|\mathbf d^\mathsf T\mathbf t_a|,|\mathbf d^\mathsf T\mathbf t_b|)\ge\alpha_T\)

方向门使用两端 alignment 的较大值，默认 \(\alpha_T=0.45\)：只要一个端点的切向与边对齐即可。这是召回优先的宽松策略，也是噪声和非均匀采样下需要重点验证的风险。

张量计算：src/feature_detection/NormalTensor.cpp；edge gate：normalTensorEdgeCandidate()。

FeatureGraph 与 TraceGraph 的分工

完整 FeatureGraph 保存所有已接受 evidence edges。TraceGraph 只保存参与 chain / loop ownership 的活动边：

(17) \(trace(e)=boundary\lor nonManifold\lor tensor\lor curvature\lor(dihedral\land\theta\ge\theta_{trace})\)

loopTraceAngleDeg < 0 时复用 featureAngleDeg。若单独提高 trace angle，浅二面角仍留在完整图和 evidence 计数中，但不会被 loop recovery 消费，并计入 untracedFeatureEdges。

策略组合：FeatureEvidence.cpp；双图构造：FeatureGraph.cpp。

8Feature graph 清理与恢复

局部 evidence 往往会产生短刺、断口和紧邻 junction。程序先在同一 trace graph 内做 cleanup，再可选地跨 component consolidation；所有新增边都明确标为 recovery bridge，不会伪装成 raw evidence。

8.1 弱 spur 删除

(18) \(ds_e=\frac{|e|}{\tfrac12(\bar\ell_a+\bar\ell_b)}\) \(strength_e=\max(S_T/\tau_T,S_C/\tau_C)\) \(T=(\sum_e ds_e)(\sum_e strength_e\,ds_e)\)

这会保留“长但弱”的连续曲线，同时删除“短而孤立”的噪声尖刺。Strength 模式最多向前追踪 64 条边，并最多迭代 8 轮清理。

8.2 Endpoint gap 与 close junction

(19) \(d_{ab}\le r_{gap}\frac{\bar\ell_a+\bar\ell_b}{2}\) \(\mathbf o_a^\mathsf T\mathbf d\ge0.5,\quad \mathbf o_b^\mathsf T(-\mathbf d)\ge0.5,\quad \mathbf o_a^\mathsf T\mathbf o_b\le0\)

默认 featureGraphGapLengthRatio=1.25。除了距离，两端外向 tangent 都必须沿连接段继续，并通过 evidence source 与 signed kind 兼容检查。候选按方向修正后的距离排序，每个端点只使用一次。

8.3 跨 component consolidation

该阶段默认关闭，只看不同 connected components 的 degree-1 endpoints。默认允许 3 个局部边长、最小 continuation alignment 0.75；候选按 normalized distance + alignment penalty 排序，一对一贪心接受。端点超过 512 时整阶段跳过并报告 cap。

交互推导：从局部证据到恢复后的曲线
原始支持边 弱 spur cleanup bridge consolidation bridge
原始 evidence：局部响应包含两条短弱 spur，并被两个短缺口分成三个片段。

8.4 兼容规则不是“离得近就连”

  • 两条已知 signed kinds 相反时拒绝。
  • 任一侧含强证据时，两侧必须共享至少一个 strong source：boundary、dihedral 或 non-manifold。
  • 恢复边的属性保持 cleanupBridge 或 consolidationBridge，不增加 featureEdges 原始证据计数。

Cleanup：FeatureGraphCleanup.cpp；兼容：FeatureGraphCompatibility.cpp；跨分量：FeatureGraphConsolidation.cpp。

9Loop 恢复与几何基元拟合

Loop recovery 不是一次 DFS。程序按从“结构更强”到“通用遍历”再到“有边界的 CAD fallback”执行五种恢复，它们可以产生重叠 loop；共享顶点会被标记用于下游保护。

顺序恢复器关键门与上限
1Junction circular cycles两条连接同一对 junction 的不同 chains 合成 cycle；必须拟合为圆/近圆，边中点也要贴圆。
2Small cycle basis只处理无弱证据 component；V≤160、E≤240、cycle rank≤32、单 cycle≤80；只接受 polygonal loop。
3Remaining traces先从 degree≠2 顶点追 open chains，再消费未访问 degree-2 cycles；每条活动边本阶段最多一次。
4Primitive components整个 component 满足 E≥V 且 E≤3V，整体点集拟合为 circle / near-circle / ellipse。
5Circular clusters无弱证据、8..120 vertices；从 trace length-2 path 取三点圆种子；覆盖≥1.5π，unsupported angular gaps≤25%，种子扫描≤32768。

9.1 所有 primitive 先共享一个最佳拟合平面

(20) \(\mu=\frac1m\sum_ip_i,\qquad C=\sum_i(p_i-\mu)(p_i-\mu)^\mathsf T\) \(\mathbf n=\text{eigenvector of }C\text{ with smallest eigenvalue}\) \(x_i=(p_i-\mu)^\mathsf T\mathbf u/s,\quad y_i=(p_i-\mu)^\mathsf T\mathbf v/s\)
\(s\) 是平面点的 RMS radius。归一化使 ellipse 的四阶设计矩阵和 circle 的矩方程更稳定。

9.2 圆：Taubin 主拟合，Kasa 确定性回退

程序先解 Taubin centered moment characteristic cubic，并用有保护的 Newton iteration 从 \(\eta=0\) 开始。行列式退化、导数失效或解非有限时，回退到 Kasa 线性最小二乘：

(21) \(2c_xx_i+2c_yy_i+\rho=x_i^2+y_i^2\) \(r^2=\rho+c_x^2+c_y^2\)

Taubin 相比 Kasa 对部分弧和非均匀采样偏差更小；Kasa 只作为病态输入兜底。

9.3 椭圆：Halíř-Flusser 直接最小二乘

Conic 为 \(ax^2+bxy+cy^2+dx+ey+f=0\)。程序用分块散布矩阵消掉线性部分，解 3×3 reduced system，并只接受满足 \(4ac-b^2>0\) 的真椭圆 eigenvector。中心、主轴与半径从中心化二次型的特征分解恢复。

9.4 分类用相对 RMS 与最大误差双门

(22) \(R_{rms}^{circle}=(rms_{radial}+rms_{plane})/r\) \(R_{max}^{circle}=\max(max_{radial},max_{plane})/r\) \(R_{rms}\le\tau_c,\quad R_{max}\le\max(3\tau_c,0.08)\) \(axisRatio=b/a,\quad axisError=|1-axisRatio|\)

默认 circle / ellipse 相对阈值都是 0.05，near-circle axis tolerance 是 0.08。fitPrimitive() 固定要求至少 5 个点，所以虽然公开 minFeatureLoopVertices 允许设为 3，3/4 顶点 recovered cycles 仍无法通过 primitive fit。

恢复顺序：FeatureLoopRecovery.cpp；拟合：PrimitiveFit.cpp；圆 fallback：FeatureCircularRecovery.cpp。

10置信度、junction 与 surface patches

10.1 Component confidence 是连续支持度，不是过滤器

Cleanup 后的 trace graph 按 BFS 分 connected components。对一个连通分量：

(23) \(cycleRank=E-V+1\) \(strongRatio=E_{boundary+dihedral+nonmanifold}/E\) \(weakSupport=\max(\overline S_T/\tau_T,\overline S_C/\tau_C)\ \text{clamped to }[0,1]\) \(evidence=\max(strongRatio,0.8\,weakSupport)\) \(residual=1-meanPrimitiveResidual/0.12\ \text{clamped to }[0,1]\) \(confidence=\operatorname{clamp}(0.45evidence+0.25closure+0.20residual+0.10weakSupport-penalty)\)

没有 primitive residual 时 residual 固定为 0.5。Junction 超过 2 个后，每多一个罚 0.04，最多罚 0.25。featureComponentMinConfidence=0.35 只控制“高置信 component”报告计数，不删除图、loop 或 vertex。

交互推导：component confidence
0.748
evidence=max(0.75, 0.8×0.40)=0.75；junction penalty=0。

10.2 Junction 的“点找到”与“分支接对”是两件事

活动 incident edge 数大于 2 才是 public graph 的 topological junction。每条 branch 存 outward tangent 与 signed kind。两个 branch 从 junction 向外，因此真正直行的 continuation 应近似反平行：

(24) \(\alpha_{ij}=-\mathbf t_i^\mathsf T\mathbf t_j\ge0.65\)

候选按 alignment 降序、索引确定性打破平局，每条 branch 最多进入一个 pair。未配对 branch 超过 1 条时标为 ambiguous。注意另一个公共类型 VertexFeature::junction 还用于下游保护共享 loop 顶点；它与严格的 FeatureGraphVertex::junction 语义不同。

10.3 Surface patch 是 barrier 上的 flood fill

(25) \(f_i\sim f_j\Longleftrightarrow f_i,f_j\text{ share a manifold edge }e\notin B_{feature}\) \(patch=connected\ component\ of\ (F,\sim)\)

空间 bridge 若不是原始 mesh edge，不能切分 face。当前实现的纯 bridge 会在 strong/weak source gate 就被跳过，因此 segmentationIgnoredRecoveryEdges 对这类 bridge 实际上基本不可达，尽管注释声称会计数；分区行为是对的，诊断字段需要后续修正。

Component 与 confidence：summarizeFeatureComponents()；junction：finalizeFeatureGraphMarkers()；patch：FeatureSegmentation.cpp。

11.3 FeatureAnalysis 如何进入 QEM

简化器可以复用预计算 FeatureAnalysis，避免二次检测。每个 feature vertex 的 tangent 生成 point-to-line quadric；component confidence 只做温和缩放：

(26) \(Q_{curve}(v)=w_{curve}\,[0.35+0.65\,clamp(confidence)]\,A_v\,Q_{line}(p_v,t_v)\)

即使 confidence=0，soft curve quadric 仍保留 35% 权重。圆/近圆/椭圆还可进入 placement projection 与硬保护；generic feature edge 是否硬锁由 simplification policy 决定，不由 detector 的 high-confidence threshold 决定。

12.2 从程序读出的主要失败模式

  • 弱通道受采样方向影响：特征曲线若与 mesh edges 不对齐，顶点证据可能很强但边 gate 仍拒绝，图会碎裂。
  • Normal tensor 是累计平滑：尺度之间不是独立统计；过多尺度可能把窄特征稀释。
  • Local recovery 不是全局证明：endpoint、close junction、consolidation 都是一对一局部贪心；密集近邻曲线仍可能误连或漏连。
  • Primitive fit 解释点集，不恢复 CAD：部分圆弧、共圆杂点、非均匀 tessellation 会挑战 fallback；程序用 graph support 和 angular coverage 限制误检，但没有孔壁语义。
  • Patch 依赖 barrier 完整性：缺口会让 flood fill 泄漏；当前没有 analytic surface fit、merge 或 surface type classification。

12.3 当前源码中的注释与实现偏差

  1. Tensor tangent：注释写 middle eigendirection；代码使用最小特征值方向，后者才是本文采用的程序事实。
  2. Options validation：头文件声称 constructor / setOptions 立即校验；实现延迟到 analyze。
  3. Junction 语义：public comment 混入 shared-loop；实际 graph junction 严格是 active valence > 2，shared 单独保存。
  4. Normal report：preservedEdges 是最终 indicator≤0.05 的计数，不严格等于 preserve-angle gate 命中数。
  5. Patch diagnostic：纯 recovery bridge 在 source gate 已跳过，segmentationIgnoredRecoveryEdges 基本不会按注释增长。
  6. Degenerate ordering：伪二面角随后会被删，但先前写入的 discrete-vertex 弱证据排除标记不会回滚。
推荐调参顺序
  1. 先确认输入拓扑与绕向诊断，再调 featureAngleDeg。
  2. 分开看 evidence 与 traced edges，避免把“检测到”误认为“已有 loop ownership”。
  3. 弱 crease 先调 tensor threshold / scale / persistence；轻噪声再打开 normal filter。
  4. 最后再用 cleanup gap、strength 与 consolidation 修连续性；bridge 数上升必须与 benchmark / 可视化一起审查。
