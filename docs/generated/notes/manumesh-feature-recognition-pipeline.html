1. 一句话路线

当前特征识别不是“单阈值二面角提边”。 它是一条 CAD/STL 优先、扫描增强 opt-in 的图恢复路线：可选 normal filter 只稳定 evidence normals；boundary / non-manifold / dihedral 提供强证据，normal tensor / smooth curvature 提供弱证据；随后 cleanup、compatible component consolidation、junction branch pairing、loop/primitive recovery、component confidence 与可选 surface patches 把局部响应变成可消费结构。

这条路线与文献图谱的判断一致：对于干净 CAD/STL，二面角、边界、facet 邻接和 loop construction 往往比直接估 curvature derivative 更稳；对于弱 crease 或噪声场景，则需要 normal/tensor voting 或多尺度证据来避免单阈值漏检。文献技能的 distilled corpus 明确把 CAD/STL hard boundary 抽取、normal/tensor voting、loop tracing 和 feature-preserving simplification 分成互补家族 P00。

输入假设

输入是三角网格 Mesh，通常来自 STL/OBJ 或生成器。没有 B-Rep 语义，因此“孔、倒角、圆环、patch 边界”都只能从三角面邻接、法向和采样点几何中推断。

识别目标

不是完整 CAD 反求，而是为后续简化和验证提供足够稳定的特征图：edge evidence、loop、primitive、junction、component confidence。

核心取舍

强证据优先、弱证据保守；先成图再恢复 loop；把可保护的 primitive curves 和普通 crease 区分开，避免所有 feature edge 都被硬锁导致简化质量恶化。

1. 面法向与有向二面角

三角形 \(f=(p_0,p_1,p_2)\) 的单位法向为：

\[ \mathbf n_f = \frac{(p_1-p_0)\times(p_2-p_0)} {\left\|(p_1-p_0)\times(p_2-p_0)\right\|} \]
退化三角形的叉积长度接近 0，源码返回零法向；后续不会把它当作可靠角度证据。

harmonizeFaceWindings() 在每个二面流形连通分量上做 BFS，为 face 分配 \(s_f\in\{-1,+1\}\)。相邻两面在共享边上应沿相反方向遍历；若输入绕向不一致，先用 \(s_f\) 做局部协调。

\[ d = \operatorname{clamp}\!\left( s_0s_1\,\mathbf n_0^\mathsf T\mathbf n_1,-1,1 \right),\qquad \theta=\arccos(d) \] \[ \chi = \left((s_0\mathbf n_0)\times(s_1\mathbf n_1)\right)^\mathsf T \left(\operatorname{dir}_0\,\frac{p_b-p_a}{\|p_b-p_a\|}\right) \] \[ \operatorname{signedKind} = \begin{cases} +1,& \chi>10^{-12}\\ -1,& \chi<-10^{-12}\\ 0,& \text{otherwise} \end{cases} \]
若协调后两面仍以相同方向遍历共享边，源码设置 inconsistentWinding=true， 改用 \(|d|\) 的无符号角并把 signed kind 置 0。 
for each mesh edge (a,b):
    incident = edgeInfo[a,b].faces
    if incident.size == 1: boundary = true
    if incident.size > 2: nonManifold = true
    if incident.size == 2:
        theta, sign, inconsistent = orientedDihedral(...)
        dihedral = theta >= featureAngleDeg
        if dihedral: signedKind = sign
数值例子： 两个已协调法向的 dot 为 \(0.5\)，则 \(\theta=\arccos(0.5)=60^\circ\)； 默认阈值 \(40^\circ\) 下是硬边。若真实法向夹角为 \(120^\circ\)，dot 为 \(-0.5\)， 当前有向公式得到 \(120^\circ\)；旧式 \(\arccos(|d|)\) 只会得到 \(60^\circ\)， 会压扁反折刀边的角度。

2. 法线域过滤：edge indicator、面积权重与 relaxation

对相邻 manifold faces \(i,j\)，先计算法向夹角 \(\theta_{ij}=\arccos(\operatorname{clamp}(\mathbf n_i^\mathsf T\mathbf n_j,-1,1))\)。 当夹角超过保护角 \(\theta_p\) 时完全禁止跨边平滑；否则使用高斯 edge indicator：

\[ g_{ij} = \begin{cases} 0,&\theta_{ij}\ge\theta_p\\ \exp\!\left[-\frac12\left(\frac{\theta_{ij}}{\sigma_\theta}\right)^2\right], &\theta_{ij}<\theta_p \end{cases} \] \[ w_{ii}=\max(A_i,10^{-12}),\qquad w_{ij}=g_{ij}\sqrt{\max(A_iA_j,10^{-24})} \] \[ \widehat{\mathbf n}_i = \operatorname{normalize}\!\left( \frac{w_{ii}\mathbf n_i+\sum_{j\in N(i)}w_{ij}\mathbf n_j} {w_{ii}+\sum_{j\in N(i)}w_{ij}} \right) \] \[ \mathbf n_i^{\,new} = \operatorname{normalize}\!\left( (1-\lambda)\mathbf n_i+\lambda\widehat{\mathbf n}_i \right) \]
默认 \(\sigma_\theta=20^\circ\)、\(\theta_p=50^\circ\)、\(\lambda=0.8\)、4 次迭代。 代码见 FeatureNormalFilter.cpp:31-179。 
normals = harmonize(rawFaceNormals)
repeat iterations times:
    for each face i:
        weighted = area[i] * normals[i]
        weightSum = area[i]
        for each manifold neighbor j:
            g = edgeIndicator(normals[i], normals[j])
            if g == 0: continue
            w = g * sqrt(area[i] * area[j])
            weighted += w * normals[j]
            weightSum += w
        target = normalize(weighted / weightSum)
        next[i] = normalize((1-relaxation)*normals[i] + relaxation*target)
    swap(normals, next)
数值例子： 两个等面积 face 的法向相差 \(10^\circ\)，取 \(\sigma_\theta=20^\circ\)、 \(\theta_p=50^\circ\)，则 \(g=\exp[-\tfrac12(10/20)^2]\approx0.8825\)。 邻域目标法向约向另一面旋转 \(4.69^\circ\)；再乘 relaxation \(0.8\)， 本次迭代约旋转 \(3.75^\circ\)。若两面相差 \(60^\circ\)，因超过保护角，\(g=0\)， 该折痕不会被跨边平均。

3. Normal tensor：outer product、特征值 saliency 与 persistence

每个顶点先累加相邻面的面积加权 normal tensor。这里的 face normal 来自原始几何， 不是上一小节的 filtered cache normal。

\[ \mathbf T_i = \frac{\sum_{f\ni i} A_f\,\mathbf n_f\mathbf n_f^\mathsf T} {\sum_{f\ni i}A_f} \] \[ \widetilde{\mathbf T}_i = \frac{\mathbf T_i+\sum_{j\in N(i)} \exp[-(\|p_j-p_i\|/r_i)^2]\,\mathbf T_j} {1+\sum_{j\in N(i)}\exp[-(\|p_j-p_i\|/r_i)^2]} \]
\(r_i=\bar\ell_i\max(0.25,m)\)，\(\bar\ell_i\) 是顶点局部平均边长， \(m\) 是当前 scale 的 radius multiplier。

对称矩阵按 \(\lambda_0\ge\lambda_1\ge\lambda_2\ge0\) 排序。 最大特征值对应主法向，最小特征值的 eigenvector 作为 crease tangent。

\[ S_{\text{surface}}=\max(0,\lambda_0-\lambda_1),\quad S_{\text{crease}}=\max(0,\lambda_1-\lambda_2),\quad S_{\text{corner}}=\lambda_2 \] \[ S_k=\max(S_{\text{crease}},S_{\text{corner}}) \] \[ \bar S=\frac1K\sum_{k=1}^{K}S_k,\qquad S_{\max}=\max_k S_k \] \[ P=\frac{\#\{k:S_k\ge\tau\}}{K},\qquad S_{\text{persistent}}=(0.65S_{\max}+0.35\bar S)P \]
代码见 NormalTensor.cpp:13-139； \(\tau\) 是调用方传入的 normal-tensor threshold。 
for each face f:
    if degenerate(f): continue
    T_face = normal(f) * transpose(normal(f))
    for vertex i in f:
        tensor[i] += area(f) * T_face
        weight[i] += area(f)
normalize tensor[i] by weight[i]

for scale k in 0..K-1:
    eigenvalues, eigenvectors = selfAdjointEigenSolve(tensor[i])
    score[k] = max(lambda0-lambda1, lambda2)
    vote[k] = score[k] >= threshold
    if another scale remains: gaussianSmoothTensorField()
数值例子： 某尺度 eigenvalues 为 \((0.80,0.18,0.02)\)，则 \(S_{\text{surface}}=0.62\)、\(S_{\text{crease}}=0.16\)、 \(S_{\text{corner}}=0.02\)，该点更像 crease。 三尺度分数为 \((0.30,0.24,0.18)\)，阈值 \(0.16\)，则 \(\bar S=0.24\)、\(P=1\)，persistent score \(=(0.65\times0.30+0.35\times0.24)=0.279\)。

Normal-tensor 顶点证据如何物化为 edge

\[ \min(P_a,P_b)\ge P_{\min},\qquad \min(S_a^{persistent},S_b^{persistent})\ge\tau \] \[ S_{\text{crease},a}\ge S_{\text{corner},a},\quad S_{\text{crease},b}\ge S_{\text{corner},b} \] \[ \max\left(|\mathbf d^\mathsf T\mathbf t_a|, |\mathbf d^\mathsf T\mathbf t_b|\right)\ge\alpha_{tensor} \]
\(\mathbf d=(p_b-p_a)/\|p_b-p_a\|\)。注意这里取两端 alignment 的较大值， 比 smooth-curvature 的双端最小值门槛更宽松。代码见 FeatureEvidence.cpp:166-215。

4. Smooth curvature：三次 Monge patch 到 ridge/valley edge

4.1 局部坐标与尺度归一化

对中心点 \(p_0\)，取局部法向 \(\mathbf n\) 和切平面基 \((\mathbf u,\mathbf v)\)。邻域半径由 topology ring 与局部平均边长共同确定：

\[ r=\max(\bar\ell_0\cdot\text{ringCount},10^{-12}) \] \[ u_i=\frac{(p_i-p_0)^\mathsf T\mathbf u}{r},\quad v_i=\frac{(p_i-p_0)^\mathsf T\mathbf v}{r},\quad w_i=\frac{(p_i-p_0)^\mathsf T\mathbf n}{r} \]

4.2 九参数三次 Monge 拟合

\[ w(u,v)= c_0u^2+c_1uv+c_2v^2+c_3u+c_4v+ c_5u^3+c_6u^2v+c_7uv^2+c_8v^3 \] \[ \min_{\mathbf c}\sum_i \omega_i \left(\mathbf a_i^\mathsf T\mathbf c-w_i\right)^2,\qquad \omega_i=\exp[-(u_i^2+v_i^2)/2]\,\omega_i^{robust} \] \[ (\mathbf A^\mathsf W\mathbf A)\mathbf c= \mathbf A^\mathsf W\mathbf w \]
至少需要 9 个有效邻域点。源码用 9×9 LDLT，并要求最小 pivot \(>10^{-13}\max(1,\text{maxPivot})\)，否则认为拟合秩亏。

鲁棒迭代采用 MAD 尺度和 Huber 式权重：

\[ \sigma=\max\!\left(10^{-8},1.4826\cdot \operatorname{median}_i|r_i|\right),\qquad c=1.5\sigma \] \[ \omega_i^{robust}= \begin{cases} 1,&|r_i|\le c\\ c/|r_i|,&|r_i|>c \end{cases} \]
代码见 SmoothCurvature.cpp:206-388。

4.3 第一/第二基本形式与主曲率

在中心 \((u,v)=(0,0)\)，令 \(d=c_3,e=c_4\)，得到：

\[ \mathbf I= \begin{bmatrix} 1+d^2&de\\de&1+e^2 \end{bmatrix}, \qquad n_z=\frac1{\sqrt{1+d^2+e^2}} \] \[ \mathbf {II}= \begin{bmatrix} 2c_0n_z&c_1n_z\\ c_1n_z&2c_2n_z \end{bmatrix} \] \[ \mathbf {II}\,\mathbf q_k=\kappa_k\,\mathbf I\,\mathbf q_k \]
generalized self-adjoint eigenproblem 给出两条带符号主曲率 \(\kappa_k\) 和参数平面方向 \(\mathbf q_k=(t_1,t_2)\)。

4.4 三次项给出 extremality

\[ e_k = 6\left( c_5t_1^3+c_6t_1^2t_2+c_7t_1t_2^2+c_8t_2^3 \right) \]
这是当前实现的三阶方向形式，近似表达沿主方向的曲率变化。 参考家族为 M014、M021、M042-M044；实现细节以源码为准。

4.5 ridge/valley 支配性、零交叉与 cyclideness

\[ \text{ridge: }\kappa_{max}>|\kappa_{min}|,\qquad \text{valley: }\kappa_{min}<-|\kappa_{max}| \] \[ e_c\,e_n<0 \] \[ C_{cross}=\frac{|e_c|+|e_{n\rightarrow c}|}{2} \ge 0.15\,\kappa_c^2 \] \[ e_{n\rightarrow c}=e_n\left(\frac{r_c}{r_n}\right)^2 \] \[ E_{cn}=C_{cross} \frac{|(p_n-p_c)^\mathsf T\mathbf t_c|}{r_c},\qquad E=\max_{n\in N(c)}E_{cn} \]
邻点 extremality 先换算到中心点尺度。因为 \(\widehat\kappa=r\kappa_{phys}\)、\(\widehat e=r^2e_{phys}\)， \(C_{cross}/\kappa^2\) 对 mesh 的均匀缩放不变。通过 cyclideness 门控后， 代码再乘 edge 沿极值方向的无量纲切向跨度，得到进入单尺度分数的 crossing strength \(E\)。

4.6 单尺度分数

\[ A_\kappa= \operatorname{clamp}\!\left( \frac{|\kappa-\kappa_{other}|} {|\kappa|+|\kappa_{other}|+0.025},0,1\right) \] \[ R_e= \operatorname{clamp}\!\left( \frac{E}{|\kappa|+0.025},0,1\right),\qquad Q_{fit}=\frac1{1+25\,r_{fit}} \] \[ S=\min(|\kappa|,4)\sqrt{A_\kappa R_e}\,Q_{fit} \]
\(E\) 是通过零交叉、一阶极大与 cyclideness 门控后的最大 crossing strength； \(r_{fit}\) 是空间权 RMS 拟合残差。代码见 SmoothCurvature.cpp:441-574。
单尺度数值例子： 取 \(\kappa=0.8\)、另一主曲率 \(0.1\)、\(C_{cross}=0.12\)、 无量纲切向跨度为 1、fit residual \(0.01\)，于是 \(E=0.12\)。cyclideness 门槛为 \(0.15\times0.8^2=0.096\)，所以 \(C_{cross}=0.12\) 通过。 \(A_\kappa\approx0.757\)、\(R_e\approx0.145\)、\(Q_{fit}=0.8\)， 最终 \(S\approx0.212\)，明显高于默认 smooth threshold \(0.015\)。

4.7 稳定尺度与 persistence

\[ \tau_r=\max(\tau_{abs},0.30S_r) \] \[ \operatorname{support}(k|r)= [\,\text{valid}_k\,]\,[\,sign_k=sign_r\,]\, [\,S_k\ge\tau_r\,]\, [\,|\mathbf t_k^\mathsf T\mathbf t_r|\ge\alpha_t\,] \] \[ \operatorname{stability}_r= \frac{N_{support}}{K}\cdot \overline{|\mathbf t_k^\mathsf T\mathbf t_r|}\cdot \frac1{1+r_{fit,r}} \] \[ J_r=S_r \begin{cases} 1,&\text{peak-score mode}\\ 0.5+0.5\,\operatorname{stability}_r,&\text{stable-scale mode} \end{cases} \] \[ S_{persistent}= \left(0.65S_r+0.35\overline{S}_{support}\right) \frac{N_{support}}{K} \overline{|\mathbf t_k^\mathsf T\mathbf t_r|} \]
参考尺度取 \(J_r\) 最大者；并列时依次取 raw score 更高、scale index 更小者。 支持尺度不要求相邻，最粗尺度没有否决权。代码见 SmoothCurvature.cpp:155-203, 638-700。

4.8 Smooth-curvature edge 接受公式

\[ \min(P_a,P_b)\ge P_{\min},\quad \min(S_a^{persistent},S_b^{persistent})\ge\tau_s,\quad sign_a=sign_b\ne0 \] \[ \min(|\mathbf d^\mathsf T\mathbf t_a|, |\mathbf d^\mathsf T\mathbf t_b|)\ge\alpha_e,\qquad |\mathbf t_a^\mathsf T\mathbf t_b|\ge\alpha_t \]
与 normal tensor 不同，这里要求两端都和 edge 对齐，因此使用 alignment 的较小值。 代码见 FeatureEvidence.cpp:218-267。

5. Graph cleanup、弱 spur 强度与跨 component consolidation

5.1 弱 spur 强度

\[ \Delta s_i=\frac{\|p_{i+1}-p_i\|} {(\bar\ell_i+\bar\ell_{i+1})/2} \] \[ q_i=\max\left( \frac{P^{tensor}_i}{\tau_{tensor}}, \frac{P^{curvature}_i}{\tau_{curvature}}\right) \] \[ T=\left(\sum_i\Delta s_i\right) \left(\sum_i q_i\Delta s_i\right) \]
当 featureGraphMinWeakSpurStrength > 0 时， \(T\) 低于阈值才删除；默认 0 保留旧的 edge-count 规则。 代码见 FeatureGraphCleanup.cpp:99-216。
数值例子： 两条单位归一化边、每条相对强度 0.8，则 \(T=(1+1)(0.8+0.8)=3.2\)。若阈值为 2，该长弱线保留。 一条单位边、强度 1.2 的短刺只有 \(T=1.2\)，会被删除。

5.2 endpoint gap / consolidation 的距离与方向

\[ d_{allow}=\rho\frac{\bar\ell_a+\bar\ell_b}{2} \] \[ \alpha_a=\mathbf o_a^\mathsf T \frac{p_b-p_a}{\|p_b-p_a\|},\qquad \alpha_b=\mathbf o_b^\mathsf T \frac{p_a-p_b}{\|p_a-p_b\|} \] \[ J_{bridge}= \frac{\|p_b-p_a\|}{d_{allow}}+ \frac{2-\alpha_a-\alpha_b}{2} \]
consolidation 按 \(J_{bridge}\) 从小到大贪心选一对一 bridge。 strong evidence 必须共享 source bit；ridge/valley 已知符号相反时拒绝； 两边都是弱 source 时允许兼容。代码见 FeatureGraphCompatibility.cpp 和 FeatureGraphConsolidation.cpp:67-159。

6. Junction continuation 与 surface patch

junction 上每个 branch tangent 都从 junction 指向相邻顶点。真正的直行 continuation 应是两个 outward tangent 反向，因此配对分数不是绝对 dot，而是：

\[ \alpha_{ij}=-\mathbf t_i^\mathsf T\mathbf t_j \] \[ \alpha_{ij}\ge0.65 \]
候选按 alignment 降序贪心匹配，每个 branch 最多进入一个 pair。 同侧近平行 branch 的 dot 接近 \(+1\)，所以 \(\alpha\approx-1\)，不会被误配。 代码见 FeatureGraph.cpp:204-309。

surface patch 将 active feature mesh edges 当作 face adjacency barrier。若 recovery bridge 不是原 mesh edge，它不会切断 face graph，并增加 segmentationIgnoredRecoveryEdges。剩余 face adjacency 上做 BFS： 

barriers = active graph edges that are also real mesh edges
if strongOnly:
    remove normalTensor/smoothCurvature-only barriers

for each unvisited face:
    create patch
    BFS across every two-face mesh edge not in barriers
    accumulate face count, area and area-weighted normal

for each barrier separating two patches:
    increment FeaturePatchAdjacency.featureEdges

代码见 FeatureSegmentation.cpp:16-158。 当前是 connectivity partition，不做 analytic plane/cylinder fitting，也不做 region merge。

7. Circle / ellipse primitive fitting 与分类

loop 先由 PCA 建立二维 frame，再把三维顶点投影并按 RMS scale 归一化。圆拟合优先 Taubin， 退化时回退 Kåsa；椭圆使用 Halíř-Flusser 直接最小二乘。

7.1 Kåsa 回退公式

\[ x_i^2+y_i^2=2c_xx_i+2c_yy_i+\gamma \] \[ r=\sqrt{\gamma+c_x^2+c_y^2} \]

7.2 Taubin 当前实现的 moments 与特征多项式

\[ z_i=x_i^2+y_i^2,\quad M_{xx}=\overline{x^2},\ M_{yy}=\overline{y^2},\ M_{xy}=\overline{xy},\ M_{xz}=\overline{xz},\ M_{yz}=\overline{yz},\ M_{zz}=\overline{z^2} \] \[ p(\eta)=a_0+\eta(a_1+\eta(a_2+\eta a_3)) \] \[ \eta_{k+1}=\eta_k-\frac{p(\eta_k)}{p'(\eta_k)} \] \[ \Delta=\eta^2-\eta M_z+(M_{xx}M_{yy}-M_{xy}^2) \] \[ c_x=\frac{M_{xz}(M_{yy}-\eta)-M_{yz}M_{xy}}{2\Delta},\quad c_y=\frac{M_{yz}(M_{xx}-\eta)-M_{xz}M_{xy}}{2\Delta} \] \[ r=\sqrt{c_x^2+c_y^2+M_z} \]
\(a_0\ldots a_3\) 的精确 moments 展开见 PrimitiveFit.cpp:143-218。 Newton 最多 32 次，若导数、determinant 或半径退化则回退 Kåsa。

7.3 Halíř-Flusser ellipse

\[ Ax^2+Bxy+Cy^2+Dx+Ey+F=0,\qquad 4AC-B^2>0 \] \[ \mathbf Q= \begin{bmatrix}A&B/2\\B/2&C\end{bmatrix},\qquad \mathbf c_e=(c_x,c_y)^\mathsf T \] \[ (\mathbf p-\mathbf c_e)^\mathsf T\mathbf Q(\mathbf p-\mathbf c_e)=-F_c \] \[ r_k=\sqrt{-F_c/\lambda_k(\mathbf Q)} \]
源码构造 \(S_1,S_2,S_3\) 并在 3×3 reduced system 上求 eigenvector， 只接受 \(4AC-B^2>0\) 的真椭圆；\(r_0,r_1\) 是两条半轴，较大者为 major radius。见 PrimitiveFit.cpp:243-350。

7.4 误差和分类

\[ e_i^{circle}= \left\|\left(\mathbf p_i-\mathbf c_c\right)- ((\mathbf p_i-\mathbf c_c)^\mathsf T\mathbf n)\mathbf n\right\|-r \] \[ e_i^{ellipse}= \left( \sqrt{\frac{x_i^2}{a^2}+\frac{y_i^2}{b^2}}-1 \right)\sqrt{ab} \] \[ e_i^{plane}=(\mathbf p_i-\mathbf c_c)^\mathsf T\mathbf n \] \[ E_{rms}=\sqrt{\frac1N\sum_i e_i^2} \] \[ R_{circle}=\frac{E_{radial,rms}+E_{plane,rms}}{r} \] \[ R_{ellipse}=\frac{E_{ellipse,rms}+E_{plane,rms}}{\sqrt{ab}} \]
\(\mathbf c_c\) 是圆拟合中心，\(\mathbf c_e\) 是椭圆拟合中心； \(x_i,y_i\) 是 \(\mathbf p_i-\mathbf c_e\) 在 major/minor 轴上的坐标， \(a,b\) 是对应半轴长度。两个中心都在同一拟合平面内，因此 plane residual 使用 \(\mathbf c_c\) 不改变结果。 circle 还要求 max error 不超过 \(\max(3\tau_{circle},0.08)\cdot r\)；ellipse 使用 \(\sqrt{ab}\) 作为尺度。代码见 PrimitiveFit.cpp:422-498。
分类例子： 半径 2 的 loop，radial RMS 0.01、plane RMS 0.005， 则相对 RMS \(0.015/2=0.0075\)，默认阈值 0.05 下通过 circle fit。 若 ellipse axis ratio 为 0.997，axis error 0.003，小于 \(\min(0.01,0.25\times0.08)=0.01\)，分类为 Circle； axis ratio 0.95 时为 NearCircle；明显低于 0.92 时会转为 Ellipse。

8. Component confidence 与 benchmark

\[ C_{closure}= \begin{cases} 1,&N_{endpoint}=0\\ \max(0,1-0.25N_{endpoint}),&cycleRank>0\\ 0.5\max(0,1-0.25N_{endpoint}),&cycleRank\le0 \end{cases} \] \[ C_{weak}=\max\left( \operatorname{clamp}\!\left(\frac{\overline P_{tensor}}{\max(\tau_{tensor},10^{-12})},0,1\right), \operatorname{clamp}\!\left(\frac{\overline P_{curvature}}{\max(\tau_{curvature},10^{-12})},0,1\right) \right) \] \[ C_{evidence}=\max(R_{strong},0.8C_{weak}) \] \[ C_{residual}= \begin{cases} \operatorname{clamp}(1-\overline r_{primitive}/0.12,0,1),& \text{有 primitive}\\ 0.5,&\text{无 primitive} \end{cases} \] \[ C=\operatorname{clamp}\left( 0.45C_{evidence}+0.25C_{closure}+ 0.20C_{residual}+0.10C_{weak}-P_{junction},0,1\right) \] \[ P_{junction}= \min(0.25,0.04\max(0,N_{junction}-2)) \]
代码见 FeatureGraphCleanup.cpp:444-494, 537-681。
数值例子： strong ratio 0.8、weak support 0.6、closure 1、primitive residual 0.02、 junction 不超过 2，则 residual score \(1-0.02/0.12=0.833\)， confidence \(=0.45(0.8)+0.25+0.20(0.833)+0.10(0.6)\approx0.837\)。

benchmark 使用标准分类指标：

\[ Precision=\frac{TP}{TP+FP},\qquad Recall=\frac{TP}{TP+FN},\qquad F_1=\frac{2PR}{P+R} \] \[ Accuracy_{patch}= \frac{\#\{\text{相邻 face 对的 same/different patch 判断正确}\}} {\#\{\text{已标注相邻 face 对}\}} \]
缺失 prediction 计错，不会因 truth 恰为 different patch 而获得正确计数。 代码见 FeatureBenchmark.cpp:46-200。

9. 特征识别如何进入 QEM

feature tangent 为单位向量 \(\mathbf t\)，通过 line quadric 惩罚点偏离穿过 \(p\) 且方向为 \(\mathbf t\) 的直线：

\[ E_{line}(x)= \left\|(\mathbf I-\mathbf t\mathbf t^\mathsf T)(x-p)\right\|^2 \] \[ Q_{feature}= w_{curve}\, (0.35+0.65C)\, A_{local}\, Q_{line} \]
\(C\) 是 component confidence，\(A_{local}\) 为顶点面积尺度。 即使 confidence 为 0，soft feature quadric 仍保留 35% 权重； 这和 hard FeatureProtectionMode 是两层机制。 代码见 Quadrics.cpp:33-54, 192-205。

Boundary edge incident faces 数为 1 即边界。 STL/CAD 三角网格边界抽取和工程对象边界 segmentation 是经典硬特征起点 P01 P09。 开放边界不一定是设计特征，也可能是破洞。

为什么强证据优先

NormalTensorEvidenceStrategy 和 SmoothCurvatureEvidenceStrategy 如果发现边已经是 boundary、dihedral 或 non-manifold，就直接返回；两个 candidate 函数还都会检查 discreteFeatureVertex，只要任一端点属于 boundary/non-manifold/强 dihedral，就拒绝弱边。这相当于在强 CAD 证据周围留出一个顶点宽的排除区，避免弱证据跨过硬边搭桥 C05 C30。两条弱路径独立执行，smooth strategy 不检查 edge.normalTensor，所以同一条非强证据边可以同时携带 normal-tensor 与 smooth-curvature 标记；后续 per-source 计数是证据通道计数，不一定等于唯一边数。

8. Smooth curvature 弱特征分支（opt-in）

本轮新增的第二条弱证据路径是确定性光滑曲率特征检测：用多尺度局部 quadric（Monge patch）拟合在光滑表面上找 ridge/valley 极值线。它没有任何 AI/学习成分，权威设计文档是 docs/design/smooth_curvature_feature_detection_2026_07_11.md，实现在 src/feature_detection/SmoothCurvature.cpp C29。

双路径理念：硬证据与弱光滑证据分开走，只在 FeatureGraph 汇合。 boundary、non-manifold、dihedral 是离散网格上的不连续；光滑 ridge/valley 是局部光滑表面上的微分事件。如果把两类原始分数直接混在一起，阈值会变得难以解释，噪声也会直接和强拓扑证据竞争。所以 ManuMesh 让硬证据（boundary / non-manifold / dihedral）和弱光滑证据（normal tensor / smooth curvature）各自打分、各自过滤，只在显式 FeatureGraph 上汇合——那里才有来源归属、连续性、junction、cleanup、component 和 confidence 可用。component 置信度把 normal-tensor 与 smooth-curvature 视为相互独立的弱支持（取两者中较强者作为 weak support），硬证据始终占主导 C12。

算法：逐顶点、逐拓扑尺度的九个步骤

  1. 构建 k-ring 邻域与面积加权局部法线；
  2. 用局部平均边长 × ring 数做坐标归一化；
  3. 带距离权与确定性 Huber 重加权拟合三次 Monge patch（9 系数：u², uv, v², u, v, u³, u²v, uv², v³），正规方程增量累加求解，替代每轮鲁棒迭代一次的稠密 QR；
  4. 由第一/第二基本形式解广义自伴特征问题，二次块给出两条带符号主曲率与方向；三次块解析给出 extremality e_i = ∇κ_i·t_i；
  5. 边零交叉极值判据（Ohtake）：主方向 line field 先做切向/extremality 符号同步；两端都通过曲率支配性测试（ridge 要求 κ_max > |κ_min|，valley 对偶）；extremality 沿近似跟随主方向的边变号并通过两端一阶极大测试；零交叉按 |e| 反比插值归属较小 |e| 的端点，使检测带保持一个顶点宽；
  6. cyclideness 门控（Yoshizawa M021 Eq.5-6）：零交叉处的插值 cyclideness 0.5(|e_center|+|e_neighbor|) 必须 ≥ 0.15·κ²（kMinCrossingCyclidenessRatio，e 与 κ² 同为 1/L² 量纲，比值无量纲、均匀缩放不变）。Dupin cyclide（球/柱/锥/环面）上 extremality 恒为零，符号变化只是离散化噪声——该门控让环面内侧曾经的伪 valley 带（24-48 段 max persistent 0.097→0.0）精确沉默；真 crest 的比值 p10 ≥ 0.38、环面伪交叉最大 0.06，阈值 0.15 对两侧各留约 2.5 倍裕量，高斯脊响应逐位不变；
  7. 打分融合尺度归一化曲率幅值、各向异性、极值对比度、拟合残差质量；
  8. 默认选最高分尺度为参照；opt-in stable-scale 模式改按跨尺度 sign/tangent/score 一致性选择，并可拒绝低于 minimum stability 的参考尺度。全部请求尺度仍独立投票，支持尺度不要求相邻，最粗尺度没有特殊否决权；
  9. 两端点在符号、切向、尺度支持、边对齐上都一致时，才把顶点证据转成 mesh-edge 证据。

Primitive 拟合逻辑

11. Component 置信度与诊断指标

component summary 对 trace graph 做 BFS，统计每个连通分量的 boundary/dihedral/tensor/smooth-curvature/non-manifold、cleanup/consolidation bridge、端点、junction、cycle rank、closure、persistence、primitive residual 和 confidence C12。

指标计算/语义用途
strongEvidenceEdgesboundary + dihedral + non-manifold。CAD/STL 离散证据强度。
weakEvidenceEdgesnormal tensor channel count + smooth curvature channel count + cleanup bridge count。同一条边可同时有两个弱 flag，因此该值可能大于唯一弱边数。弱支持通道总量，不应误读成去重后的边集合大小。

confidence threshold 是报告阈值，不是过滤器。 featureComponentMinConfidence 只决定 highConfidenceFeatureComponents 计数；QEM 简化的硬保护主要看 VertexFeature、primitive 和 FeatureProtectionMode。连续 confidence 会在 Quadrics.cpp:195 通过 0.35 + 0.65·confidence 温和缩放 feature-curve soft quadric，所以低置信 component 仍有至少 35% 的软支持，而不是被删除。

junction branch pairing

finalize 阶段为每个活动 incident edge 建立 outward branch tangent 和 signed kind，再优先配对最接近反向延续的分支。FeatureGraphBranchPair 保存 branch 索引和 alignment；剩余未配对分支使 junction 标记为 ambiguous。这一层让 benchmark 可以测 continuation topology，而不只测 junction 顶点集合。

surface patch segmentation（opt-in）

segmentation 以活动真实 mesh feature edge 为 face-adjacency barrier。strong evidence 始终可作 barrier，weak evidence 可通过 strong-only 模式排除。cleanup/consolidation bridge 若不是原 mesh edge，会被忽略并计数，避免空间恢复线段人为切开 faces。输出为 facePatchIds、FeaturePatch 和 FeaturePatchAdjacency；它是 connectivity partition，不包含 analytic surface fitting 或 region merge。

  • featureComponentMinConfidence 不过滤低置信 component；若产品策略需要“低于阈值不保护”，必须在消费层显式实现，不能依赖当前计数选项。
  • surface patch segmentation 依赖 barrier 完整性，当前不做 region merge 或 analytic surface fitting。
