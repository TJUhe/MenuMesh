1. 阅读范围和总览

ManuMesh 当前是一个 C++17 三角网格处理内核。可执行程序 manumesh 只是应用层消费者；真正的算法入口在 include/algorithms/feature_detection、include/algorithms/simplification 和 src/ 对应实现中。

主要源码阅读范围：
  • apps/manumesh/main.cpp、ManuMeshCli.cpp、ManuMeshCommands.cpp：CLI 入口、参数校验、命令注册和命令处理。
  • src/io/MeshIo.cpp：STL/OBJ 读取和 ASCII STL 写出。
  • src/feature_detection/*.cpp：特征边证据、trace graph、cleanup、loop/primitive 恢复、component 置信度。
  • src/simplification/*.cpp：QEM/line-quadrics 初始化、候选队列、动态拓扑、折叠合法性、结果 compact。
  • src/api/CApi.cpp、src/api/CApiConverters.cpp：C ABI 句柄、结构体 ABI 校验、异常到状态码转换。

2. 程序入口与命令分发

main() 只调用 manumesh::cli::run(argc, argv)。所有 CLI 异常在 run() 顶层捕获：打印 error: ... 和 usage，返回 1。 

flowchart TD
  A["main(argc, argv)"] --> B["manumesh::cli::run(argc, argv)"]
  B --> C{argc < 2 ?}
  C -- 是 --> D["printUsage()"] --> E["return 0"]
  C -- 否 --> F["command = argv[1]
args = argv[2..]"]
  F --> G["validateArgs(args)"]
  G --> H{validateArgs 抛异常?}
  H -- 是 --> Z["catch std::exception
打印 error + usage"] --> Z1["return 1"]
  H -- 否 --> I{command 是 help/-h/--help ?}
  I -- 是 --> D
  I -- 否 --> J["commandRegistry().find(command)"]
  J --> K{找到 handler ?}
  K -- 否 --> L["throw invalid_argument
Unknown command"] --> Z
  K -- 是 --> M["执行 handler(args)"]
  M --> N{handler 正常返回?}
  N -- 是 --> O["返回 handler 的 int"]
  N -- 否，抛异常 --> Z

参数校验规则

情况处理结果
参数不是以 - 开头视为 positional argument，不在 validateArgs 中校验。后续 handler 用 positionalArgs() 取出。
以 - 开头但不在已知 flag 集合validateArgs() 抛 invalid_argument("Unknown option")。顶层 catch，打印 usage，返回 1。
需要值的 flag 缺少值，或后面直接跟另一个已知 flag抛 invalid_argument("<flag> requires a value.")。返回 1。
数值参数解析失败或不是有限数parseIntStrict/parseDoubleStrict 抛异常。返回 1。
--industrial-safe在 parseSimplifyOptions() 中自动打开保守 guard：保边界、最小质量下限、法向偏转上限、本地误差比例下限、自交检查。参数被转换为更保守的简化策略。

每个命令的分支处理

命令主要流程特殊情况 / 失败处理输出
generate 读取 --type、--n、必需 --out；调用 generateMeshByName；保存 ASCII STL；打印 stats。 缺 --out 抛 invalid_argument；未知 generator type 返回 false 后转 runtime_error；保存失败也转 runtime_error。 一个 STL 文件。
simplify 要求 input output；解析 SimplifyOptions；读取 mesh；执行 QEMSimplifier::simplify；保存 STL；计算输入/输出 stats 和采样距离；可写 metrics CSV。 输入读取失败、简化参数非法、输入几何非法、输出保存失败都会抛出并由 CLI 顶层返回 1。 简化后 STL；可选 metrics CSV；stdout 打印 report 计数器。
compare 要求 original simplified；读取两个 mesh；计算简化 mesh stats；做双向采样距离。 任一 mesh 读取失败即失败。采样数 --samples 默认 3000。 stdout 距离和质量统计。
feature-report 要求输入 mesh；解析 FeatureOptions；执行 detectFeatureCurves；打印 feature counters 和每个 loop 的 CSV 行。 可选 --csv 时先创建父目录；检测参数非法会抛异常。 stdout 报告；可选 CSV。
feature-benchmark 要求 input labels.csv；读取 ground-truth edge/junction；检测特征；计算 precision/recall/F1。 label 文件打不开抛 runtime_error；CSV 中非整数行会被忽略，junction/junction_vertex 行作为 junction 标签。 stdout benchmark；可选 CSV。
feature-compare 检测 original 和 simplified 的 circular loops；对 original loop 逐个找 simplified 中未用的最佳 circular loop；按中心、半径、法向角判断匹配。 可疑匹配阈值：center ≤ 0.08*bboxDiag，radiusRel ≤ 0.20，normal ≤ 30°；更严格时标 matched，否则 weak_match；不满足则 missing。 stdout/CSV 的 loop 匹配表。
sweep 读取一次输入；解析 --weights；每个 weight 复制 base options，设置 lineWeight/useLineQuadrics，简化、保存 STL、写 metrics。 weight ≤ 0 且 mode 为 uniform 时关闭 line quadrics；否则开启。任一保存失败会中断整个 sweep。 多个 STL + metrics.csv。
ratio-sweep 读取输入；解析 --ratios；每个 ratio 设置 targetFaces=-1 和 targetRatio 后简化。 ratio ≤ 0 或 ≥ 1 不抛异常，只打印 skip invalid ratio 并继续。 多个 STL + metrics.csv。
face-sweep 读取输入；解析 --faces；每个目标面数设置 targetFaces 后简化。 targetFaces ≤ 0 不抛异常，只打印 skip 并继续。 多个 STL + metrics.csv。
demo 创建 demo 输入/输出目录；quick 模式只处理外部 flange；完整模式生成多种内置网格并运行多个 sweep/ratio/face sweep；最后汇总 metrics。 外部 flange 不存在或复制失败会抛异常；quick 默认 samples=500，完整默认 samples=1000。 output/demo_input、output/demo 下 STL/CSV。
validate-features 复制 spindle/ring/pulley/flange 四个外部 STL；每个 case 先 feature-report，再 line simplify、curve-preserving simplify，再 feature-compare。 任一外部输入不存在时失败；curve 版本会打开 --preserve-feature-curves 和 curve weight。 每个 case 的 feature CSV、两份 STL、metrics、feature compare CSV。
validate-external 在输入目录寻找 fandisk/rocker_arm/beetle/cow/suzanne OBJ；存在则逐个 report、line simplify、curve simplify、compare，并写 summary。 单个模型不存在只 skip；如果一个都没处理，最终抛 runtime_error。 external_summary.csv 和每个模型的输出。
summarize-metrics 递归找 metrics.csv，合并列集合和数据行。 输出根目录不存在时抛异常；空 metrics 文件会跳过。 默认 output/demo/demo_summary.csv。

证据类型判定条件处理结果
Boundary一条边只属于 1 个 face。标记 boundary=true，计入 boundary feature edges。
Non-manifold一条边属于超过 2 个 face。标记 nonManifold=true，后续 trace graph 会直接纳入。
Dihedral两个相邻 face 法向夹角达到 featureAngleDeg。标记 dihedral=true，并尝试判断 convex/concave/unknown。
Normal tensor不是已有离散特征边；两端 persistent score 达阈值；crease saliency 不弱于 corner；边方向与 crease tangent 对齐。作为弱特征候选，计入 normal tensor counters。

trace graph 和 cleanup

阶段分支规则记录/输出
buildTraceGraph boundary、non-manifold、normal-tensor 边直接进入 trace graph；dihedral 边还必须满足 loopTraceAngleDeg，若该参数为负则复用 featureAngleDeg。 进入的边计 tracedFeatureEdges；未进入的 dihedral 证据计 untracedFeatureEdges。
removeWeakSpurs 如果 cleanupFeatureGraph=false 或 featureGraphMaxWeakSpurEdges<=0，跳过；否则最多 8 轮删除短的 tensor-only 端点 spur。 被删边在 graph edge 上标 removedByCleanup，计 graphCleanupRemovedSpurs。
bridgeCloseJunctions 如果 gap ratio ≤ 0 跳过；junction 数少于 2 或超过 256 跳过；距离在局部尺度阈值内则加 cleanup bridge。 计 graphCleanupMergedJunctions。
bridgeEndpointGaps 端点数少于 2 或超过 512 跳过；端点距离和方向兼容才桥接；每个端点最多被用一次。 计 graphCleanupBridgedGaps。

flowchart TD
  A["recoverFeatureLoops"] --> B["junction 间双链组合

  B --> C["small cycle basis

  C --> D["traceRemainingFeatureLoops"]
  D --> D1{从 junction/endpoint 出发?}
  D1 -- 是 --> D2["traceOpenChain"]
  D1 -- 否 --> D3["剩余边 traceClosedLoop"]
  D2 --> E["addTracedLoop"]
  D3 --> E
  E --> F{闭合且顶点数达标?}
  F -- 是 --> Fit["fitPrimitive

  F -- 否 --> Assign["assignLoopToVertices

情况处理
loop 顶点少于 minFeatureLoopVertices很多闭环恢复和 primitive fallback 会跳过，避免把短碎片当成制造特征。
primitive fit 失败applyPrimitiveFit 不写入 primitive 数据，loop 保持 unknown/polygonal 状态，仍可作为普通 trace loop 存在。
圆拟合 RMS/最大误差过大不标为 circle/near-circle；可能落为 ellipse 或 polygonal loop。
组件已存在 circular looprecoverPrimitiveComponents 和 circular cluster fallback 会跳过，避免重复 loop。
circular cluster fallback 过大组件顶点数超过 120 或三点扫描超过 32768 次时停止，保证最坏情况可控。

6. QEM 简化流程

公共入口是 QEMSimplifier::simplify 或 simplifyMesh。它先校验选项和输入，然后创建 SimplificationRun 执行一次完整简化。 

flowchart TD
  A["QEMSimplifier::simplify(input, report)"] --> B["validateSimplifyOptions(options)"]
  B --> C["validateSimplifierInput(input)"]
  C --> D["SimplificationRun(input, options, optional features)"]
  D --> E["execute()"]
  E --> R["initializeReport"]
  R --> F["analyzeFeatures
仅 preserveFeatureCurves 时启用"]
  F --> V["initializeVertices
initial quadrics + boundary flags + feature ownership"]
  V --> FS["initializeFaces
DynamicTopology + optional SpatialFaceIndex"]
  FS --> Budget["initializeBudget
targetFaces / areaEps / normalDot / localError / rejection limit"]
  Budget --> Q["rebuildQueue
collectActiveEdges + pushEdge"]
  Q --> Loop["collapseUntilTarget"]
  Loop --> Compact["compactResult"]
  Compact --> Out["填 finalVertices/finalFaces
复制 report
返回 Mesh"]

简化选项校验

选项合法范围 / 处理
targetFaces必须为 -1 或正数；为正时覆盖 targetRatio。
targetRatio当 targetFaces<0 时必须在 (0, 1]。
权重类数值lineWeight、featureBoost、boundaryWeight、featureCurveWeight 等必须有限且非负。
特征检测参数通过 featureOptionsFromSimplifyOptions 转成 FeatureOptions 后复用特征检测校验。
minTriangleQuality必须在 [0, 1]；0 表示关闭三角形质量硬过滤。
maxNormalDeviationDeg必须在 [0, 180]；180 等价于关闭法向偏转过滤。

终止原因触发条件
AlreadyAtOrBelowTarget一开始 active face count 已经小于等于目标，且没有发生折叠。
ReachedTarget折叠后达到目标；或一开始已达目标但此前 report 中已有折叠记录。

9. 统一失败处理索引

层级失败类型程序处理方式用户看到什么
CLI 参数层未知命令、未知选项、缺少必需值、数值解析失败。抛 invalid_argument；run() catch。stderr 显示 error: ... 和 usage，进程返回 1。
CLI 文件层输入文件打不开、格式错误、输出目录创建失败、输出 STL 打不开。I/O 函数返回 false + error；handler 转 runtime_error。stderr 显示具体 error，返回 1。
mesh 校验索引越界、非有限顶点、退化 face、零面积 face。validateMeshGeometry false 或 simplifier 抛 invalid_argument。CLI 返回 1；C API 返回 INVALID_ARGUMENT。
特征检测阈值非法、min loop vertices 过小、tensor 参数非法。validateFeatureOptions 抛异常。CLI 返回 1；简化入口中也会拒绝非法 feature 相关选项。
简化初始化targetFace/ratio 非法、质量/误差/法向参数非法、拓扑构建失败。validateSimplifyOptions 或 validateSimplifierInput 抛异常。CLI 返回 1；C API 返回 INVALID_ARGUMENT。
简化运行候选全部耗尽。不抛异常；report.terminationReason = NoCandidates。输出当前可达简化结果和 report。
简化运行连续候选被硬约束拒绝太多。不抛异常；report.terminationReason = RejectionLimit。输出当前结果；report 中有各类 rejected counter。
批处理命令ratio-sweep 中 ratio 非法，或 face-sweep 中目标面数非法。打印 skip，不抛异常，继续处理其他值。该条没有输出 STL/CSV 行；命令仍可能成功。
validate-external单个候选 OBJ 不存在。打印 skip 并继续。如果至少处理一个模型，命令成功；如果一个都没有，最终抛异常返回 1。
读 report 的要点：简化失败不一定是程序错误。NoCandidates 和 RejectionLimit 都是“当前参数和约束下无法继续折叠”的正常诊断状态，应结合 featureRejectedCollapses、boundaryRejectedCollapses、topologyRejectedCollapses、qualityRejectedCollapses、errorRejectedCollapses 等计数判断是哪类约束过强。
