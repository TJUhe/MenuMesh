QEM 二次型展开速查：当前到底加了哪些项

ManuMesh 当前把所有软几何成本统一累积到齐次二次型。设 x 是候选新顶点位置，x_h=[x,1]^T，每个顶点保存 Q=[[A,b],[b^T,c]]，则候选代价为 E(x)=x_h^T Q x_h=x^T A x+2 b^T x+c。折叠边 (i,j) 时先做 Q_edge=Q_i+Q_j，再解 A x=-b；若谱条件（minEval/maxEval > 1e-12）拒绝全空间最优，先尝试沿折叠边的一维最优 t* = (rhs·d − dᵀA a)/(dᵀA d)（rank-2 quadric——直棱、边界折痕——的良定情形，分母用尺度不变相对阈值判定），仍失败才落回端点/中点候选；边界边坍缩的 placement 另按 Lindstrom-Turk 边界守恒约束投影（src/simplification/Placement.cpp）。

二次型项展开到 A,b,c参数与默认值作用与引用
面平面 QEMpi=[n,-n.p]，Q += area/3 * pi*pi^T。等价于 E=a(n.x-n.p)^2，所以 A+=a nn^T、b+=-a(n.p)n、c+=a(n.p)^2。无独立开关；退化面使用 1e-6 * representativeArea * pointQuadric，保持与正常 QEM 相同的 L^4 缩放量纲。主几何误差，来自 M002 Garland-Heckbert 1997。
普通 Line QuadriclineQuadric(p,n) 取两个与局部法线 n 垂直的单位方向 u,v，加入 Q_l=pi_u*pi_u^T+pi_v*pi_v^T。展开为 E_l=||(I-nn^T)(x-p)||^2，即惩罚切向漂移。useLineQuadrics=true，lineWeight=1e-3。默认分支：Q_i += w_i area_i Q_l。补平坦区 QEM 切向不满秩问题，来自 M004 Liu-Rahimzadeh-Zordan 2025。
特征加权 Line Quadric非 uniform 模式下 w_i=lineWeight+featureBoost*s_i；s_i 来自 dihedral、normal-tensor persistence、height 或 xband。normal-tensor 模式只给满足 normalTensorMinPersistentScales 的顶点写入 persistent score。weightMode=uniform，featureBoost=0.05；常用调试值 dihedral/normal-tensor + 0.08。featureAngleDeg=40，normalTensorFeatureThreshold=0.16，normalTensorScaleCount=1。让硬边、弱 ridge 或指定区域获得更高排序成本；feature evidence 参考 M007/M012/M013/M015/M016，弱特征参考 M026。
Adaptive Scale 分支（Wang 2008 解耦）若 adaptiveScale=true，quadric 只加干净的 adaptiveBaseLineWeight*area_i*Q_l 基础项；featureBoost 不再放大 quadric（旧行为会扭曲 placement），改为逐顶点 priorityScale = 1 + max(0,featureBoost)*s_i，只乘候选队列的排序代价（取折叠边两端点最大值，折叠时按 max 传播到 keep 端）。adaptiveScale=false，adaptiveBaseLineWeight=1e-2。非 adaptiveScale 路径 featureBoost 仍按旧行为加进 line weight。Wang 2008 优先级/placement 解耦：排序看特征，placement 求解不受特征权重污染；实现见 Quadrics.cpp 与 CandidateQueue.cpp。
边界 Plane Quadric边界边 (a,b) 只有一个邻接面时，取 m=normalize(n_face x e_hat)，加入 Q_b=boundaryWeight*|e|^2*pi_m*pi_m^T 到两个端点。它的 A=boundaryWeight*|e|^2*mm^T，秩 1；边长平方使该项与面积加权 face QEM 同为 L^4 缩放量纲。boundaryWeight=0.0 默认关闭；常用 1-10。硬边界保护另看 preserveBoundary。减少开放边界沿面内法向漂移；扩展 QEM 思路参考 M003，工程 guards 参考 M030-M033。
特征曲线 Tangent-Line Quadric当检测到 loop/primitive 后，对特征顶点用切线 t 调用 lineQuadric(p,t)，即 E_curve=eta*rho*area*||(I-tt^T)(x-p)||^2。这里 rho=0.35+0.65*confidence。preserveFeatureCurves=false 默认关闭；featureCurveWeight=0.05，常用 0.08；featureComponentMinConfidence=0.35 只影响 high-confidence component 报告计数，不过滤 component 或保护。允许沿特征线滑动，惩罚离开曲线；组合 M004 line quadrics、M016 CAD feature line、M026 weak-feature consolidation、M028/M029 feature-preserving simplification。
Primitive 投影与硬过滤圆/椭圆/多边形不是当前 Quadrics.cpp 里的单独径向二次型；当前代码用 tangent-line quadric 排序，再由 projectToCircle/projectToEllipse/projectToPolygonal、maxFeatureCurveDeviationRatio 和 featureProtectionMode 控制最终位置与是否拒绝折叠。maxFeatureCurveDeviationRatio=0 表示关闭曲线漂移预算；featureProtectionMode=PrimitiveCurves。圆/椭圆阈值默认均为 0.05。把“软成本排序”和“硬合法性保护”分开，符合 M030-M033 edge-collapse 工程建议。
纹理失真标量项（不进 quadric 矩阵）启用 preserveTexture 且网格带逐角 UV 时，排序代价变为 E_total(p)=E_geometry_4x4(p)+textureWeight*E_uv_local(p)，其中 E_uv_local=edgeLength^2*Σ(faceArea*cornerUvDisplacement^2)/meanLocalUvEdgeLength^2。它是排序期按候选 placement 现算的标量附加项，不展开进 A,b,c，不改变 Mat4 维度与 placement 求解；chart 配对/UV 定向/有符号面积检查作为硬过滤另行拒绝坍缩。preserveTexture=false 默认关闭（关闭时与旧无纹理路径 bit-exact）；textureWeight=1.0，textureSeamTolerance=1e-8，minTextureAreaRatio=1e-8。诊断：textureProtectedEdges、textureRejectedCollapses。仅 C++ API，CLI 未暴露。不走 M003 属性扩维（n×n quadric）路线；按 M033 工程拆分做局部标量排序项 + 显式合法性策略，与 M004/085 的 4×4 line-quadric 主干兼容。实现 src/simplification/TextureProtection.cpp，设计 docs/design/texture_aware_qem.md。
带合理参数的数值展开例子

为了看清量级，假设坐标单位是 mm，某顶点 p=(10,5,0)，barycentric 顶点面积 a_i=2.0，候选新位置写作 x=(x,y,z)。实际折叠候选会把两端点 Q_i+Q_j 相加；下面先看单个顶点的一项怎样进入 A,b,c。

例子代入参数展开后的二次型读法
面平面 QEM平面 z=0，n=(0,0,1)，a=2.0E_plane=2*z^2，A=diag(0,0,2)，b=(0,0,0)，c=0离开面法向 0.2 mm 的代价是 2*0.2^2=0.08。
普通 Line QuadriclineWeight=1e-3，n=(0,0,1)，a_i=2.0，所以 alpha=0.002E_line=0.002*((x-10)^2+(y-5)^2)，A=diag(0.002,0.002,0)，b=(-0.02,-0.01,0)，c=0.25切向漂移 1 mm 只加 0.002，它是稳定排序的小正则项，不应压过平面 QEM。
特征加权 Line QuadricweightMode=normal-tensor，persistent score s_i=0.6，lineWeight=0.001，featureBoost=0.08，得 w_i=0.001+0.08*0.6=0.049，alpha=0.098E_feature_line=0.098*((x-10)^2+(y-5)^2)，A=diag(0.098,0.098,0)，b=(-0.98,-0.49,0)，c=12.25同样 1 mm 切向漂移，代价从 0.002 升到 0.098，约 49 倍；这就是弱特征被 QEM 排序“看见”的方式。
边界 Plane Quadric边长 |e|=4，boundaryWeight=5，边界面内法向 m=(1,0,0)，得 alpha=20E_boundary=20*(x-10)^2，A=diag(20,0,0)，b=(-200,0,0)，c=2000边界沿面内法向漂移 0.2 mm 的代价是 20*0.2^2=0.8，明显比普通 line 正则强。
特征曲线 Tangent-Line Quadric切线 t=(0,1,0)，featureCurveWeight=0.08，component confidence 0.8，rho=0.35+0.65*0.8=0.87，alpha=0.08*0.87*2=0.1392E_curve=0.1392*((x-10)^2+z^2)，A=diag(0.1392,0,0.1392)，b=(-1.392,0,0)，c=13.92沿 y 方向滑动不罚，离开特征线横向/法向才罚；这是“允许沿孔边走，但不要偏离孔边”。

例如同一个候选位移 x=(11,5,0.2)：平面项给 0.08，普通 line 项只给 0.002，normal-tensor 特征加权 line 项给 0.098。所以默认 line quadric 是温和正则；一旦 feature score 和 featureBoost 介入，它才会变成明显影响 collapse 排序的特征保护成本。

为什么识别到边界、dihedral 或 normal-tensor 特征后要提高 Line Quadric 权重

先把一个容易误解的点说清楚：提高 lineWeight 或 featureBoost，确实会改变 A x=-b 的最小误差位置。它会让位置从“纯 plane QEM 的最优点”偏向“更靠近原顶点法线支撑线、切向漂移更小”的点。因此这不是免费的精度提升，而是一个有意加入的软正则项。M004 line quadrics 的核心价值，正是给标准 QEM 在平坦或近似平坦区域缺失的切向方向补一个小惩罚；M030-M033 的 edge-collapse 工程路线也强调，QEM/line quadrics 负责候选排序，真正危险的 collapse 仍要交给拓扑、边界、特征和质量过滤器。

当前代码里，weightMode=dihedral 会把开边界边记为 score=1，把超过 featureAngleDeg 的二面角边按强度写入端点分数；weightMode=normal-tensor 则使用满足 normalTensorMinPersistentScales 的 persistent feature score。随后普通 line quadric 的权重变成 w_i=lineWeight+featureBoost*s_i。这意味着边界、硬折痕、弱 ridge 附近的候选点，如果试图沿局部切平面大幅滑走，会在优先队列里付出更高代价。

疑问准确回答对应代码/参数
为什么识别到特征还要加 line 权重？因为 plane QEM 主要惩罚离开局部平面，很多特征破坏发生在切向：点沿表面滑过折痕、孔边被拖圆、边界轮廓缩进。Line quadric 惩罚 ||(I-nn^T)(x-p)||^2，正好给这种切向漂移加成本。Quadrics.cpp::lineQuadric，lineWeight，featureBoost
这会不会让最小误差位置更偏？会。它会偏离纯 plane QEM 的最优点，但这个偏移的方向是“少做切向漂移”。如果纯 plane QEM 本来在切向不满秩或近似不满秩，那么这个偏移反而让候选 placement 更稳定。solvePlacementCandidates() 用合并后的 Q_i+Q_j 求解
为什么特征附近要比普通平面更强？普通平面内的小滑动通常视觉影响不大；特征线附近同样大小的滑动可能跨过 CAD patch boundary、浅 ridge 或孔边。提高 w_i 让这些 collapse 排序靠后，给非特征区域优先被简化的机会。w_i=lineWeight+featureBoost*s_i
边界线也靠 line 权重保护吗？不是只靠它。开边界在 dihedral weight mode 下会得到高 feature score，从而减少切向漂移；但真正的边界形状和拓扑还要看 boundaryWeight 的边界 plane quadric、preserveBoundary 的硬策略和 topology guards。addBoundaryQuadrics()，preserveBoundary
normal tensor 弱特征会不会误检后过度保护？会有这个风险。normal-tensor 路径用 persistent score、最少支持尺度和 edge alignment 降低单尺度噪声；component confidence 在 Quadrics.cpp:195 通过 0.35 + 0.65·confidence 连续缩放软 quadric。注意 featureComponentMinConfidence 只是报告阈值，不会过滤弱特征或关闭保护。normalTensorFeatureThreshold，normalTensorMinPersistentScales，VertexFeature::confidence

可以用一个二维化的例子看直觉。假设局部平面是 z=0，纯 plane QEM 是 E_plane=2*z^2。候选点从 (10,5,0) 滑到 (11,5,0) 时，纯 plane QEM 代价仍是 0，因为它没有离开平面。加入普通 line quadric 后，代价多出 0.002；如果 normal-tensor persistent score 是 0.6 且 featureBoost=0.08，同样 1 mm 切向滑动代价变成 0.098。这并不是说几何误差突然大了 49 倍，而是系统在告诉优先队列：“这里像特征支撑，不要把切向漂移很大的 collapse 排得太靠前。”

因此正确的调参原则不是“特征越强，line 权重越大越好”。更稳的顺序是：保持基础 lineWeight 小，让它只修补平坦区病态；让 featureBoost 只放大高置信的 dihedral/normal-tensor 证据；把圆、椭圆、polygonal loop 交给 featureCurveWeight、primitive projection 和 hard feature policy；最后用 feature_rejected、generic_feature_rejected、max_orig_to_simp 和 feature drift 去判断是否过度保护。这个取舍也对应 M026 弱特征整合和 M030-M033 collapse guards 的思路：先让特征证据形成可靠 support，再决定软成本、硬保护或后处理投影。

因此当前总能量可读成：E = E_plane + E_line(weightMode) + E_boundary + E_feature_curve，启用 preserveTexture 时再加排序期标量项 textureWeight*E_uv_local；拓扑、边界、特征保护、法向翻转、三角形质量、局部误差、自交检查以及纹理 chart/有符号 UV 面积检查不是二次型项，而是候选折叠通过 QEM 排序之后的硬过滤。

1问题背景

三角网格是 3D 图形学中最常用的曲面表示。一个精细模型可能有数百万个三角形，但在很多场景下（LOD、移动端渲染、物理仿真）只需要几千个。网格简化就是在尽量保持外观的前提下减少三角形数量。

最主流的方法是 迭代边坍缩（iterative edge collapse）：每次找一条"最不重要的边"，把两端顶点合并成一个，减少一个顶点和两个三角形。重复直到达到目标数量。

核心问题是：怎么衡量一条边重不重要？ QEM（Quadric Error Metric, Garland & Heckbert 1997）给出了经典答案。

23D QEM 基础：从平面到顶点

2.1 点到平面的距离

3D 中一个三角面片 $ijk$ 定义了一个平面。设平面单位法向量为 $\hat{n}_{ijk}$，面上一点为 $v_i$。任意点 $x \in \mathbb{R}^3$ 到该平面的距离为：

$d = \hat{n}_{ijk}^\top (x - v_i)$ (1)

平方距离（即误差）：

$E_{ijk}(x) = \big(\hat{n}_{ijk}^\top (x - v_i)\big)^2$ (2)

2.2 写成二次型

展开 (2)：

$E_{ijk}(x) = x^\top (\hat{n}\hat{n}^\top) x - 2(\hat{n}\hat{n}^\top v_i)^\top x + v_i^\top \hat{n}\hat{n}^\top v_i$ (3)

令 $A = \hat{n}\hat{n}^\top$（3×3），$\mathbf{b} = -\hat{n}\hat{n}^\top v_i$（3×1），$c = v_i^\top \hat{n}\hat{n}^\top v_i$（标量），则：

$E_{ijk}(x) = x^\top A\, x + 2\mathbf{b}^\top x + c$ (4)

用齐次坐标 $\bar{x} = [x, 1]^\top \in \mathbb{R}^4$，定义 三角面 quadric（4×4 矩阵）：

$$Q_{ijk} = \begin{bmatrix} A & \mathbf{b} \\ \mathbf{b}^\top & c \end{bmatrix} = \begin{bmatrix} \hat{n} \\ -\hat{n}^\top v_i \end{bmatrix} \begin{bmatrix} \hat{n} \\ -\hat{n}^\top v_i \end{bmatrix}^\top$$ (5)
关键观察

$Q_{ijk}$ 是 秩 1 矩阵（外积 $\mathbf{p}\mathbf{p}^\top$，其中 $\mathbf{p} = [\hat{n},\; -\hat{n}^\top v_i]^\top \in \mathbb{R}^4$）。误差计算简化为：

$E_{ijk}(x) = \bar{x}^\top Q_{ijk}\, \bar{x}$(6)

2.3 顶点 Quadric：邻接面加权求和

顶点 $i$ 的邻接三角面集合记为 $N_i$（one-ring faces）。顶点 quadric 是邻接面 quadric 的加权求和，权重为 barycentric area $a^i_{jk} = a_{jk}/3$（面面积的三分之一）：

$$Q_i = \sum_{ijk \in N_i} a^i_{jk} \, Q_{ijk}$$ (7)
面积加权的原因

不加权的 QEM 对大三角形和小三角形一视同仁。面积加权让大三角面对误差贡献更大，更符合"外观保持"的直觉。

此时顶点 $i$ 的误差为：

$E_i(x) = \bar{x}^\top Q_i \, \bar{x} = \sum_{ijk \in N_i} a^i_{jk} \, E_{ijk}(x)$ (8)

物理含义：顶点 $i$ 的误差 = 到所有邻接面平面距离的加权平方和。这是一个关于 $x \in \mathbb{R}^3$ 的二次函数。

3边坍缩与线性系统求解

3.1 边 Quadric

坍缩边 $ij$ 时，新顶点 $\bar{v}$ 的 quadric 就是两端 quadric 之和：

$Q_{ij} = Q_i + Q_j$ (9)

因为 $E_{ij}(x) = E_i(x) + E_j(x) = \bar{x}^\top (Q_i + Q_j) \bar{x}$，两个二次函数相加等于矩阵直接相加。

3.2 求最优新顶点位置

新顶点 $x^*$ 应最小化 $E_{ij}(x)$。对 $E_{ij}(x) = x^\top A_{ij} x + 2\mathbf{b}_{ij}^\top x + c_{ij}$ 求梯度等于零：

$\nabla E_{ij} = 2A_{ij}\, x + 2\mathbf{b}_{ij} = 0 \quad \Longrightarrow \quad A_{ij}\, x^* = -\mathbf{b}_{ij}$ (10)

其中 $A_{ij}$ 是 $Q_{ij}$ 的左上 3×3 子块，$\mathbf{b}_{ij}$ 是右上 3×1 子块。

求解的条件
  • $A_{ij}$ 可逆且条件良好 → 直接 Cholesky 分解求解，$x^*$ 唯一且稳定
  • $A_{ij}$ 奇异（det = 0）→ 无唯一解；ManuMesh 当前不做 SVD，而是先尝试沿折叠边的一维最优（rank-2 quadric 的良定情形），仍失败才落回端点/中点候选
  • $A_{ij}$ 可逆但病态（条件数很大）→ 解存在但被浮点噪声主导

3.3 坍缩代价与优先队列

最优位置 $x^*$ 确定后，坍缩代价就是这个位置上的误差值：

$\text{cost}_{ij} = E_{ij}(x^*) = \mathbf{b}_{ij}^\top x^* + c_{ij}$ (11)

（最后一步用了 $A_{ij} x^* = -\mathbf{b}_{ij}$。）

QEM 简化的主循环：所有边按 cost 从小到大排序放入优先队列，每次弹出最小的执行坍缩，更新受影响边的代价，重复直到达到目标顶点数。

注意

这个流程意味着边的坍缩顺序由 $\text{cost}_{ij}$ 决定。如果所有边的 cost 都≈0且差异在噪声量级，优先队列等价于随机选择——这正是下一章要分析的核心问题。

4不满秩问题：何时、为何、后果多严重

上一章指出，求解最优顶点位置需要 $A_{ij}$ 可逆。但 $A_{ij}$ 在什么情况下不满秩？不满秩时实际会发生什么？ 本章从结构分析出发，逐层剖析后果。

4.1 A 的结构分析

$A_{ij}$ 是 3×3 对称矩阵，由若干秩 1 矩阵 $\hat{n}\hat{n}^\top$ 加权求和而成：

$$A_{ij} = \sum_{\text{邻接面}} w_k \, \hat{n}_k \hat{n}_k^\top$$ (12)

这是一个 法向量的二阶矩矩阵（类似协方差矩阵）。它的秩取决于邻接面法向量的分布：

法向量分布A 的秩几何场景状态
3 个以上不共面法向量3正常曲率区域（球面、角点）满秩 ✓
2 个独立法向量（共面不同向）2棱边、折痕秩亏 1 ✗
1 个法向量方向（所有面共面）1平坦区域秩亏 2 ✗
0（无边邻接）0孤立顶点零矩阵 ✗

下面分三层分析不满秩的后果，从"勉强能跑"到"致命"。

4.2 第一层：完全平坦——方程组无唯一解

所有三角面都在 $z=0$ 平面上，法向量均为 $\hat{n} = (0,0,1)$。以 2D 类比说明（3D 完全类似）：

$$A = \sum_k w_k \begin{pmatrix} 0 & 0 & 0 \\ 0 & 0 & 0 \\ 0 & 0 & 1 \end{pmatrix} = \begin{pmatrix} 0 & 0 & 0 \\ 0 & 0 & 0 \\ 0 & 0 & W \end{pmatrix}, \quad W = \sum_k w_k$$

$A$ 的秩 = 1。$x$ 和 $y$ 方向完全没有约束。线性方程组退化为：

$$\begin{cases} 0 \cdot x = 0 \\ 0 \cdot y = 0 \\ W \cdot z = -b_z \end{cases} \quad \Longrightarrow \quad z^* = -b_z/W, \;\; x^*, y^* \text{ 任意}$$

$A$ 是奇异的，线性方程组没有唯一解。朴素实现必须用 SVD 或其他 fallback 启发式——这些方法给出的 $x, y$ 坐标本质上是随机的（如取端点中点、取 SVD 最小范数解等），不反映任何几何意义。（ManuMesh 当前用受约束的候选集回避这种任意性：端点/中点候选始终参与，谱条件拒绝全空间最优后先尝试沿折叠边的一维最优，最后按代价取最小者。）

4.3 第二层：近平坦——解存在但被浮点噪声主导

即使不是完全平坦，只要法向量接近一致，$A$ 虽形式上满秩，条件数也会极大。

设法向量 $\hat{n}_1 = (0, 0, 1)$，$\hat{n}_2 = (\varepsilon, 0, \sqrt{1-\varepsilon^2})$（差一个小角度 $\approx \varepsilon$）：

$$A = \hat{n}_1\hat{n}_1^\top + \hat{n}_2\hat{n}_2^\top = \begin{pmatrix} \varepsilon^2 & 0 & \varepsilon\sqrt{1-\varepsilon^2} \\ 0 & 0 & 0 \\ \varepsilon\sqrt{1-\varepsilon^2} & 0 & 2-\varepsilon^2 \end{pmatrix}$$

特征值中有一个 $\approx \varepsilon^2$（极小），条件数 $\kappa \approx 2/\varepsilon^2$。当 $\varepsilon = 0.01$ 时 $\kappa \approx 20000$。

$\varepsilon = 0.01$ 时，$A$ 的 $x$ 方向特征值约为 $0.0002$。形式上可逆，但：

$$x^* = \frac{b_x + \text{浮点误差}}{0.0002}$$

浮点误差量级 $\sim 10^{-16}$，除以 $0.0002$ 后变成 $\sim 10^{-12}$。看似很小，但如果 $b$ 本身在量级 $10^{-2}$（$\varepsilon^2$ 量级），那浮点噪声的相对影响就是 $10^{-10}$——对于多次迭代累积来说，足够让结果跳变。

但这一层还不是最严重的。第三层才是致命的。

4.4 第三层（致命）：优先队列失效

QEM 简化的核心流程（回顾 3.3 节）：

1. 对每条边，计算坍缩代价 E_ij(x*)  ← 最低点的误差值
2. 把所有边按 E_ij 从小到大放进优先队列
3. 每次弹出代价最小的边，执行坍缩
4. 更新受影响边的代价，放回队列
5. 重复

关键在第 1-2 步：边的坍缩顺序由 $E_{ij}(\mathbf{x}^*)$ 决定。

在近平坦区域，代入 $\mathbf{x}^*$：

$$E(\mathbf{x}^*) = \frac{2\varepsilon^2}{\varepsilon^2+1} \cdot 1 + 0 + c \approx 0.0002 + c$$

而 $c$ 也在 $\varepsilon^2$ 量级。结论：平坦区域中所有边的坍缩代价 $E \approx 0$，彼此差异在 $\varepsilon^2 \sim 10^{-4}$ 量级。

优先队列看到的代价：

边 A: 0.00019998
边 B: 0.00020001
边 C: 0.00019995
边 D: 0.00020003
...

这些差异是纯数值噪声，不反映任何几何意义。算法本质上在随机挑边坍缩。

具体后果
正确顺序（应该先坍缩不重要的边）:
  先坍缩 e₅ → 再坍缩 e₃ → 再坍缩 e₇ → 均匀简化 ✓

实际顺序（平坦区随机）:
  先坍缩 e₂ → 再坍缩 e₂的邻居 → 再坍缩邻居的邻居 → 一边堆挤、一边空旷 ✗

结果就是论文 Fig.3 中间列的样子：平坦区域出现大量细长三角形、顶点分布极不均匀。

4.5 为什么缩放方法无效

之前的方法（如 [LHW10]）试图对 QEM 做标量缩放来调整优先级：$\tilde{E} = s_i \cdot E$。但 $0 \times \text{任何数} = 0$——在完全平坦区域，$E = 0$，缩放后仍然是 0，对优先级毫无影响。这就是论文 Fig.1 所展示的问题：缩放方法无法在平坦区域提供任何控制力。

5Line Quadrics 定义与构造

5.1 核心思想

标准 QEM 的 $A$ 只在法向量方向有约束力（"垂直于面"的方向）。Line Quadrics 在切平面方向也加上约束——这样 $A$ 在所有方向都有值，不再秩亏。

直觉

标准 QEM 说："新顶点要离原来的平面近" → 但在平面内随意移动无所谓
Line Quadric 补充说："新顶点还要离原来的顶点位置近" → 平面内也有约束了

5.2 数学定义

对于顶点 $i$（位置 $v_i$，单位法向量 $\hat{n}_i$），定义一条过 $v_i$、方向为 $\hat{n}_i$ 的直线 $L_i$。Line Quadric 衡量的是点到这条直线的距离平方。

用勾股定理构造

3D 中点到直线的距离可以通过两个正交平面来分解。首先用 Gram-Schmidt 构造两个与 $\hat{n}_i$ 正交的单位向量：

$\hat{x}_i \perp \hat{n}_i, \quad \hat{y}_i = \hat{x}_i \times \hat{n}_i, \quad \|\hat{x}_i\| = \|\hat{y}_i\| = 1$ (13)

两个平面 quadric（都过 $v_i$，法向量分别为 $\hat{x}_i$ 和 $\hat{y}_i$）：

$$Q_i^x = \begin{bmatrix} \hat{x}_i \\ -\hat{x}_i^\top v_i \end{bmatrix} \begin{bmatrix} \hat{x}_i \\ -\hat{x}_i^\top v_i \end{bmatrix}^\top, \qquad Q_i^y = \begin{bmatrix} \hat{y}_i \\ -\hat{y}_i^\top v_i \end{bmatrix} \begin{bmatrix} \hat{y}_i \\ -\hat{y}_i^\top v_i \end{bmatrix}^\top$$ (14)

Line Quadric 是两者之和：

$$Q_i^l = Q_i^x + Q_i^y$$ (15)

5.3 Line Quadric 的 A 子块

计算 $Q_i^l$ 的左上 3×3 子块：

$$A_i^l = \hat{x}_i \hat{x}_i^\top + \hat{y}_i \hat{y}_i^\top$$ (16)

因为 $\{\hat{x}_i, \hat{y}_i, \hat{n}_i\}$ 构成正交基，有恒等式：

$$\hat{x}_i \hat{x}_i^\top + \hat{y}_i \hat{y}_i^\top + \hat{n}_i \hat{n}_i^\top = I_3$$ (17)

因此：

$$\boxed{A_i^l = I_3 - \hat{n}_i \hat{n}_i^\top}$$ (18)
关键性质

$A_i^l$ 是投影矩阵——它将向量投影到法向量 $\hat{n}_i$ 的正交补空间（即切平面）。$A_i^l$ 的秩为 2，恰好填补了标准 QEM 在切平面方向上的缺失。

6Line Quadrics 对 E 的影响：完整推导

第 4 章分析了标准 QEM 不满秩的三层后果。本章对应地推导：加入 Line Quadric 后，每一层问题如何被解决。

6.1 增强后的 Q 和 A

在原 QEM 基础上加入 line quadric：

$$\tilde{Q}_i = Q_i + w_i \, a_i \, Q_i^l$$ (19)

其中：

  • $Q_i$：标准 QEM 顶点 quadric（邻接面 plane quadric 之和）
  • $Q_i^l$：line quadric（两个切平面 quadric 之和）
  • $w_i > 0$：用户权重（默认 $10^{-3} \sim 10^{-4}$）
  • $a_i = \sum_{ijk} a^i_{jk}$：barycentric vertex area，保证尺度无关

增强后的 A 子块：

$$\boxed{\tilde{A}_i = \underbrace{\sum_{ijk \in N_i} a^i_{jk} \, \hat{n}_{ijk} \hat{n}_{ijk}^\top}_{\text{标准 QEM（秩 ≤ 3）}} + \; w_i \, a_i \, \underbrace{(I_3 - \hat{n}_i \hat{n}_i^\top)}_{\text{Line Quadric（秩 2）}}}$$ (20)

6.2 改变 1：矩阵永远可解（解决第一层）

平坦区域中所有法向量 $\hat{n}_{ijk} = (0,0,1)$，顶点法向量 $\hat{n}_i = (0,0,1)$：

$$\tilde{A}_i = \begin{pmatrix} 0 & 0 & 0 \\ 0 & 0 & 0 \\ 0 & 0 & a_i \end{pmatrix} + w_i \, a_i \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 0 \end{pmatrix} = \begin{pmatrix} w_i a_i & 0 & 0 \\ 0 & w_i a_i & 0 \\ 0 & 0 & a_i \end{pmatrix}$$

$\tilde{A}_i$ 是对角矩阵，三个特征值分别为 $w_i a_i, \; w_i a_i, \; a_i$，全部为正。永远满秩，永远非奇异。 Cholesky 分解直接求解，无需 SVD。

6.3 改变 2：数值稳定（解决第二层）

切平面方向特征值从 $\approx 0$ 变成 $\approx w_i \cdot a_i$。条件数 $\kappa = 1/w_i$。

$\varepsilon$原特征值（切向）加后特征值原条件数加后条件数
0（完全平坦）0$w \cdot a$$\infty$$\sim 1/w$
0.01（近平坦）$\sim 0.0002$$0.0002 + w \cdot a$$\sim 10000$$\sim 1/w$
0.1（微曲）$\sim 0.02$$0.02 + w \cdot a$$\sim 100$$\sim 1/w$（几乎不变）
1（明显弯曲）$\sim 1$$1 + w \cdot a$$\sim 1$$\sim 1$（几乎不变）

当 $w = 10^{-3}$ 时，条件数上限 $\sim 1000$，完全健康。且高曲率区几乎不受影响——LQ 自动隐身。

6.4 改变 3（最关键）：优先级变得有意义（解决第三层）

加上 line quadric 后，误差函数变为：

$$\tilde{E}(\mathbf{x}) = \underbrace{E_{\text{QEM}}(\mathbf{x})}_{\approx 0 \text{ 在平坦区}} + \; w \cdot a \cdot \underbrace{\|\mathbf{x} - \mathbf{v}_i\|^2_{\text{切}}}_{\text{切平面方向距离平方}}$$

在平坦区域，QEM 部分约等于 0，所以：

$$\tilde{E}(\mathbf{x}^*) \approx w \cdot a \cdot \|\mathbf{x}^* - \mathbf{v}_i\|^2_{\text{切}}$$

坍缩代价不再≈0，而是正比于"新顶点在切平面方向上离原始顶点有多远"。

具体数值对比（$\varepsilon = 0.01$, $w = 0.001$）

假设有 4 条边等待坍缩，每条边的新顶点到原始顶点距离不同：

边新顶点到原始顶点距离原始 $E_{\text{QEM}}$加后 $\tilde{E}$优先级变化
$e_1$0.10.0002000.000210几乎不变
$e_2$2.00.0001990.004199大幅降低优先级
$e_3$0.50.0002010.000451略微降低
$e_4$5.00.0001980.025198几乎不会先选
  • 不加：4 条边的代价都在 0.000198~0.000201，差异 $\sim 10^{-6}$，随机选
  • 加了：代价范围 0.000210~0.025198，差异 $\sim 10^{-2}$，有意义地排序

$e_1$（离原始顶点近、坍缩代价低）被优先选中 → 新顶点不会跑太远 → 顶点分布均匀。$e_4$（离原始顶点远、坍缩代价高）被推迟 → 不会出现一个区域被过度坍缩、另一个区域被忽略的情况。

6.5 误差函数 E 的完整展开

增强后的误差函数完整形式：

$$\tilde{E}_i(x) = \underbrace{E_i^{\text{QEM}}(x)}_{\text{到邻接面平面的距离平方和}} + \; w_i \, a_i \, \underbrace{E_i^l(x)}_{\text{到法向量直线的距离平方}}$$ (21)

展开 line quadric 误差项。由勾股定理，点到直线 $L_i$（过 $v_i$，方向 $\hat{n}_i$）的距离平方等于点到两个正交平面 $\hat{x}_i, \hat{y}_i$ 的距离平方和：

$$E_i^l(x) = \big(\hat{x}_i^\top(x - v_i)\big)^2 + \big(\hat{y}_i^\top(x - v_i)\big)^2$$ (22)

利用正交基恒等式 (17)，这等价于：

$$E_i^l(x) = \|x - v_i\|^2 - \big(\hat{n}_i^\top(x - v_i)\big)^2$$ (23)
物理含义

Line Quadric 误差 = "点到顶点的总距离平方" 减去 "法向量方向的距离平方" = 切平面方向上的距离平方

line quadric 只惩罚新顶点在切平面内偏离原始顶点，不惩罚沿法向量方向的移动（那由标准 QEM 负责）。

完整展开 (21)：

$$\tilde{E}_i(x) = \sum_{ijk \in N_i} a^i_{jk} \, \big(\hat{n}_{ijk}^\top(x - v_{ijk})\big)^2 + w_i \, a_i \left( \|x - v_i\|^2 - \big(\hat{n}_i^\top(x - v_i)\big)^2 \right)$$ (24)

边 $ij$ 坍缩后的增强 quadric 为两端之和：

$$\tilde{Q}_{ij} = \tilde{Q}_i + \tilde{Q}_j = (Q_i + Q_j) + w_i a_i Q_i^l + w_j a_j Q_j^l$$

在平坦区域，$Q_i + Q_j \approx 0$，坍缩代价简化为：

$$\tilde{E}_{ij}(x^*) \approx w_i a_i \, E_i^l(x^*) + w_j a_j \, E_j^l(x^*)$$ (25)

6.7 多轮迭代的累积效应

单步看，加不加 line quadric 的差别可能不大。但 QEM 是迭代的，每一步的 Q 矩阵会传到下一步：

累积对比
不加 Line Quadric加 Line Quadric
第 1 轮平坦区所有边 $E \approx 0$ → 随机选 → 新顶点位置随机离原始顶点近的边优先 → 新顶点 ≈ 质心
第 2 轮新 Q 仍然奇异 → 继续随机选新顶点的 line quadric 累积 → 后续代价更明确
第 N 轮累积随机性 → 顶点扎堆或稀疏 → 细长三角形堆积Fréchet 均值效应 → 顶点趋向已坍缩顶点的平均位置 → 均匀分布

7Fréchet 均值连接

论文 Lemma 4.1 的核心结论：在平面区域上，加入 line quadrics 后，新顶点的最优位置是所有已坍缩顶点位置的 Fréchet 均值（加权最小二乘中心）。

推导

在完全平坦区域，标准 QEM = 0，增强误差只剩 line quadric。经过多轮坍缩，新顶点 $\bar{v}$ 的 quadric 累积了所有已坍缩顶点 $v_1, v_2, \ldots, v_k$ 的 line quadric：

$$\tilde{E}(\bar{v}) = \sum_{m=1}^{k} w_m a_m \left( \|\bar{v} - v_m\|^2 - \big(\hat{n}^\top(\bar{v} - v_m)\big)^2 \right)$$

在平坦区域 $\hat{n}$ 对所有顶点相同，令 $\hat{n} = (0,0,1)$，则 $(\hat{n}^\top(\bar{v}-v_m))^2 = (\bar{z}-z_m)^2$，误差变为：

$$\tilde{E}(\bar{v}) = \sum_{m=1}^{k} w_m a_m \left( (\bar{x}-x_m)^2 + (\bar{y}-y_m)^2 \right)$$

对 $\bar{x}, \bar{y}$ 求梯度等于零：

$$\bar{x}^* = \frac{\sum_m w_m a_m \, x_m}{\sum_m w_m a_m}, \qquad \bar{y}^* = \frac{\sum_m w_m a_m \, y_m}{\sum_m w_m a_m}$$ (26)

这就是 加权质心——Fréchet 均值的标准定义。

结论

平坦区域中，新顶点自动落在已坍缩顶点的加权质心。多次迭代后，顶点自然趋于均匀分布——不需要任何额外的均匀化步骤。

8特征保留：自适应权重

通过给不同顶点设置不同的 $w_i$，可以实现软性特征保留：

权重设置效果应用
$w_i = 10^{-4}$（全部相同）仅在平坦区起作用，均匀分布通用简化
$w_i$ 在特征顶点处 = 1.0强烈拉住特征顶点，防止偏离关节、拐角保留
$w_i$ 在特征边顶点处增大保留折痕线硬表面模型
$w_i$ 按用户区域渐变区域间不同简化密度LOD 设计

与硬约束的区别：硬约束"禁止删除某顶点"，可能导致拓扑问题；line quadric 的软约束允许特征顶点被坍缩，只是代价更高，在保持外观和保留特征之间自动平衡。

ManuMesh 当前实现的两条加权路径

非 adaptiveScale 路径（默认）沿用本章思路：w_i = lineWeight + featureBoost·s_i 直接加进 line quadric。adaptiveScale=true 时则按 Wang 2008 做优先级/placement 解耦：quadric 只保留干净的 adaptiveBaseLineWeight（默认 1e-2）基础 line 项，featureBoost 改为逐顶点 priorityScale = 1 + featureBoost·s_i，只乘候选队列的排序代价（取折叠边两端点的最大值，折叠时按 max 传播到 keep 端），不再改变 $\tilde{A}x=-\tilde{\mathbf{b}}$ 的解——特征加权只影响“先折叠谁”，不再扭曲“折到哪”。

9完整算法流程

输入: 网格 M=(V,F), 权重 {w_i}, 目标顶点数 N 1. 初始化 ├─ 对每个顶点 i: │ ├─ 计算法向量 n_i（面积加权法向量） │ ├─ 构造正交基 x_i, y_i ⊥ n_i │ ├─ 计算 line quadric Q_i^l = Q_i^x + Q_i^y │ ├─ 计算标准 QEM Q_i（邻接面 plane quadric 之和） │ └─ 增强顶点 quadric: Q̃_i = Q_i + w_i * a_i * Q_i^l │ └─ 对每条边 (i,j): ├─ Q̃_ij = Q̃_i + Q̃_j ├─ 解 Ã_ij * x* = -b̃_ij (Cholesky 分解，无需 SVD!) ├─ cost = Ẽ_ij(x*) └─ 放入优先队列 2. 迭代简化 while |V| > N: ├─ 弹出代价最小的边 (i,j) ├─ 坍缩: 删除 v_i, v_j, 插入新顶点 v* = x* ├─ Q̃_new = Q̃_ij (继承，不重新计算) ├─ 更新邻接边的 Q̃ 和 cost └─ 更新优先队列 3. 输出简化网格 M' 核心代码改动（在标准 QEM 基础上）: + compute_line_quadric(vi, ni) # 10 行 + Q̃_i += w_i * a_i * Q_i^l # 1 行 总计: ~10 行代码改动

10总结

标准 QEM 的问题
  • $A$ 由法向量外积求和构成，平坦区秩亏
  • 平坦区所有边 cost ≈ 0，随机坍缩
  • 缩放方法无效：0 × k = 0
  • 需要 SVD 等数值修补
  • 无法控制顶点分布和特征保留
Line Quadrics 的解决
  • $A^l = I - \hat{n}\hat{n}^\top$ 填补切平面方向
  • $\tilde{A} = A + w \cdot a \cdot A^l$ 永远满秩
  • 平坦区 cost ∝ 到原始顶点距离 → 有意义排序
  • Cholesky 直接求解，无需 SVD
  • Fréchet 均值 → 均匀分布；自适应 w → 特征保留
一句话总结

标准 QEM 的 $A$ 只在法向量方向有约束（"别离开平面"），切平面方向完全空白。Line Quadric 的 $A^l = I - \hat{n}\hat{n}^\top$ 恰好填补切平面方向（"别离原始顶点太远"），两者相加 = 完整的 3D 约束。权重 $w = 10^{-4}$ 足以在平坦区建立有意义的优先级排序，同时在高曲率区几乎无影响。

10ALine Quadrics 与特征识别的边界

Line Quadrics 解决的是 QEM 在平坦区切向自由度过大的问题，它本身不是特征检测算法。真正决定“哪条曲线要被保护”的仍然是 FeatureAnalysis：boundary/dihedral/non-manifold 给强证据，normal tensor 给弱证据，feature graph cleanup 负责连通与闭合，primitive fitting 决定圆/椭圆 loop 是否可信。

模块回答的问题不能替代谁
Plane QEM新点是否贴近原始局部平面。不能判断 CAD 语义特征。
Line Quadrics平坦区切向漂移是否有温和代价。不能识别 feature graph 或 loop。
FeatureDetection哪些 edge/loop/component 是 feature support。不能单独保证 collapse 后误差和拓扑合法。
FeatureConstraints哪些 feature collapse 要拒绝或投影。不能修复检测阶段漏掉的特征。

所以本页公式读完后，下一步应该去看 current-program-principles.html#feature-recognition-deep-dive：那里解释 featureAngleDeg、loopTraceAngleDeg、normal tensor persistence、cleanup bridge、component confidence 如何共同决定 Line Quadrics 和 QEM 到底保护什么。

10B纹理保护与 4×4 line-quadric 主干的兼容关系

本轮新增的纹理感知简化（preserveTexture，设计文档 docs/design/texture_aware_qem.md，实现 src/simplification/TextureProtection.cpp）刻意不进入本页推导的任何矩阵：几何 quadric 仍是 4×4 齐次 Mat4，坍缩仍解同一个 $\tilde{A}\,x^* = -\tilde{\mathbf{b}}$，候选仍是端点、中点、稳定 3D QEM 最优点，以及全空间最优被谱条件拒绝时新增的沿边一维最优。texture 只在两个位置介入：一是候选排序——把只在坍缩边一环上现算的标量 E_uv_local 乘 textureWeight（默认 1.0）加到几何代价上，即 E_total(p)=E_geometry_4x4(p)+textureWeight*E_uv_local(p)；二是合法性过滤——局部 UV chart 一一配对、存活 UV 三角形的有符号定向与最小面积比例（minTextureAreaRatio）检查，不满足就拒绝坍缩并计入 textureRejectedCollapses。

因此本页关于 line quadrics 的全部结论——满秩保证、条件数 $\sim 1/w$、平坦区优先级恢复、Fréchet 均值效应——在纹理模式下逐字成立：纹理项既不改变 $\tilde{A}$ 的秩，也不移动线性系统的解，只可能改变“哪条边先被弹出队列”和“这次坍缩会不会被否决”。preserveTexture=false（默认）时几何输出与旧无纹理路径 bit-exact 一致。

模块是否被 texture 改变说明
几何 quadric 构造（plane/line/boundary/curve）完全不动仍是 4×4 齐次二次型累加，维度与内容不变。
placement 求解与回退完全不动候选集合与 $\tilde{A}x=-\tilde{b}$ 求解不变，texture 不参与解。
候选排序增加标量项+ textureWeight*E_uv_local，局部现算，量纲与面积加权几何 QEM 一致（长度⁴），且对 UV atlas 均匀缩放不变。
坍缩合法性增加纹理硬过滤chart 无对应/配对歧义/合并不相关 chart、存活 UV 三角形定向翻转、有符号 UV 面积低于 minTextureAreaRatio 时拒绝；与拓扑/质量/自交 guards 并列。
诊断新增两个计数textureProtectedEdges（初始即无合法中点纹理坍缩的边数）、textureRejectedCollapses（placement 评估后被否决的队列候选数）。
