1. 学习顺序与完成标准

Mesh 容器与 validate -> MeshTopology 只读缓存 -> DynamicTopology 可变邻接 -> MeshCompaction 稳定 remap -> GeometryPredicates -> SpatialIndex / MeshDistanceIndex -> OBJ / STL IO -> MeshAnalysis 最终指标

不要先从大型 OBJ 或工业 STL 开始。每个单元先画出 3-8 个顶点的小 fixture，手算边、邻面、边界、包围盒或距离，再进入断点。

完成标准：面对上层算法中的异常计数，你能判断它来自输入数据、拓扑缓存、几何谓词、空间候选、IO 归一化还是分析采样。

2. VS2019 调试命令

cmake --preset vs2019-debug
cmake --build --preset vs2019-debug-tests

./build/vs2019-debug/bin/Debug/manumesh_tests.exe \
  --gtest_filter=ManuMesh.MeshTopologyCachesBoundaryAndNonManifoldEdges \
  --gtest_break_on_failure

快速跑完整基础回归使用 ctest --preset vs2019-debug-unit。单步时始终使用完整 gtest 名称，避免一次进入多个 fixture。

单元 0：Mesh 容器和验证契约

ManuMesh.EmptyMeshBoundsAreZeroManuMesh.RemoveUnusedVerticesDropsInvalidFacesWithTheirExclusiveVerticesManuMesh.ResultDoesNotRequireDefaultConstructibleValues

断点Mesh::validate、Mesh::removeUnusedVertices、bounds 计算、Status/Result 构造。

观察原始容器计数与“可用几何”计数的区别；invalid face 被跳过或拒绝的契约不能混淆。

单元 1：只读 MeshTopology

ManuMesh.TopologyEdgeKeyIsOrderIndependentAndSharedWithDetailManuMesh.MeshTopologyCachesBoundaryAndNonManifoldEdgesManuMesh.MeshTopologyRejectsOutOfRangeHandles

断点MeshTopology 的 Pimpl/cache 构造、edge key 打包、边界与非流形分类。

观察edge-to-face incidence、vertex neighbors、boundary edge 数和缓存复制/移动。理解这里是公共只读查询，不负责算法编辑。

单元 2：DynamicTopology 与 MeshCompaction

MeshEdit.DynamicTopologyTracksAdjacencyAndDuplicateFacesMeshEdit.CompactsActiveFacesAndReturnsStableRemaps

断点动态拓扑 add/remove/update，compactMesh。

观察active face、vertex-face incidence、duplicate face key、old-to-new vertex/face remap。上层算法必须通过这层维护局部一致性。

单元 3：几何谓词

ManuMesh.GeometryPredicatesMeasureTriangleQualityAndDistanceManuMesh.GeometryPredicatesTriangleIntersectionIsScaleInvariantManuMesh.GeometryPredicatesAllowOnlyDeclaredSharedTopologyContact

断点triangleQuality、pointTriangleDistanceSquared、trianglesIntersectBeyondSharedTopology。

观察退化阈值、尺度归一化、coplanar overlap、共享点/边白名单。相交函数返回的是“超出已声明共享拓扑的接触”。

单元 4：UniformAabbCandidateGrid

ManuMesh.UniformAabbCandidateGridQueriesOverlappingItemsManuMesh.UniformAabbCandidateGridRemovesAndUpdatesItemsManuMesh.UniformAabbCandidateGridKeepsOversizedItemsAsConservativeCandidates

断点insert/update/remove/query 以及 oversized item 分支。

观察cell size、bucket keys、去重、保守候选。空间索引只缩小精确谓词的输入集合，本身不证明相交。

单元 5：MeshDistanceIndex

ManuMesh.MeshDistanceIndexFindsNearestTriangleDistanceManuMesh.MeshDistanceIndexIgnoresDegenerateTriangles

断点索引构建与 nearest distance 查询。

观察有效三角形列表、AABB lower bound、当前 best distance 和退化面跳过。它为 simplification 的 reference envelope 与最终距离比较提供基础。

单元 6：OBJ 与 STL

MeshIo.ObjResolvesNegativeIndicesMeshIo.ObjEarClipsConcavePolygonsWithoutOverlappingFanTrianglesMeshIo.ObjPreservesPerCornerTextureCoordinatesThroughConcaveEarClippingMeshIo.BinaryStlRoundTripUsesStandardLayoutMeshIo.StlVertexMergingIsInvariantToLargeTranslation

断点OBJ line/face parser、ear clipping、STL binary probe、vertex merge。

观察1-based/negative index、face-corner UV、投影轴、polygon orientation、二进制长度、量化 bucket 邻域和错误行号。

OBJ 的逐角 UV 不能压成逐顶点属性；同一几何顶点在不同 texture chart 上可以有不同 UV。

单元 7：MeshAnalysis

ManuMesh.ComputesMeshStatsForGeneratedCubeManuMesh.MeshAnalysisSkipsMalformedFacesAndKeepsRawContainerCountsManuMesh.SampledDistanceSkipsMalformedFacesOnBothSides

断点analysis::computeMeshStats、analysis::compareMeshesBySampledDistance。

观察raw counts、usable faces、area/volume、edge length、triangle quality、sampling budget。sampled distance 是工程指标，不是全局 Hausdorff 形式化证明。
